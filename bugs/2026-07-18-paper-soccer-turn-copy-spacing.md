# 纸上球局：换手反馈在玩家名之前多出空格

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：纸上球局普通落点反馈与 live region
- 发现版本 / commit：功能提交前工作区

## 环境

- macOS 26.5.2；headed Chromium 150.0.7871.125；
- 鼠标点击任一首步合法落点。

## 复现步骤

1. 点击“把球放到中点”；
2. 点击任一高亮的新格点；
3. 读取事件栏和 live region。

## 预期结果

显示“落到新点，轮到蓝方。”，与其他回合文案的中文空格规则一致。

## 实际结果

显示“落到新点，轮到 蓝方。”，动词与玩家名之间出现不必要的半角空格。

## 根因

模板字符串把自然语言空格写在插值之前；动态玩家名本身不需要额外分词。

## 解决方案

删除 `${playerName(...)}` 之前的半角空格，并让可见事件栏和 live region 继续共用同一条 `visibleEvent`。

## 回归验证

- [x] 鼠标、SVG 键盘和方向盘三条路径都显示“轮到蓝方/红方”；
- [x] 进球、借力与困死文案不受影响；
- [x] 正常作品页面控制台 0 error / 0 warning。
