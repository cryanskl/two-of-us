# 一层一层：留言阶段仍把已打开的当前层计入剩余数

- 状态：`fixed`
- 日期：2026-07-17
- 影响作品：一层一层逐层进度提示
- 发现版本 / commit：实现提交前工作区

## 环境

- macOS 26.5.2；headed Chromium；
- 完成任意一层并进入该层留言。

## 复现步骤

1. 开始拆礼物；
2. 解开第一层左右丝带；
3. 查看留言下方的剩余层数。

## 预期结果

第一层已打开，显示“还有 3 层”；后续留言依次显示 2、1、0。

## 实际结果

第一层留言仍显示“还有 4 层”。完成标记已经变成勾，但文字仍把当前层算入剩余量。

## 根因

进度文案只按 `4 - layerIndex` 计算，没有解释 `phase`。同一个 `layerIndex` 在 `layer` 阶段代表“正在拆”，在 `note` 阶段代表“已经拆完”。

## 解决方案

在 `note` 阶段额外扣除当前层；`complete` 继续使用独立终局文案。

## 回归验证

- [x] 四个操作阶段进入时分别显示 4、3、2、1；
- [x] 四个留言阶段分别显示 3、2、1、0；
- [x] complete 显示“已经拆到最后”；
- [x] 重开回到“还有 4 层”。
