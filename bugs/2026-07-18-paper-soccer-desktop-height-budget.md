# 纸上球局：桌面首屏高度预算常量多算两像素

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：纸上球局 1504×1046 桌面布局
- 发现版本 / commit：功能提交前工作区

## 环境

- macOS 26.5.2；headed Chromium 150.0.7871.125；
- 视口：1504×1046。

## 复现步骤

1. 在原生概念尺寸打开 intro 或 playing；
2. 读取 `innerHeight` 与 `documentElement.scrollHeight`；
3. 缩小棋盘宽度后重新读取。

## 预期结果

完整球场、标题、回合、比分、方向盘和页脚都落在 1046px 首屏内，不出现页面级滚动。

## 实际结果

初版页面高 1051px；把棋盘从 715px 缩到 710px 后仍为 1048px，说明剩余溢出不是棋盘内容造成。

## 根因

`.workspace` 使用 `min-height: calc(100vh - 138px)`，但外层上下 padding、顶栏、工作区上下 margin 与页脚合计需要扣除 140px。这个最小高度本身把页面固定撑高 2px，继续压缩棋盘无效。

## 解决方案

把工作区预算修正为 `calc(100vh - 140px)`，并恢复 715px 棋盘宽度。最终棋盘为 715×892.75px，页面 `scrollHeight = innerHeight = 1046`。

## 回归验证

- [x] 1504×1046 intro 与 playing 都无横向或纵向滚动；
- [x] 桌面八方向按钮约 131×68px，页脚完整可见；
- [x] 390×844 与 320×760 仍无横向溢出并可自然滚动。
