# capsule-docking 象限展开产生 `-0`

- 日期：2026-07-25
- 影响范围：`COS_TABLE` / `SIN_TABLE` 的四个象限轴
- 状态：已修复

## 复现与影响

第一轮核心测试对四个象限轴做严格比较时，`COS_TABLE[64]` 与
`SIN_TABLE[128]` 等位置出现 JavaScript 数值 `-0`，而冻结规格要求生成期把
`-0` 归一为 `0`。

JSON 序列化会把 `-0` 写成 `0`，所以 SHA-256 仍可能通过；只靠哈希无法发现这类
运行时表示漂移。严格比较、调试输出和 `Object.is()` 仍能观察到差异。

## 根因与修复

第一象限整数表包含 `0`，在二、三象限按符号展开时执行 `-0` 产生了负零。展开器
现在对每个结果执行 `value === 0 ? 0 : value`，再写入冻结的 256 项表。

## 回归

项目测试同时核对四个象限轴、半圈反号、完整表 SHA-256 和深冻结。
