# 雾里，跟着你走：1280×720 驾驶标题与方向盘重叠

- 日期：2026-07-20
- 阶段：完整四轮浏览器终验
- 影响：常见低高桌面视口中，驾驶提示与方向键互相遮挡，页面还产生 25.5px 纵向滚动
- 状态：已修复并完成桌面、移动端回归

## 复现

1. 以 1280×720 打开 `experiences/co-op/fog-navigation/index.html`；
2. 进入任一驾驶阶段；
3. “第 1 / 4 段 · 雾松坡”换成两行，方向盘顶部为 385.0px，而标题底部为 419.6px、提示底部为 464.4px；
4. 方向盘遮住标题和提示，`documentElement.scrollHeight` 为 745.5px。

## 根因

`max-height: 820px` 桌面规则把舞台写成 `100vh - 92px`，但真实 header、间距和 app 上下 padding 约占 118px，导致总高度超过视口。方向盘又脱离文档流，以容器 `top: 57%` 绝对定位，没有为会换行的标题和提示保留高度；舞台内容与控制区因此各自“正确”但彼此相交。

## 修复

- 低高桌面舞台改为 `min-height: calc(100vh - 118px)`，恢复精确页面高度预算；
- 同一媒体查询内把 `.controls-host` 下移到 `top: 72%`；
- 不改 DOM、字体、地图尺寸或移动端静态流布局。

## 回归验证

- 1280×720：提示底部 476.9px，方向盘顶部 504.0px，间距约 27px；页面 `scrollWidth × scrollHeight` 精确为 1280×720；
- 390×844：5×5 雾窗完整，四个方向键均为 56×56px，页面无横向或纵向溢出；
- 320×700 与 1728×962：此前浏览器冒烟仍适用，因为修复只命中 `min-width: 901px` 且 `max-height: 820px`；
- 30 项作品逻辑测试、80 项 catalog Gate 通过，控制台零 warning/error。

## 可复用结论

绝对定位控件与可换行文案共存时，必须用几何边界验证互不相交；仅检查各自是否在视口内不够。低高度媒体查询的 `100vh - N` 也应把 header 实际内容高度、外边距和容器 padding 全部计入，而不是只沿用设计稿中的理想最小高度。
