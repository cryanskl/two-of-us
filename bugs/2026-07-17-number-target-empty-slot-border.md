# 数字凑靶：空算式槽被渲染为已填写实线

- 状态：`fixed`
- 日期：2026-07-17
- 影响作品：数字凑靶视觉状态
- 发现版本 / commit：实现提交前工作区

## 环境

- macOS 26.5.2；headed Chromium 150.0.7871.125；
- 视口：1504×1046 与 390×844。

## 复现步骤

1. 进入任意一局 drafting；
2. 在尚未选择牌时查看两位玩家的六个 `?` 槽；
3. 检查计算样式的 `border-style`。

## 预期结果

未填写槽使用虚线边框；拿到牌后对应槽改为实线，形成清楚的完成进度。

## 实际结果

所有槽都是实线。CSS 用 `:not(:empty)` 判断，但占位符 `?` 本身就是文本，所以选择器永远匹配。

## 根因

把“DOM 是否有文字”误当成“规则槽是否有值”。占位文案和权威状态不是同一个概念。

## 解决方案

渲染槽位时按值显式切换 `.is-empty`，CSS 只对 `span:not(.is-empty)` 使用实线。占位符仍保留给可见与可访问文本。
