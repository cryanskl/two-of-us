# 软软相扑：暂停按钮低于项目触控高度合同

- 状态：`fixed`
- 日期：2026-07-19
- 影响作品：软软相扑
- 发现版本 / commit：前端提交前候选

## 环境

- 操作系统：任意触屏设备
- 浏览器与版本：任意现代浏览器
- 启动等级与入口：A 级，`experiences/versus/soft-sumo/index.html`

## 复现步骤

1. 开始任一轮，使 utility bar 的“暂停”按钮显示。
2. 检查 `.quiet-action` 的计算最小高度。
3. 对照视觉规格中阶段与工具动作至少 48px 的项目合同。

## 预期结果

暂停按钮和其他阶段动作一样，最小高度至少 48px。

## 实际结果

初版通用按钮规则先声明 48px，随后 `.quiet-action` 又覆盖为 34px，导致暂停按钮不满足本项目的触控尺寸 Gate。

## 根因

为了压缩顶部工具栏，把可缩减的留白和不可缩减的触控目标一起缩小了。

## 解决方案

移除 34px 覆盖并把 `.quiet-action` 最小高度固定为 48px；布局高度通过 utility bar 的间距和响应式场地尺寸消化。

## 回归验证

- [x] CSS 静态值为 48px
- [x] 390×844 与 320×700 计算高度至少 48px
- [x] 两种窄屏都无横向滚动，320px 实际 playing 可滚动到第二席
