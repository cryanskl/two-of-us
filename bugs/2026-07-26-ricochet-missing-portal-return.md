# 弹射坦克缺少正常模式返回入口

- 日期：2026-07-26
- 项目：`ricochet-tank-duel`
- 发现阶段：主分支统一门户 Chrome 验收

## 现象

从根门户真实点击“这一弹，拐弯见你”可以进入体验，但 JavaScript 正常模式没有
可见的“返回作品集”入口。自动化环境中的浏览器返回快捷键也未触发导航，用户只能
关闭标签页或手动改地址。

无 JavaScript 面板已有返回链接，因此问题只出现在真实可玩路径。

## 根因

生产 UI 把返回入口只放在 `<noscript>` 面板中，误把浏览器历史返回当成正常模式的
隐式导航。统一门户的“进入 → 游玩 → 返回”闭环没有被 UI 合同测试覆盖。

## 修复

- 在正常模式标题区增加静态相对链接 `../../../index.html`；
- 保持链接为原生 `<a>`，同时兼容 localhost 与 `file://`；
- 增加失败合同，要求正常模式始终存在唯一可见返回入口；
- 在主门户重新执行真实点击进入与返回验收。

## 防回归

项目 UI 合同现在同时锁定正常模式和 no-JS 模式的返回入口。导航属于体验外壳，
不进入模拟状态，也不依赖 JavaScript。
