# 和你一样：成员迁移后隐藏 DOM 保留上一题答案

## 状态

已修复，2026-07-17。

## 复现条件

1. 两位玩家完成至少一题并进入揭晓或终局；
2. 当前主机点击“离开房间”，另一位玩家被提升为主机；
3. 页面回到“等待另一个人”后检查隐藏的 `#quiz` 节点。

## 预期结果

成员或主机变化后，公开状态、私密选择、消息队列和问答 DOM 全部回到空白初始态。

## 实际结果

问答区虽然被 `display: none` 隐藏，但仍保留 `.selected`、`.revealed`、双方上一题答案和终局文案。Chrome 复现时可在隐藏 DOM 读到 `你选了：没去过的新角落`、`对方选了：熟悉的老地方` 和 `4 / 8`。

## 根因

`resetQuiz()` 只清理 JavaScript 状态和本机选择；正常渲染负责更新的 class、ARIA 属性和文字节点没有专门的反向清理路径。

## 解决方案

新增 `clearQuestionPresentation()`，在整局重置时同时清空题目和答案文字、双方状态、终局文案、心线揭晓态、选中/揭晓 class 与 `aria-pressed`，并禁用答案按钮。下一局开始时仍由正常 `renderQuestion()` 重新填充。
