# 折纸心纸张 ARIA 名称重复句号

## 现象

Chrome 浏览器验证进入折叠阶段后，纸张分组的可访问名称为：

> 准备完成第 1 / 5 折。。当前是第一折……

`view.text.progress` 本身已经以句号结尾，`paperLabel()` 拼接时又补了一个句号。视觉页面不受影响，但屏幕阅读器会读出不自然的停顿。

## 原因

UI 把来自逻辑层的完整进度句子误当成不带结尾标点的短语。

## 解决

保留逻辑层完整文案，在 `paperLabel()` 中直接拼接“当前是……”，不再额外插入标点。这样逻辑层和 UI 层仍各自维护单一文案责任。

## 验证

- Chrome DOM 快照中纸张分组只保留一个句号。
- 逻辑测试与仓库全量测试继续通过。
