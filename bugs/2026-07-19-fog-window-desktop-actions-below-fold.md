# 在雾上，写给你：1280×800 首屏看不到状态和主动作

- 状态：`fixed`
- 日期：2026-07-19
- 影响作品：在雾上，写给你
- 发现版本 / commit：前端实现的提交前候选；修复随 `312b18c feat: build fog window letter experience` 进入

## 环境

- 操作系统：macOS
- 浏览器与版本：Codex in-app Chromium，1280×800 视口
- 启动等级与入口：A 级作品，经本地仓库服务加载同一静态入口

## 复现步骤

1. 以 1280×800 打开作品初始态。
2. 不滚动，检查雾窗底部、可见状态和“开始写 / 直接打开”。
3. 读取页面与关键元素的计算矩形。

## 预期结果

首屏看见完整雾窗、当前状态和至少一个当前主动作；页面不得因固定视觉高度要求先滚动才能开始。

## 实际结果

文档高 996px；雾窗底部为 825px，可见状态从 854px 开始，控制带从 898px 开始，两个动作完全位于 800px 首屏之外。

## 根因

桌面候选同时保留了大标题区、570px 雾窗、独立键盘说明、状态和 76px 控制带，却没有先做 800px 高度预算。`max-height: 570px` 只限制舞台，没有约束整页。

## 解决方案

为高度不超过 1000px 且宽度大于 640px 的桌面增加紧凑规则：舞台收敛到规格目标约 760×470，压缩非核心留白，把键盘说明视觉隐藏但保留在可访问树，并保持按钮 48px。

- [x] “开始写”和“直接打开”均为 48px 且完整可见
- [x] 浏览器控制台无 warning / error
