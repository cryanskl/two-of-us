# 和你一样：触屏 sticky hover 让选中答案文字消失

## 状态

已修复，2026-07-17。

## 复现条件

1. 用 390×844 或 320px 的触屏视口打开问答页；
2. 点击任一答案，使按钮进入 `.selected`；
3. 截图或检查选中按钮的计算样式。

## 预期结果

选中答案使用莓果红背景与白色文字，标记和文案保持清晰可读。

## 实际结果

按钮保持触屏 sticky hover 后，通用 `button:hover:not(:disabled)` 把文字颜色改回莓果红；背景同为莓果红，截图中选中答案看起来是一条空白色带。DOM 文本仍存在，但计算颜色不可见。

## 根因

通用 hover 选择器的优先级高于 `.answer-choice.selected`。桌面鼠标移开后不容易暴露，移动触屏却可能持续保留 hover 状态。

## 解决方案

为 `.answer-choice.selected:hover:not(:disabled)` 明确声明与选中态相同的白字、莓果背景和边框，使语义状态稳定压过通用 hover。
