# 四符片名擂台：使用聚光灯后焦点丢失

## 复现

1. 在 Chrome 进入任意猜题页；
2. 选择会被本题聚光灯排除的选项；
3. 激活“使用聚光灯”；
4. 检查 `document.activeElement`。

首次生产 UI 浏览器验收中，Chrome 的焦点回到了 `body`。

## 影响

聚光灯本身正确消耗一次资源、排除固定错误项并清除失效选择，但键盘和屏幕阅读器
用户失去了明确的后续位置，需要重新寻找当前题面。

## 根因

界面按公共状态投影重建当前 screen。聚光灯使用后，被激活的按钮会在新 DOM 中
变为 `disabled`，不能继续持有焦点；这一条重渲染路径没有像选项选择路径那样
指定安全的焦点目标。

## 修复

- 把当前题标题设为可编程聚焦的 `tabindex="-1"`；
- 聚光灯 action 成功后把焦点移到当前题标题；
- 不让 disabled 控件成为焦点恢复目标，也不改变 Tab 顺序。

## 回归

Chrome 在真实聚光灯路径上确认：

- 一项被排除且保持 disabled；
- 若被排除项原先已选择，选择被清空；
- 继续按钮恢复为 disabled；
- `document.activeElement.id === "question-heading"`。
