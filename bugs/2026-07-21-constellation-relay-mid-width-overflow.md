# 星座接线员：721–829px 双栏最小宽度必然横向溢出

- 状态：`fixed`
- 日期：2026-07-21
- 影响作品：把星光，一笔一笔交给你
- 发现版本 / commit：前端首次实现，提交前只读复审发现

## 环境

- 文件：`experiences/co-op/constellation-relay/style.css`
- 视口：721–829 CSS px；也影响 1504px 视口的 200% zoom

## 复现步骤

1. 原双栏最小轨道为 520px 棋盘、272px 侧栏和至少 14px 间距；
2. 计算最小总宽：`520 + 272 + 14 = 806px`；
3. 原页面只在 720px 以下切单栏；
4. 在 768px 视口中，页面可用宽约 744px，小于 806px。

## 预期结果

任意断点及 200% zoom 下 `scrollWidth === clientWidth`，不会因双栏最低尺寸产生横向滚动。

## 实际结果

721–829px 仍命中不可收缩的双栏规则，确定性溢出；1504px@200% 的有效视口约 752px，也进入同一断层。

## 根因

断点按常见设备宽度选择，却没有从布局轨道、gap 和页面边距反推安全阈值。

## 解决方案

- 双栏统一为 `min-width: 840px`；
- 单栏统一为 `max-width: 839px`；
- 840px 下内容宽约 816px，仍高于 806px 最小双栏需求；
- 768、820 与 1504@200% 全部使用安全单栏。
