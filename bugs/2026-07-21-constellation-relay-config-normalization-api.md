# 星座接线员：规格要求归一化配置但没有公开入口

- 状态：`fixed`
- 日期：2026-07-21
- 影响作品：把星光，一笔一笔交给你
- 发现版本 / commit：规格提交 `fa028bd`，逻辑实现前审计发现

## 环境

- 文档：`docs/167-constellation-relay-spec.md`
- 阶段：逻辑与前端子任务开始时的公开 API 审计
- 启动等级：A；问题属于规格，不依赖浏览器

## 复现步骤

1. 查看原规格 §11，页面必须“只消费归一化后的冻结配置”；
2. 查看原规格 §4 的 `ConstellationRelayLogic` 导出表；
3. 尝试从 `app.js` 调用配置归一化入口。

## 预期结果

规则层公开默认配置和唯一归一化函数；页面不复制 Unicode 长度、两席不同名、整份回退与递归冻结规则。

## 实际结果

原导出表只有关卡、几何、求解、状态机和公开视图，没有配置 API。前端若严格遵守导出表，就无法满足 §11；若自行归一化，又会违反“页面不复制规则”的边界。

## 根因

规格编写时冻结了配置数据与约束，却漏把配置归一化能力纳入公开 API。文件边界与消费原则正确，缺的是连接二者的显式契约。

## 解决方案

- 在公开 API 增加递归冻结的 `DEFAULT_CONFIG`；
- 增加 `normalizeConfig(raw)`，作为页面唯一配置入口；
- 合法返回必须与 raw 断开引用并递归冻结；
- 任一字段、类型、原型或边界非法时整份回退；
- 不允许配置覆盖点、边、规则、颜色或完成条件。
