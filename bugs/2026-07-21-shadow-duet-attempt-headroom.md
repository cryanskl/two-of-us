# 把影子，跳成我们：尝试上限没有为剩余幕保留最低预算

- 状态：`fixed`
- 日期：2026-07-21
- 影响作品：把影子，跳成我们
- 发现版本 / commit：纯逻辑首次实现，提交前独立审计发现

## 环境

- Node.js v22；纯 reducer 伪造状态探针
- 启动等级与入口：A；`reduce()` / `getPublicView()`

## 复现步骤

1. 构造仍未完成首幕、`attempt = Number.MAX_SAFE_INTEGER - 5` 的合法 missed 状态；
2. 派发 `{ type: "RETRY_SCENE" }`；
3. 继续尝试完成当前幕和后五幕。

## 预期结果

任何被接受的状态都必须为当前幕和每个剩余幕保留至少一次尝试；会侵占最低预算的重试保持原对象 no-op。

## 实际结果

旧校验只确认当前 `attempt + 1` 本身未溢出。重试后总量仍是安全整数，却没有额度完成后五幕，产生表面合法但不可完成的状态。

## 根因

安全整数检查局限在单字段递增，没有把完成前缀、当前 attempt 与剩余幕最低次数放进同一个可达性不变量。

## 解决方案

- 当前幕未完成时校验 `sum(completed) + attempt + remainingFutureScenes <= MAX_SAFE_INTEGER`；
- `pose-result` 为尚未开始的每幕各保留一次；
- `RETRY_SCENE` 先验证递增后的公式，失败时保持原引用；
- 用剩余 1–5 幕和总量 M−1/M 的表驱动测试覆盖所有未完成阶段。
