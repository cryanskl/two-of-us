# Bug：全景回忆在运行时就绪后仍提示启动服务

- 状态：`fixed`
- 日期：2026-07-15
- 影响作品：回到那一天
- 发现版本 / commit：项目提交前代码复核

## 环境

- 操作系统：macOS
- 浏览器与版本：Chrome（Codex Chrome 扩展会话）
- 启动等级与入口：B 级，`/experiences/surprises/panorama-memory/`

## 复现步骤

1. 通过根目录启动器打开本地门户；
2. 进入“回到那一天”；
3. 观察全景舞台下方第一条说明。

## 预期结果

本地服务和 Pannellum 可用时，说明应确认本地运行时已就绪。

## 实际结果

选择器已经可用，但说明仍固定显示“请先运行本地启动器”，会让用户误判启动状态。

## 根因

启动说明只存在于静态 HTML，运行时就绪分支没有同步更新对应文案。

## 解决方案

为说明文本增加稳定 DOM 标识，并在通过 HTTP(S) 且 Pannellum API 可用后更新为“本地运行时已就绪”。直接 `file://` 打开时仍保留原始启动提示。
