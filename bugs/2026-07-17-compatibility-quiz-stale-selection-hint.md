# 和你一样：已选择后仍提示先选答案

## 状态

已修复，2026-07-17。

## 复现条件

1. 进入任意一道题；
2. 点击 A 或 B，但尚未点击“密封这个选择”；
3. 查看按钮下方的辅助提示。

## 预期结果

页面确认答案已经选中，并提示玩家准备好后将它密封。

## 实际结果

答案按钮已经高亮，辅助提示仍显示“先选一个答案，再把它密封。”，与当前状态矛盾。

## 根因

未提交分支只根据 `submitted` 判断文案，没有继续区分 `selectedAnswer` 是否存在。

## 解决方案

未提交时按 `selectedAnswer` 切换提示：尚未选择继续引导选择；已经选择则显示“准备好后，把这个答案密封。”。

- [x] 已选择时显示密封提示
- [x] 提交后仍显示“已选好，等你”
