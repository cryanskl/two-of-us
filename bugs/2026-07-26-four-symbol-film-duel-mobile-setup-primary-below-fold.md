# 四符片名擂台：移动设置页主动作落在首屏之外

- 状态：`fixed`
- 日期：2026-07-26
- 环境：Chrome，390×844，localhost 自动化入口

## 复现与实际结果

在 390×844 打开项目设置页且保持 `scrollY = 0`。“开始放映”按钮高度为
50.5px，但位于 y=1207.8–1258.3，页面总高 1299px；用户必须先纵向滚动才能
执行首局唯一主动作。

## 预期

设置内容完整保留、DOM 与 Tab 顺序不变，且 390×844 首载时“开始放映”位于
首屏内；所有姓名、题包、等价文字和计分选项仍可访问。

## 根因与修复

通用 700px 断点把姓名与四个题包都改成单列，两个字段组的高度叠加后把按钮推到
首屏之外。390px 断点现在为 setup 专门恢复双列姓名与双列题包，并收紧局部间距
和题包卡片内边距。没有改变 DOM 顺序、默认值、玩法或其他阶段布局。
