# 月相圆环在 Pointer 与键盘之间切换时失焦

## 现象

开始校准后，程序会把焦点放到月份圆环，方向键可用；但用户点过日期加减按钮，再点击月份或月相圆环并按方向键，读数不变化。

## 复现

1. 直接打开 `experiences/surprises/moon-phase-secret/index.html`；
2. 点击“开始校准”；
3. 点击任意日期加减按钮；
4. 点击月份圆环，再按 `ArrowRight`；
5. 修复前月份不变，焦点仍停在日期按钮。

## 根因

圆环为支持拖动，在 `pointerdown` 中调用了 `event.preventDefault()`。这同时阻止了按钮元素的默认聚焦行为，导致鼠标/触摸与键盘两种输入通路无法自然切换。

## 解决方案

成功捕获主指针后，先调用 `ring.focus({ preventScroll: true })`，再阻止默认手势。这样保留 Pointer 拖动和页面防滚动边界，同时恢复点击后立即使用方向键的能力。

## 回归重点

- 点击月份圆环后，方向键改变月份；
- 点击月相圆环后，方向键改变月相；
- 日期按钮仍保持 48px 点击目标；
- Pointer 拖动、`Home`、失焦和页面隐藏清理仍可用。
