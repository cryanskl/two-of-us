# 七日小花园：目录 Gate 在 CSS 中检查由 JavaScript 持有的图集路径

- 状态：`fixed`
- 日期：2026-07-21
- 环境：Node 全量测试；目录接入阶段
- 影响：新增目录边界测试误报失败，运行时作品不受影响

## 复现

1. 新增 C16 目录测试，断言 `styles.css` 包含 `assets/plant-states.png`；
2. 运行 `npm test`；
3. 目录与 1448 项其他测试通过，新增资源测试失败。

## 预期

测试应在真正持有植物图集路径的源文件中锁定该本地资产，既能防止资源漂移，也不强迫实现采用错误的 CSS 组织方式。

## 实际

植株图集由 `app.js` 创建预加载探针并赋给 `Image.src`，CSS 只负责根据 `plant-image-ready` 状态显示图层。测试却在 CSS 中寻找 URL，把正确的职责分离误判为缺少资产。

## 根因

编写 Gate 时沿用了背景图和完成纪念图的 CSS 检查形式，没有逐项确认植物图集的资源所有权。测试锁住了臆测的内部结构，而非真实实现边界。

## 修复

保留图集路径断言，但把目标从 `css` 改为 `app`。背景与完成纪念图仍在 CSS 中检查，三个资产各自在真实拥有者处被约束。
