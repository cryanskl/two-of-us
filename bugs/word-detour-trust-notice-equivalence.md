# 绕词对决：默认信任声明被验证器错误拒绝

## 复现

首次加载 `logic.js` 时，内建 `config.js` 的 `trustNotice` 使用“页面不会录音”，
模块却抛出 `Invalid built-in word detour config`，项目测试无法启动。

## 根因

规格允许“不录音或等价明确否定”，但验证器只搜索连续字面量“不录音”，没有把
默认文案中的“不会录音”识别为同一明确否定。

## 修复

验证器只接受 `不录音` 与 `不会录音` 两种明确形式，不移除隐私声明 Gate，也不
接受含糊的“通常不录音”等表述。测试同时固定默认文案与另一种合法明确否定。

## 回归

重新运行项目定向测试、全仓测试、repository verify 和 `git diff --check`。
