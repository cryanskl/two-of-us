# 爱心投石器：步进符号被拼进按钮可访问名称

- 状态：`fixed`
- 日期：2026-07-24
- 影响作品：`heart-catapult`
- 发现版本 / commit：`04d903f` 加入视觉样式后的工作区候选

## 环境

- 操作系统：macOS
- 浏览器与版本：Chrome MCP 当前连接版本
- 启动等级与入口：A；`experiences/versus/heart-catapult/index.html`

## 复现步骤

1. 进入秘密瞄准阶段；
2. 用 CSS 伪元素把完整按钮文字视觉替换成“− / +”；
3. 打开浏览器可访问树；
4. 检查四个步进按钮的名称。

## 预期结果

视觉只显示“− / +”，按钮名称分别保持“角度减一档”“角度加一档”“力度减一档”
和“力度加一档”。

## 实际结果

Chrome 把 CSS 生成内容与 DOM 文字一起用于名称计算，按钮被读成“−角度减一档”
和“+角度加一档”等带重复方向提示的名称。

## 根因

样式实现假设伪元素只影响视觉，没有用真实可访问树验证生成内容是否参与名称计算。

## 解决方案

在创建步进按钮时显式写入完整 `aria-label`，让短符号负责视觉、中文动作负责可访问
名称；继续保留 DOM 文字作为无样式时的可用回退。
