# 连心四子棋：斜线测试的获胜格顺序写反

## 状态

已修复，2026-07-15。

## 复现条件

1. 用合法落子序列形成从左上到右下的四颗斜线；
2. 运行 `node --test experiences/versus/lan-connect-four/logic.test.js`；
3. reducer 返回 `[17, 23, 29, 35]`，测试却预期 `[35, 29, 23, 17]`。

## 原因

测试作者按落子形成过程手写了反向索引，没有遵循 reducer 已确定的扫描顺序。四个格子的集合相同，胜利检测结果正确，错误只存在于断言顺序。

## 解决方案

把测试预期改为按棋盘行列递增扫描得到的稳定顺序，同时保留另一条斜线测试，明确两种方向的输出契约。没有为了迎合错误断言修改生产逻辑。

- [x] 获胜格顺序稳定，可直接用于双端 UI 高亮
