# 爱心投石器：完整历史会在联合结果前泄露下一段秘密

- 状态：`fixed`
- 日期：2026-07-24
- 影响作品：`heart-catapult`
- 发现版本 / commit：`04d903f` 提交前候选

## 环境

- 操作系统：macOS
- 浏览器与版本：Chrome MCP 当前连接版本
- 启动等级与入口：A；`experiences/versus/heart-catapult/index.html`

## 复现步骤

1. 两位玩家依次锁定不同的角度和力度；
2. 进入第一段飞行揭晓；
3. 检查页面正文、飞行摘要和比分；
4. 再进入第二段飞行与联合结果。

## 预期结果

第一段飞行只显示第一位玩家的公开帧；第二段飞行才显示第二位玩家的公开帧；双方
参数和本轮得分只能在联合结果阶段一起出现，完整历史只在最终完成态可见。

## 实际结果

候选渲染器直接使用完整回合状态生成摘要，可能在第一段飞行时提前显示第二位玩家
已经锁定的参数，或在联合结果前显示本轮分数。

## 根因

状态机正确保存了完整秘密，但视图层没有把“已存储”与“当前阶段允许公开”分开，
把内部 history 当作了通用渲染数据源。

## 解决方案

- 所有阶段渲染只消费 `getPublicView()`；
- 飞行阶段只读取当前公开的 `flight` 帧与已允许显示的摘要；
- 联合结果出现前不渲染本轮分数；
- 完整 history 只在 `complete` 阶段进入公开投影。
