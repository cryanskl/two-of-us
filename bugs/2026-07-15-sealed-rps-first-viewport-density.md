# 密封猜拳：常见桌面与移动视口看不到完整出拳区

## 状态

已修复，2026-07-15。

## 复现条件

1. 在约 1269×830 的 Chrome 内容区打开已开始的比赛；
2. 保持页面位于顶部；
3. 首稿的大号封印占满首屏，三个出拳按钮全部落在折叠线以下；390×844 下页面还需额外滚动约 42px 才能看到完整提交区。

## 原因

首稿分别设计了标题、房间码、比分、封印和选择区，却没有把它们的累计垂直高度作为一个首屏预算验证。

## 解决方案

桌面端压缩标题、比分、封印和分隔间距，保留开放纸面布局；移动端只进一步缩小封印与纵向空白，不缩小选择按钮。最终 390×844 下三个选择按钮约为 117×116px。

## 回归验证

- [x] Chrome 设备模拟得到 `innerWidth = scrollWidth = 390`
- [x] 390×844 得到 `scrollHeight = 844`
- [x] 三个选择按钮均高 116px，提交按钮完整可见
- [x] 桌面首屏可同时看到比分、封印和出拳区
