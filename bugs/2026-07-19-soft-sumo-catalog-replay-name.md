# 软软相扑：目录合同使用不存在的重放 API 名

- 状态：`fixed`
- 日期：2026-07-19
- 影响范围：`shared/runtime/catalog.test.js`

## 现象

新增目录边界测试断言 `logic.js` 包含 `replaySoftSumo`，导致定向目录测试 75 项中 1 项失败；运行页面和逻辑测试不受影响。

## 根因

目录测试在集成时凭概念命名重放入口，没有对照已经冻结的逻辑导出表。真实公开 API 是单轮 `replayRound` 与整场 `replaySession`。

## 解决方案

把断言拆成 `replayRound` 和 `replaySession` 两项，并用实现导出行与逻辑测试中的调用交叉确认。

## 回归验证

- [x] 逻辑实现与 27 项逻辑测试使用相同名称
- [x] 目录定向测试 75 / 75 通过
- [x] 全仓测试 1280 / 1280 通过，49 个作品入口仓库验收通过
