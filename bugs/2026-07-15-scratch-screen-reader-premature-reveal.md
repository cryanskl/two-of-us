# 爱的刮刮卡：屏幕阅读器提前读出惊喜

## 状态

已修复，2026-07-15。

## 复现条件

1. 打开刮刮卡，但不刮开涂层；
2. 使用浏览器无障碍树或屏幕阅读器浏览页面；
3. 礼物标题和正文已经可以被读取。

## 原因

Canvas 只覆盖视觉画面，不会遮挡下方 DOM 的无障碍语义；同时体验区曾直接使用礼物标题作为可访问名称，等于在揭晓前主动暴露答案。

## 解决方案

体验区改用页面标题命名。仅在 JavaScript 成功初始化遮罩后，给礼物卡设置 `aria-hidden="true"`；揭晓时恢复礼物卡、隐藏已经失效的 Canvas，并通过独立的 `aria-live` 区域宣布完整惊喜。HTML 初始不写 `aria-hidden`，因此脚本失败时正文仍可作为降级内容读取。

- [x] 揭晓后 AX 树恢复礼物节点、移除 Canvas 节点，并包含完整 `aria-live` 文案
