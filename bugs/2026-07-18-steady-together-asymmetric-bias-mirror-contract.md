# 稳稳地，和你一起向前：非等幅坡势与严格镜像 Gate 矛盾

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：稳稳地，和你一起向前
- 发现版本 / commit：`e47e821 docs: specify steady together`

## 环境

- C06 P5 纯逻辑实现与测试阶段；
- 规格常量：第一段 bias `+72`，第二段 bias `-84`；
- 测试 Gate：左右输入、位置、速度、倾角与坡势反号后要求严格镜像。

## 复现

1. 取第一段某个公开物理状态，交换 left/right 输入与升力；
2. 将 tilt、ballPosition、ballVelocity 反号，并把路线移到第二段；
3. 各自派发一次生产 `TICK { ticks: 1 }`；
4. 比较新的升力、倾角、速度和位置。

## 预期

第二条轨迹的局部物理字段是第一条轨迹的严格镜像，测试可精确发现任何左右符号错误。

## 实际

第一段坡势为 `+72`，第二段为 `-84`，不是等幅反号。即使公式和左右交换完全正确，目标倾角也会相差 12 个单位，严格镜像断言必然失败。现有公开 API 又不允许测试注入自定义 bias，因此只能弱化为“方向相反”，失去精确 Gate。

## 根因

规格调参时分别选择了两个不同坡度，但测试章节仍沿用了“对称坡势”的假设；常量与可验证性质没有在同一次评审中核对。

## 修复

- 将第一段 bias 从 `+72` 改为 `+84`，与第二段 `-84` 严格对称；
- 明确镜像测试只比较同一局部物理状态下一 tick 的 lifts/tilt/ball position/velocity/stability 字段；
- routeProgress、checkpoint 和 reachedCheckpoints 属于不同旅程位置的元数据，不要求整体深相等；
- 要求生产 reducer 测试使用固定路线段，不开放测试专属物理入口。

## 回归

- [x] 规格常量成为 `+84/-84/0`；
- [x] 镜像 Gate 的比较字段和非比较元数据已写清；
- [ ] P5 逻辑测试按修复后的常量通过严格镜像断言；
- [ ] 生产 reducer 可达轨迹仍能通过三段路线。

后两项由 P5 独立提交完成后勾选或在其提交信息中引用本记录；本提交先修复权威规格，避免实现继续依据矛盾契约。

## 预防

任何声称交换、旋转或镜像不变性的测试，都要把对应配置常量列入同一代数检查。若参数刻意不对称，规格必须改写为可量化的非对称性质，不能保留无法满足的“严格等价”措辞。
