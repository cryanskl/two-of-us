# ImageGen 精灵图预览棋盘格并非真实透明通道

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：这一颗我先到
- 发现版本 / commit：视觉资产提交前

## 环境

- macOS；Codex 内置 OpenAI ImageGen；
- 检查工具：`sips` 与原尺寸图片查看；
- 目标资产：四宫格卫星、目标星与中央太阳 PNG。

## 复现步骤

1. 请求生成“透明背景 PNG 精灵图集”；
2. 在预览中看到透明棋盘格；
3. 执行 `sips -g format -g hasAlpha <asset.png>` 并查看原尺寸边缘。

## 预期结果

PNG 含真实 Alpha 通道，棋盘格只属于查看器预览背景，不进入像素。

## 实际结果

`sips` 返回 `format: png`、`hasAlpha: no`。棋盘格已经烘焙为普通 RGB 像素；若直接裁切，方形边界会进入午夜蓝舞台。

## 根因

生成提示中的“透明 PNG”没有形成真实 Alpha 通道，生成器把常见透明预览棋盘格作为画面内容绘制。仅看预览无法区分真实透明与假透明。

## 解决方案

拒绝第一版资产并重新生成统一 `#06131f` 深蓝哑光底图集。运行时使用同色舞台、四宫格裁切和径向 CSS mask 淡出边缘，同时提供 CSS 形状降级。最终资产继续是 RGB PNG，这是有意接受的约束，不再声称透明。

## 回归验证

- [x] 拒绝资产未进入仓库；
- [x] 最终图集为 1254×1254 RGB PNG 且无棋盘格；
- [x] 原尺寸检查确认四个对象与哑光底完整；
- [ ] 浏览器实现后验证裁切边界、mask 和资产失败降级。

## 后续资产 Gate

任何声称透明的生成图都必须同时通过：原尺寸查看、`sips -g hasAlpha` 元数据检查、页面实际底色合成。预览图不再作为透明度证据。
