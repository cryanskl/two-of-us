# 三枚以后，都是我们：来源声明标题未满足仓库机器 Gate

- 状态：`fixed`
- 日期：2026-07-19
- 影响作品：三枚以后，都是我们
- 发现方式：`npm run verify`

## 复现步骤

1. 保留作品 README 中的 `## 借鉴说明` 标题；
2. 运行 `npm run verify`。

## 预期结果

README 的借鉴章节被仓库统一验收器识别，详细声明仍链接到 `ATTRIBUTION.md`。

## 实际结果

验收器报告：`future-cookie-notes 的 README 缺少“借鉴与来源声明”`。章节内容存在，但标题没有满足精确合同。

## 根因

人工文案使用了近义标题，仓库校验器则把 `## 借鉴与来源声明` 作为所有作品一致的可机器检索入口。语义近似不等于结构合同一致。

## 解决方案

把 README 标题改为精确的 `## 借鉴与来源声明`，不改变来源内容或零复制边界。

- [x] 详细声明固定两个 MIT 项目、一个排除项和生成资产链
- [ ] 目录接入完成后重新运行 `npm run verify`
