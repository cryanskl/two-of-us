## 环境

- 操作系统：任意
- 浏览器与版本：任意现代浏览器，背景图集成功或失败均可观察

## 复现步骤

1. 打开 intro，观察 aimIndex 0 的玩家 0。
2. 对照逻辑方向表：index 0 为 `(4096, 0)`，即向右。
3. 观察 CSS `.aim-arrow` 的位置与箭头朝向。

## 预期结果

aimIndex 0 的图集缺口、CSS 冗余箭头和实际冲刺都朝右；旋转后继续同向。

## 实际结果

初版把 CSS 箭头放在棋子顶部并朝上，与图集向右缺口和逻辑向右冲刺相差 90°。图片加载失败或 forced-colors 下尤其容易误导玩家。

## 根因

视觉实现沿用了常见“角色头顶箭头”的定位，没有对照本作方向 LUT 的零角定义。

## 解决方案

把冗余箭头移到棋子右侧并用向右三角形绘制；forced-colors 同步改用系统文字色。旋转仍只施加在 token 外层，因此缺口、箭头与运动共享同一角度。
