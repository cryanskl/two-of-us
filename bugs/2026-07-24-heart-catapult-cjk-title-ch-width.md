# 爱心投石器：`ch` 宽度让桌面中文标题提前换行

- 状态：`fixed`
- 日期：2026-07-24
- 影响作品：`heart-catapult`
- 发现版本 / commit：`6fcfebf` 提交前视觉候选

## 环境

- 视口：1280 × 800 CSS px
- 启动等级与入口：A；`experiences/versus/heart-catapult/index.html`

## 复现步骤

1. 在 1280 × 800 视口进入秘密瞄准；
2. 检查产品标题换行和主动作底边；
3. 对照容器的实际可用宽度。

## 预期结果

中文产品标题在桌面自然单行，瞄准主动作完整留在视口内。

## 实际结果

`max-width: 18ch` 让中文标题提前断成两行，瞄准主动作底边落到 860.55px。

## 根因

`ch` 以西文数字“0”的宽度为基准，不能等价表示中文字符数量。

## 解决方案

移除产品标题的 `ch` 上限，让桌面按容器自然排版；手机仍由真实容器宽度换行。

## 回归验证

- [x] 1280px 桌面标题高度从两行缩为 59.8px
- [x] 瞄准主动作底边回到 698.75px
- [x] 390px 与 320px 标题仍自然换成两行
- [x] 全部视口无横向溢出
