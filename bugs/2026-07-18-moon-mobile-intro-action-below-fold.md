# 月相手机开场首屏没有可执行动作

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：把月亮拨回那一天 390×844 与 320×760 开场态
- 发现版本 / commit：`845d13e fix: fit moon phase unlock in desktop viewport`

## 现象

390×844 下完整月盘和三轴读数占满首屏，“开始校准”按钮顶部位于 y=909；intro 阶段所有 ± 和圆环都禁用，因此首屏看得到仪器却没有任何可执行动作。

## 根因

手机布局固定使用标题 → 仪器 → 线索 → 动作的顺序，却没有区分 intro 只有一个启动动作、calibrating 才需要线索和调节的任务阶段。

## 解决方案

仅在 `body[data-stage="intro"]` 的手机媒体查询中把 action grid area 放到标题之后；开始校准后恢复标题 → 仪器 → 线索 → 动作的原顺序。控件禁用、DOM 隐私和桌面布局不变。

## 回归验证

- [x] 390×844 开始按钮 y=239–301、完整月盘 y=327–693，均在首屏；
- [x] 320×760 无横向滚动，开始按钮 y=222–284、完整月盘 y=306–606；
- [x] 进入校准后动作区恢复到线索之后；
- [x] 两个手机视口的最小触控目标均为 48px。
