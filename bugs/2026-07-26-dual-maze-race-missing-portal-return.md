# Dual Maze Race 缺少返回作品集入口

## 现象

作品可以从根门户打开，但正常脚本页面没有可见的“返回作品集”入口。用户完成或中止
比赛后只能依赖浏览器后退；no-JS 场景也没有站内返回路径。

## 原因

生产 UI 分支只验证了游戏内阶段、输入、视口与降级，没有把“门户 → 体验 → 门户”
作为独立导航合同。共享 catalog 尚未接入时，这个缺口不会被项目核心测试发现。

## 解决

先在 UI 合同中锁定一个始终存在的原生链接和精确相对路径
`../../../index.html`，再在状态机之外加入可见入口。桌面低高度下链接绝对定位，不
挤占比赛纵向空间；600px 以下回到正常文档流，避免覆盖窄屏标题。链接不依赖
JavaScript，因此正常和 no-JS 场景都可使用。
