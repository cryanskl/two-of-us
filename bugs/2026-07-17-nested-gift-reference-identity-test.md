# 一层一层：无效操作测试比较了两份等值状态的引用

- 状态：`fixed`
- 日期：2026-07-17
- 影响作品：一层一层纯逻辑回归测试
- 发现版本 / commit：实现提交前工作区

## 环境

- Node.js 内置 test runner；
- 使用 `assert.strictEqual` 验证非法阶段操作保持原状态引用。

## 复现步骤

1. 分别调用两次测试辅助函数 `reachLayer(2)`；
2. 把第一次生成的状态传给 `knock()`；
3. 用 `strictEqual` 将返回值与第二次生成的状态比较。

## 预期结果

测试只验证 reducer 对传入状态保持原引用，不把两份结构相同但彼此独立的 fixture 当成同一对象。

## 实际结果

两份状态结构完全一致，但引用不同，`strictEqual` 失败，错误看起来像 reducer 复制了无效状态。

## 根因

引用恒等性是“输出是否等于本次输入”的契约，不是“两次工厂调用是否产生同一对象”的契约。测试在断言前重新创建了期望状态。

## 解决方案

先把辅助函数结果保存在局部变量中，再把同一变量同时传给 reducer 和 `strictEqual`。

## 回归验证

- [x] 非当前层 knock 返回本次传入状态的原引用；
- [x] 抽屉钳制后不再变化也返回本次传入状态的原引用；
- [x] 本项目 8 / 8 规则测试通过。
