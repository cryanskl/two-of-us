# 爱的刮刮卡：高 DPI 屏遮罩提示字号重复放大

## 状态

已修复，2026-07-15。

## 复现条件

1. 以相同 CSS 视口宽度分别在 DPR 1 与 DPR 2 环境打开刮刮卡；
2. 比较 Canvas 中“从这里慢慢刮开”的字号；
3. DPR 2 下提示文字明显偏大。

## 原因

Canvas 的 `width` 已经是 CSS 宽度乘 DPR 后的物理像素，旧实现使用这个物理宽度计算字号后又乘了一次 DPR。

## 解决方案

先用 `width / pixelRatio` 还原 CSS 宽度并计算 16–25 CSS 像素的字号，赋给 Canvas 字体时再乘一次 DPR。

## 回归验证

- [x] Chrome CDP 在相同窄屏下测得 DPR 1 为 `16px`、DPR 2 为 `32px`，等效均为 16 CSS px
- [x] DPR 2 的 Canvas 缓冲区按双倍像素创建，截图中的纹理、文字与笔画清晰
- [x] 390×844 下无横向溢出，Chrome 控制台无新增错误
