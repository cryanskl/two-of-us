# capsule-docking 1280px 标题异常换行

- 发现日期：2026-07-25
- 视口：Chrome 1280×800，100% zoom
- 影响：H1 被 `18ch` 限宽后在“推一点”中间断行，破坏概念稿锁定的完整标题节奏。

## 根因

CSS 的 `ch` 以当前字体数字 `0` 的宽度计算，不等于中文全角字宽。`18ch` 看似足够
容纳 18 个字符，实际只给中文标题留下约半数预期宽度。

## 修复

移除生产页 `.masthead h1` 的 `max-width: 18ch`，只在较窄的无脚本说明页保留该
阅读宽度。桌面标题改由既有 8/12 栅格自然约束，移动端继续由媒体查询控制字号。

## 回归

- 1280×800 Chrome 重新加载后，完整题名保持单行；
- 390×844 与 320×568 仍允许在标点边界自然换行；
- 项目 UI/逻辑测试、全仓测试与仓库 verify 在最终验收阶段统一重跑。
