# Bug：ImageGen 心形点阵不能作为离散坐标证据

- 状态：`fixed`
- 日期：2026-07-23
- 影响作品：等雪停下
- 发现版本 / commit：视觉提案提交前

## 环境

- 操作系统：macOS
- 浏览器与版本：不适用；按 PNG 原生尺寸目检
- 启动等级与入口：docs-only ImageGen 候选

## 复现步骤

1. 要求生成模型严格绘制规格中的 9×11、63 个 active 点心形。
2. 分别生成桌面、手机、横屏与无 Canvas 概念，并在 prompt 中重复矩阵。
3. 按原生尺寸查看 G4、G6、G7、G9，逐行观察较大的心形点阵。

## 预期结果

概念位图严格保持九行、每行十一列的坐标框，并只画出冻结矩阵中的 63 个点。

## 实际结果

生成模型会把点阵重排为更圆滑的装饰性心形。多次修订能改善构图，却仍不能
提供可逐点核对的 9×11/63 证明；G9 的“无 Canvas”面板也会自行增减行列。

## 根因

图像生成是视觉合成，不是确定性栅格渲染器。prompt 中的离散矩阵属于严格数据
约束，但模型会优先满足整体心形观感，因此像素结果不具备测试夹具的确定性。

## 解决方案

- 保留最终 PNG 作为材质、构图与响应式意图候选；
- 在生成台账和视觉提案中明确标注：位图不是坐标或点数证据；
- 生产只读取 `logic.js` 的冻结 target，以 HTML/CSS/Canvas 确定性绘制；
- 用 target 哈希、点数测试、CSS grid 审计和浏览器截图证明 9×11/63；
- 不再通过无限重抽追求位图数据精度，也不从 PNG 描点或 OCR。
