# 把这首转给你：移动端摇柄覆盖主按钮并产生窄屏溢出

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：把这首转给你
- 发现版本 / commit：`a56d798`

## 环境

- 操作系统：macOS；
- 浏览器：headed Chromium；
- 启动等级与入口：A 级 `file://`；
- 视口：390×844 与 320×760。

## 复现步骤

1. 在 390px 宽视口打开作品 intro；
2. 检查摇柄与“开始转动”的边界；
3. 缩到 320px 并比较 `scrollWidth` 与 `clientWidth`。

## 预期结果

摇柄落在控制区预留的右栏，不覆盖主动作；320px 无水平滚动。

## 实际结果

摇柄仍按桌面规则居中，与 390px 主按钮重叠约 42px；右对齐后，其旋钮视觉末端在 320px 又超出页面 6px。

## 根因

移动控制区已经用右侧 padding 给摇柄预留空间，但摇柄自身没有切换到右对齐；旋钮又允许超出圆形按钮边界，最窄视口缺少视觉安全区。

## 解决方案

在移动断点将摇柄 `align-self` 设为 `flex-end`，使其进入预留右栏；在 `≤340px` 断点增加 6px 右 margin，容纳旋钮视觉外沿。

## 回归验证

- [x] 390px：无横向滚动，摇柄与主按钮间隔 21px；
- [x] 320px：`scrollWidth = clientWidth = 320`，间隔 14px；
- [x] 320px 旋钮最右边界恰为 320px；
- [x] 主按钮保持 54px 高，摇柄保持 104px 触控直径；
- [x] 正常路径控制台 0 error / 0 warning。
