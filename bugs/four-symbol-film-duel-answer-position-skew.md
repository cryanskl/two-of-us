# 四符片名擂台：固定答案位置明显偏斜

## 现象

本作不在运行时洗牌，因此规格要求正确答案位置均匀。基线 32 张卡的正确选项
位置计数却是：

```text
第 1 / 2 / 3 / 4 项：11 / 12 / 8 / 1
A 方：             6 /  7 / 3 / 0
B 方：             5 /  5 / 5 / 1
```

A 方整个题库没有一题以第 4 项为正确答案。重复游玩后，玩家可以利用位置偏差，
而不是四符语义，提高猜中概率。

## 根因

内容校验覆盖了题数、配对、类型、难度、选项唯一性和提示排除项，但只证明
“每题有一个正确答案”，没有对固定展示位置建立分布不变量。

## 解决方案

配置构建阶段保留每个选项原有稳定 ID，只确定性调整显示顺序：

- 每个 `pack × side` 的四张题分别覆盖第 1、2、3、4 项；
- pack 与 side 使用轮换偏移，避免所有题包共享同一回合位置模式；
- 全局分布严格为 `8 / 8 / 8 / 8`；
- A、B 各自严格为 `4 / 4 / 4 / 4`；
- 正确标题、干扰项、提示排除项、题序和计分均不改变；
- 不增加运行时随机或跨局漂移。

## 验证

- 红灯：新增公平性用例后定向测试 `29/30`；
- 修复后定向测试 `30/30`；
- 8 个 `pack × side` 分组都通过 `[0,1,2,3]` 排序断言；
- `validateGameData(config)` 仍返回空错误数组；
- 128 个选项标题仍全局唯一。

## 影响范围

仅修改 `four-symbol-film-duel/config.js` 的内置选项展示顺序与对应测试。没有修改
题卡文字、答案语义、生产 UI、共享依赖、入口、launcher、catalog 或 Board。
