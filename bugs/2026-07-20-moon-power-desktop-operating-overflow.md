# 月面供电：1440×900 operating 多出 20px 纵向滚动

- 日期：2026-07-20
- 阶段：桌面浏览器响应式验收
- 影响：正常 operating 的页面高度为 920px，未满足桌面首屏完整 Gate
- 状态：已修复，未缩小字体或触控控件

## 复现

1. 视口设为 1440×900，进入第一班 operating；
2. 读取 `document.documentElement.scrollHeight`；
3. 结果为 920，横向宽度与所有元素边界正常。

## 根因

主体区已经以紧凑的 12px gap 排列，双席控件最小高度也必须保留 48px。额外 20px 来自 `.page-shell` 上 14px、下 18px 的视口边缘 padding；主体末尾本地说明的 bottom 为 902.18px，再加 18px 壳 padding 得到 920.18px。

## 修复

- `.page-shell` 上/下 padding 改为 8px/4px，精确回收 20px；
- 不改变标题字号、拓扑、状态区、双席面板或触控尺寸；
- 重新验证 1440×900 的 `scrollHeight <= innerHeight`；
- 复验 390×844 与 320×700 无横向溢出、目标仍至少 48px。

## 可复用结论

桌面“首屏完整”失败时，应先量每个区块与外壳的真实边界。若差值来自纯装饰性页边距，优先回收外壳空白，不要先缩字体、按钮或信息密度；后者会把一个 20px 布局问题扩散成可访问性问题。
