# 一起，把家搬进来：移动端主动作被压到 44px

- 状态：`fixed`
- 日期：2026-07-19
- 影响作品：一起，把家搬进来
- 发现版本 / commit：前端实现的提交前候选；修复随 `f98b9e6 feat: add moving home experience` 一并进入

## 环境

- 操作系统：任意
- 浏览器与版本：宽度不超过 760px 的现代浏览器
- 启动等级与入口：A 级，双击 `experiences/co-op/moving-home-together/index.html`

## 复现步骤

1. 以 390px 或 320px 宽度打开作品。
2. 检查移动断点下主动作按钮的计算高度。
3. 对照冻结规格的 48px 辅助动作最小高度与目录自动化 Gate。

## 预期结果

主动作和暂停等辅助入口在窄屏仍至少 48px 高；左右主控制盘仍至少 120×120px。

## 实际结果

前端候选在移动断点把主动作按钮的最小高度覆盖成 44px。控制盘尺寸正确，但按钮违反了已冻结的 48px 合同。

## 根因

为了收紧手机首屏的纵向预算，响应式规则误把可缩减的布局留白和不可缩减的触控目标一起压缩。

## 解决方案

只把移动断点中的主动作 `min-height` 从 44px 恢复为 48px，不改变字体、地图高度、控制盘尺寸或其他响应式规则；目录测试同时锁定 120px 主控制盘与 48px 辅助入口。

- [x] 两个方向盘保持至少 120×120px，主动作保持至少 48px
- [x] 目录测试 63 / 63、全仓测试 831 / 831 通过
