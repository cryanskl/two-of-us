# Bug：未来车票在概念原生尺寸下整体纵向下沉

- 状态：`fixed`
- 日期：2026-07-17
- 影响作品：未来车票
- 发现版本 / commit：`b58b4d3` 后的实现阶段，修复包含于 `5393fd0`

## 环境

- 操作系统：macOS
- 浏览器：Chrome 浏览器插件控制的真实页面
- 启动等级与入口：A 级，`experiences/surprises/future-ticket/index.html`
- 复现视口：1536×1024（概念原生尺寸）

## 复现步骤

1. 以 1536×1024 显式视口打开作品；
2. 保持 intro 或第一孔 choosing 状态；
3. 对比概念稿和浏览器截图中的标题、车票起始高度。

## 预期结果

导航下方紧接大标题，票据约从页面上部四分之一处开始，与概念的开放式顶部构图一致。

## 实际结果

首版 `.content` 使用 `align-self: center`。在 1269×774 下偏差不大，但 1536×1024 的第二网格行更高，内容整体被垂直居中，标题比概念低约 100px，顶部出现无意义空白。

## 根因

把“短视口首屏居中”的局部策略放在了所有桌面高度上。视口越高，剩余空间越多，网格居中造成的偏移越严重。

## 解决方案

- 桌面 `.content` 改为 `align-self: start`，并只保留 18px 固定上边距；
- 700px 以下移除该上边距，避免 320px 主动作被推到首屏之外；
- 重新保存四个显式视口截图。

- [x] 390×844 无溢出，主动作底部约 698px
