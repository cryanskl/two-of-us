# 企鹅冰原夺旗：静态钳制重新制造玩家重叠

## 环境

- 项目：`penguin-flag-duel`
- 分支：`codex/exp-penguin-flag-duel-core`
- 发现阶段：非视觉定点物理审查
- 基线实现：`4ea7dee`

## 复现

玩家半径为 `7168` 定点单位，因此无重叠中心距应为 `14336`。

### 靠左墙

1. 席 0 中心放在左墙合法边界 `x = 7168`；
2. 席 1 放在其右侧 50 像素处；
3. 调用 `resolvePlayerCollision`。

旧实现结果中心距为 `13569`，小于 `14336`。

### 靠冰岛

1. 席 0 放在上冰岛左侧合法相切位置；
2. 席 1 放在其左侧 50 像素处；
3. 调用 `resolvePlayerCollision`。

旧实现同样得到 `13569` 的中心距。

## 影响

旧实现先完成全部玩家碰撞 pass，最后才调用一次静态合法化。墙或冰岛把被推出的玩家钳回后，会重新制造玩家重叠，且已经没有后续 pass 继续修正。持旗掉落点、接触判定和下一 tick 的冲量可能因此出现不必要的偏差。

## 根因

玩家-玩家约束与玩家-静态约束是耦合的。把静态约束只放在循环外，破坏了每个 pass 的位置假设。

## 修复

每个玩家碰撞位置修正 pass 后，立即对两席执行世界边界和冰岛合法化，再进入下一 pass。四个 pass 后允许量化法线和整数舍入造成的极小剩余误差，但不会回到初始的大穿透。

## 回归

`logic.test.js` 新增“靠墙和靠冰岛夹碰时每个 pass 都保持静态合法并继续消解重叠”：

- 两种场景的静态接触玩家都留在合法边；
- 中心距严格大于初始 50 像素；
- 四个“半穿透修正” pass 后剩余穿透不超过 128 个定点单位（0.5 逻辑像素）；当前两种 fixture 的实测值均为 95。
