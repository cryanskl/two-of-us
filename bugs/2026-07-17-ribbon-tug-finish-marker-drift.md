# 心动拔河：规则越线时织带结未对齐终点针

## 状态

已修复，2026-07-17。

## 复现条件

1. 在桌面视口开始比赛；
2. 让左侧或右侧玩家把规则位置拉到 `-1` 或 `1`；
3. 对照织带结中心与对应终点针。

## 预期结果

规则位置达到胜利阈值时，织带结中心与该侧终点针重合；视觉越线与状态机结算表达同一事件。

## 实际结果

首版 JS 把织带结的旅行范围设为中心左右各 38%，CSS 却把终点针单独放在 meter 两端的 8.4%。桌面截图中左侧已经显示赢局，织带结仍与终点针相差约 42px。

## 根因

同一个规范化位置被两套互不相干的百分比常量映射：JS 管结的位置，CSS 管终点位置。两者各自看似合理，却没有共享同一个布局坐标来源。

## 解决方案

在控制层只定义一次 `KNOT_TRAVEL_PERCENT`，同时把它写入 meter 的 `--travel` CSS 变量；织带结位置和左右终点针都由这个值推导。`position = -1 / 1` 因而稳定映射到同一条视觉终点线。
