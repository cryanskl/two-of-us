# 星码解锁：轴向度数与方位字母重叠

- 状态：`fixed`
- 日期：2026-07-18
- 影响作品：星码解锁桌面与移动星盘
- 发现版本 / commit：功能提交前工作区

## 环境

- macOS 26.5.2；Google Chrome 150.0.7871.125；
- 1503×1046 与 390×844 视口均可观察。

## 复现步骤

1. 打开 `experiences/surprises/star-code-unlock/index.html`；
2. 查看圆盘最上、最右、最下、最左四个轴向标签；
3. 对照首张浏览器截图。

## 预期结果

四个主轴只显示 N/E/S/W，其他方向显示 30° 间隔的度数，不出现叠字。

## 实际结果

0°/90°/180°/270° 与 N/E/S/W 由两次 SVG 文本绘制占用相近坐标，缩放后形成难以辨认的青色/灰色叠字。

## 根因

刻度循环无条件创建 12 个度数标签，后续又单独创建四个主方位；数据层知道两者语义重复，渲染层却没有排除轴向刻度。

## 解决方案

在生成度数标签时只绘制 `degree % 90 !== 0` 的八个中间方位，四个主轴继续由 N/E/S/W 单独表达。刻度线本身仍保留，因此圆盘几何没有缺口。

## 回归验证

- [x] 1503×1046 的 `file://` Chrome 截图只显示 N/E/S/W 与八个非轴向度数；
- [x] 390px 长截图无重叠、无水平溢出；
- [x] 12 个星位编号、连线和星码词不受影响；
- [x] 页面控制台 0 error / 0 warning。
