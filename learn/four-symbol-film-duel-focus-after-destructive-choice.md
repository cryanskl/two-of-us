# 状态重建后不要把焦点还给已失效的控件

热座游戏常用“公共投影 → 整屏重建”确保秘密节点及时卸载。这个结构有利于隐私，
但 action 可能同时让触发控件失效：例如有限提示使用后按钮立刻 disabled，或一个
选项被排除。

可复用做法：

1. 每条会重建 DOM 的交互都明确决定焦点目的地；
2. 若原控件仍有效，可按稳定 ID 恢复；
3. 若原控件已被移除或 disabled，把焦点送到当前状态标题或第一项安全操作；
4. 状态标题用 `tabindex="-1"` 支持程序化聚焦，但不进入普通 Tab 顺序；
5. 回归不仅检查视觉状态，还检查 `document.activeElement`。

不要依赖浏览器在节点替换后的默认焦点行为，也不要为了保留焦点而把已经失效的
控件继续做成可操作状态。
