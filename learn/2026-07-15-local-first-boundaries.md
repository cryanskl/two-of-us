# 本地优先不等于单文件：A–D 的真实边界

## 1. 本机后端不是公网后端

Node、WebSocket、SQLite 或本地模型服务只要运行在用户自己的设备，并且断开公网后核心体验仍完整，就符合本地优先。真正需要排除的是不可替代的第三方账号、云数据库、公共房间和远程推理 API。

## 2. 构建方式不是启动等级

React、Vue、WASM 或模型项目可能在制作阶段需要复杂构建，但最终用户只关心安装后如何启动。提交构建产物并双击 HTML，最终可算 A；双击启动器进入 localhost，最终是 B。

## 3. C 级的权限陷阱

普通触摸、键盘和 WebSocket 可以通过局域网 HTTP 工作，但摄像头和麦克风的 `getUserMedia()` 要求安全上下文。主机自己的 `localhost` 通常符合要求，手机访问 `http://192.168.x.x` 通常不符合。

所以 C 级音视频项目需要可信的局域网 HTTPS、原生包装，或把摄像头集中到主机；不能只验证主机 localhost 后就宣称双手机可用。

## 4. WebRTC 仍然需要信令

WebRTC 建立连接后，媒体和 DataChannel 可以设备直连，但双方仍要交换 offer、answer 和 ICE candidate。项目必须记录信令走本机 WebSocket、手工二维码还是公共服务，也要单独记录 STUN/TURN 是否访问公网。

## 5. 框架许可证不覆盖模型和素材

Transformers.js、ONNX Runtime 或 ComfyUI 的许可证只覆盖运行时。具体模型权重、LoRA、声音、音乐、照片和字体都可能有不同条款。D 级作品必须使用 manifest 固定每个资源的来源、版本、哈希、大小与许可证。

## 验证清单

- 拔掉公网后重新启动，而不只是刷新已缓存页面；
- 检查 Network 面板是否仍访问 CDN、统计、公共 WebSocket、STUN/TURN 或模型站点；
- 从第二台真实设备测试 C 级加入；
- 分别测试主机和加入设备的相机、麦克风权限；
- 对每个运行时、模型和素材单独保留许可证证据。
