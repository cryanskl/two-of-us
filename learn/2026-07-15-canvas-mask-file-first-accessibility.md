# 本地优先 Canvas 遮罩的可访问与输入模型

## 适用范围

适用于刮刮卡、擦除涂层、雾面揭晓等“真实内容在 DOM、Canvas 负责视觉遮挡”的本地静态作品。

## 关键结论

### 视觉隐藏与语义隐藏必须同步

Canvas 覆盖层不会让下方 DOM 从无障碍树消失。若内容具有悬念，应在脚本成功创建遮罩后才给内容设置 `aria-hidden="true"`，揭晓时移除；不要把隐藏属性直接写死在 HTML，否则脚本失败时无障碍用户也得不到降级内容。揭晓结果应由独立的 `aria-live` 区域宣布，已经失效的 Canvas 则从无障碍树隐藏。

### Pointer Capture 不等于单指锁

`setPointerCapture()` 保证活动指针即使移出元素仍继续送达，但第二个指针仍会产生自己的事件。一次笔画要保存唯一的 `activePointerId`，并让 move、up、cancel、lost capture 都先核对所有权。只用共享的 `drawing` 与上一点会在双指下产生跨指线段。

### CSS 像素和物理像素只转换一次

Canvas 缓冲区按 `CSS 尺寸 × DPR` 创建。字体、笔刷等视觉尺寸先在 CSS 像素中决定，真正赋给 Canvas 上下文时再乘 DPR。归一化轨迹使用 0–1 坐标，尺寸变化时重绘遮罩并重放轨迹，既保持高分屏清晰度，也避免旋转屏幕后进度消失。

### 进度扫描放在笔画边界

透明面积抽样会读取 Canvas 像素，不适合每个 `pointermove` 都执行。移动阶段只擦除和记录线段，一笔结束时再抽样；百分比是揭晓阈值的近似反馈，不应包装成精确测量。

### `file://` 兼容性来自依赖边界

点开即用的 A 级作品使用相对路径普通脚本，不依赖 ES Modules、`fetch`、远程字体和 CDN。配置以普通全局对象加载，并通过 `textContent` 写入 DOM；这样私人文案不会被解释为 HTML，也不需要本地服务器。

## 验证方法

- 揭晓前后分别检查浏览器无障碍树；
- 用鼠标、单指和双指分别完成笔画；
- 在 DPR 1/2 与窄屏下比较提示字号、画笔和重绘结果；
- 捕获网络请求与控制台信息，确认没有公网依赖和运行错误；
- 关闭或阻断 JavaScript 后检查 HTML 中仍保留可读正文。
