# 有理墙面 TOI 与代数圆形 TOI 的精确排序

## 适用场景

固定步长、整数或定点坐标的连续碰撞检测中，同时存在：

- 移动点对轴对齐矩形；
- 移动点对圆；
- “命中与反射同刻时命中优先”一类严格事件规则；
- 禁止浮点 epsilon，且要求重放确定性。

## 实际问题

移动点对 AABB 的 slab 接触时间是两个整数之比，可以规范化为有理数
`{ num, den }`。移动点对圆的首次接触来自二次方程：

```text
a*t² + b*t + c = 0
t_hit = (-b - sqrt(b² - 4ac)) / (2a)
```

判别式通常不是完全平方，因此 `t_hit` 通常不是有理数。若把所有 TOI 强制保存
成分子 / 分母，只能引入量化；若改用浮点和 epsilon，则并列优先级、镜像和重放
可能在边界输入上分叉。

## 可复用解法

墙面事件仍保存规范有理时刻 `q = n / d`。圆命中候选只保存安全整数系数
`a, b, c`，不物化无理根。比较 `t_hit` 与 `q` 时令：

```text
D = b² - 4ac
K = 2an + bd
```

因为 `d > 0`：

- `K >= 0` 时，进入根一定早于 `q`；
- `K < 0` 时，比较 `D*d²` 与 `K²`：
  - `D*d² > K²`：进入根早于 `q`；
  - `D*d² = K²`：严格同刻；
  - `D*d² < K²`：进入根晚于 `q`。

判别式和平方比较可用瞬时 `BigInt`，但 `BigInt` 不应进入逻辑状态、JSON、重放
日志或状态哈希。若判别式恰为完全平方，才可把圆命中时刻约分成普通有理数。

## 边界约定

- 初始严格重叠是状态不变量错误，失败关闭；
- 初始位于表面且向内运动是零时刻接触；
- 初始位于表面且向外或沿切线运动不产生重复接触；
- 判别式为零的纯切线不算命中；
- 事件排序不使用浮点数或 epsilon；
- 圆命中后弹体立即销毁，因此无需把无理接触位置写回状态。

## 本项目验证

`ricochet-tank-duel` 的几何测试覆盖：

- 完全平方判别式得到规范有理 TOI；
- 非完全平方候选与 `1/2` 的严格比较；
- 高速穿越目标不漏检；
- 表面向外与纯切线无伪命中；
- AABB 有理并列和拐角双法向不依赖 epsilon。
