# 落笔前图状态：实现无向路径、借力与困死

## 适用范围

适用于纸上足球、点线占地、封路棋、铁路铺设、迷宫留痕和任何“边不能重复、到旧节点会改变回合规则”的本地静态游戏。

## 关键结论一：无向边必须先规范化再进入状态

玩家从 A 走到 B 后，B → A 不是另一条线。规则层应提供唯一的 `edgeKey(a,b)`：先按稳定坐标顺序排列两个端点，再序列化。合法移动、状态校验、重复检测与测试都只比较这个 key。

如果 UI 自己比较 `from/to`，很容易只挡住同向重走，却漏掉反向重走。SVG 线条只是状态的投影，不应成为占边真相。

## 关键结论二：借力判断读取落笔前快照

“目标是不是旧点”描述的是本次动作发生之前的拓扑。正确顺序是：

```text
1. 用旧 edges 判断目标是否已访问或属于边界
2. 计算 bounced
3. 追加本次新边
4. 根据 bounced 决定继续或换手
5. 仅在继续时检查是否自困
```

如果先追加边，每个新目标都会因为刚出现的来路而被误认成旧点，所有玩家都会无限续走。

## 关键结论三：边界是拓扑规则，不是伪造的玩家轨迹

边界点触发借力，但外边线不可沿线走。实现时可以把两件事分开：

- `wasVisitedBeforeMove()` 把边界点视为已访问；
- `getLegalMoves()` 排除沿外边线的候选；
- `state.edges` 只记录玩家真正画过的线。

这样回放、计数和 SVG 不会把场地边框误当成某位玩家的移动。

## 关键结论四：可达性不变量能删掉伪终局

普通落点之所以换手，是因为它在落笔前没有任何已走边。加入来路后，它仍然有其他出口；所以“普通换手后对手立刻无路可走”在经典球场上不可达。

困死只能在旧点或边界借力后发生：玩家仍拥有行动权，却发现所有其余边都已占用。先证明这种不变量，可以避免为不可能状态编写分支、文案和错误测试。

## 关键结论五：多种输入只做动作适配

SVG 点击、SVG Enter/Space、QWEADZXC 和九宫格按钮都应只解析出同一个目标坐标，然后调用同一 `move(state,target)`。输入层不判断换手、进球、乌龙、连续借力或比分。

渲染层同样只读 `getLegalMoves(state)` 创建目标。这样鼠标能走的点必然也是键盘和触控能走的点，且禁用态不会和规则漂移。

## 反例

- 用有方向的 `"ax,ay>bx,by"` 直接判断重复边；
- 先写入新边，再判断目标是否访问过；
- 把整圈边框预填进玩家 `edges`；
- 每次换手都做无出口判定，不区分普通落点与借力；
- 鼠标点击自己算一次合法性，方向盘再维护另一份规则。

## 验证方法

- 断言 `edgeKey(a,b) === edgeKey(b,a)`；
- 从中心检查八方向，再分别覆盖外边线、球门口和反向重复边；
- 构造回到旧点与落到边界的连续行动；
- 用真实可达角点路径证明自困，而不是直接伪造状态；
- 同一局分别用 SVG 点击、Enter、Space、方向键和按钮推进；
- 在 `file://` 与 HTTP 两种路径核对轨迹数、当前玩家、反馈和终局一致。
