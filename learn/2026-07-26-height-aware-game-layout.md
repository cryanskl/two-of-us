# 同屏游戏需要同时预算 viewport 宽度与高度

宽度断点无法完整描述同屏游戏布局。双棋盘、HUD 和固定控制区常会在“宽屏、低高度”
窗口中发生首屏裁切，即使没有横向溢出。

可复用做法：

1. 先列出不可缩小项，例如 52px 触控目标、双方同时可见的棋盘和共享主动作；
2. 把装饰、副标题和辅助摘要列为可压缩项；
3. 除 `max-width` 外增加 `max-height` Gate；
4. 正方形主舞台使用 `calc(100vh - 固定垂直预算)` 限制，而不是只写绝对
   `max-width`；
5. 通过真实浏览器截图检查“全部关键交互是否进入首屏”，不能只断言
   `scrollWidth === innerWidth`；
6. 不用缩小触控目标或隐藏一位玩家来修复高度问题。

这个方法适用于双棋盘、节奏轨道、双人控制台和任何需要在首屏保留多人控制的本地
互动页面。
