# 移动游戏 HUD：压缩布局，不删除语义

Canvas 游戏在窄屏上最容易被先删掉的是“详细 HUD”。如果这些字段承担了方向、
冷却、威胁或阵营的文本替代，它们不是装饰；`display: none` 不但让视觉用户失去
信息，也会让辅助技术失去整块语义。

更稳妥的顺序是：

1. 先把状态轨从左右栏回流到赛场下方；
2. 把字段改成双列或紧凑网格；
3. 缩短间距、边框和字号，但保留可读性；
4. 只有纯装饰图层才允许隐藏；
5. 用静态契约禁止关键语义容器在窄屏媒体查询中变成 `display: none`，再用真实
   320 px 浏览器检查滚动、遮挡与字号。

这条原则同样适用于比分、计时、回合、资源上限和危险提示。
