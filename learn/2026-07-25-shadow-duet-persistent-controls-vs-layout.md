# 稳定 DOM 身份不等于所有阶段都要占位

双人 Pointer/键盘作品常要求按钮节点贯穿全流程，避免重建节点导致 capture、焦点或
迟到事件落到旧对象上。这里真正需要保持的是 DOM 身份和监听关系，不是每个阶段的
视觉占位。

可复用做法：

1. 把 fieldset 与按钮写进静态 HTML，不在 render 中替换；
2. 非交互阶段设置真实 `disabled`；
3. 只有完全结束、且控件不再传达有效状态时，使用 phase CSS 隐藏，但不删除节点；
4. 用浏览器同时检查节点引用是否稳定、终局顺序是否正确，以及桌面首屏是否容得下
   主动作。

这样能同时满足输入会话安全、阶段信息密度和终局视觉叙事。
