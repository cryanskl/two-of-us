# no-JS 降级要移除假交互，不只是补一句提示

对纯前端游戏来说，`<noscript>` 文案存在不等于无脚本降级完成。若原始 HTML
已经带着按钮、计时、比分和阶段面板，禁用脚本后它们仍会被浏览器渲染，只是失去
监听器；用户看到的是“坏掉的游戏”，不是诚实的静态说明。

可复用的最低合同是：

1. 在 head 的 `<noscript><style>` 中隐藏整个交互应用根；
2. 在应用根外提供独立静态面板；
3. 静态面板只保留标题、启用要求、隐私/联网边界和可靠返回入口；
4. 用契约测试同时锁定“交互根被隐藏”和“静态入口存在”；
5. 最终用真实禁用 JavaScript 的浏览器确认按钮、Canvas 与 dialog 都不可见。

这样不会影响正常脚本模式，也不需要运行时检测或第二套 JavaScript 状态。
