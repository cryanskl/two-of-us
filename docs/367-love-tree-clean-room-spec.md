# Love Tree clean-room 重制：产品与技术规格

> 状态：视觉确认前的候选规格
> 依赖方向：原生 HTML / CSS / JavaScript，零运行时第三方依赖
> 生产代码状态：未开始
> 前置方向：`docs/366-love-tree-clean-room-brainstorm.md`

## 1. 目标

将 Love Tree 重制为一个本地点开即用、手机与桌面都完整可玩的单页惊喜：

1. 收礼者进入页面后，只看到一颗明确可触发的心和一句邀请；
2. 点击或键盘触发后，树从地面连续长出；
3. 枝叶与花瓣逐步构成心形花冠；
4. 盛放完成后，个性化情书与相爱时长出现；
5. 整个流程离线可用、默认静音、可重播、支持低动态模式。

## 2. 成功标准

### 产品成功

- 第一次进入页面的用户无需说明即可知道要点击哪里；
- 点击后 100 ms 内出现视觉反馈；
- 用户能清楚感知“生长 → 盛放 → 揭晓”而不是三张画面切换；
- 情书是最终阅读焦点，树不会遮挡正文；
- 桌面和 360 px 宽手机均能完成全流程；
- 重播不会刷新页面，也不会叠加旧粒子、计时器或声音实例。

### 工程成功

- 入口继续为 `experiences/surprises/love-tree/index.html`；
- 直接双击 `index.html` 可运行，不要求本地服务器；
- 运行时不访问网络、不读取 CDN、不调用外部 API；
- 不使用 npm 运行时依赖、jQuery、Jscex 或旧版业务文件；
- 页面加载后没有阻断性控制台错误；
- `prefers-reduced-motion`、键盘操作和可读对比度通过人工验收；
- 旧授权不清晰文件仅在用户批准实现后按计划移除，且删除动作独立提交。

## 3. 非目标

- 不做在线编辑器、云端保存、分享链接或二维码；
- 不做多人实时互动；
- 不做照片上传；
- 不做账户、密码或隐私数据收集；
- 不做复杂背景音乐播放器；
- 不复刻旧版像素级画面或动画；
- 不引入主题切换、成就、统计等额外功能。

## 4. 受众与使用场景

### 赠送者

- 在代码顶部或单一配置文件中修改姓名、称呼、纪念日起点和情书；
- 将整个文件夹发送给对象；
- 不需要安装 Node、Python 或浏览器扩展。

### 收礼者

- 双击打开页面；
- 点击一次即可观看；
- 可选择开启轻微的本地合成声音；
- 看完后可点击“再看一次”。

## 5. 页面结构

页面只有一个沉浸式舞台，不设置站点导航。

```text
body
└─ main.love-tree
   ├─ button.sound-toggle
   ├─ section.intro
   │  ├─ h1
   │  ├─ button.heart-trigger
   │  └─ p.status
   ├─ figure.tree-stage
   │  ├─ canvas 或内联 svg
   │  └─ figcaption（无障碍描述）
   ├─ article.letter
   │  ├─ h2
   │  ├─ p × n
   │  ├─ time.elapsed
   │  └─ button.replay
   └─ div.live-region
```

要求：

- `heart-trigger` 必须是真实 `<button>`；
- 树的可视区域不可承担唯一交互；
- 情书正文必须是可选择、可缩放、可被辅助技术读取的 HTML 文本；
- Canvas / SVG 只负责视觉，不承载文案；
- 声音开关为次要控件，默认状态为关。

## 6. 内容配置

建议后续实现一个静态、易编辑的配置对象：

```js
const LOVE_TREE_CONFIG = {
  recipient: "给你",
  title: "有一棵树，想长给你看",
  letter: [
    "从遇见你的那天起，平常的日子也有了光。",
    "愿以后的四季，我们仍然一起慢慢走。"
  ],
  since: "2020-01-01T00:00:00+08:00",
  locale: "zh-CN"
};
```

约束：

- 示例值必须明显可替换，不把真实个人信息写入仓库；
- `since` 使用带时区的 ISO 8601 字符串，避免不同机器解释不同；
- 无效日期不阻断情书揭晓，计时区域显示友好提示；
- 文案通过 `textContent` 或静态 DOM 渲染，不将配置作为 HTML 注入；
- 本阶段不决定配置是内嵌在 `index.html` 还是放入独立本地文件，实施时以“双击可用”为先。

## 7. 状态机

唯一可信状态源：

| 状态 | 含义 | 可用动作 | 下一个状态 |
|---|---|---|---|
| `idle` | 等待用户触发 | 开始、切换声音 | `growing` |
| `growing` | 树干和枝杈生成 | 切换声音 | `blooming` |
| `blooming` | 叶片和花瓣形成花冠 | 切换声音 | `revealing` |
| `revealing` | 信件和计时进入 | 切换声音 | `complete` |
| `complete` | 可阅读最终画面 | 重播、切换声音 | `idle` |

### 状态约束

- 开始按钮在 `idle` 之外不可重复触发；
- 每次进入 `growing` 前清除上一轮动画帧、粒子、计时与声音节点；
- 状态转换由一个显式控制器完成，不由多个独立 `setTimeout` 隐式竞争；
- 页面失焦后恢复时不能跳出非法状态；
- 低动态模式保留同样状态语义，只缩短或简化视觉过渡；
- 重播回到初始构图，但保留用户的声音开关选择。

## 8. 动画规格

### 8.1 邀请

- 心形按钮处于画面中心附近；
- 微弱呼吸幅度不超过 4%，周期不短于 2.4 秒；
- 悬停、焦点和按下都有明确反馈；
- 低动态模式取消呼吸，仅保留静态高亮。

### 8.2 生长

- 总时长目标：4.5–5.5 秒；
- 前 100 ms 出现地面光点或第一段树芽；
- 树干从下向上生长，随后 2–4 组主枝分叉；
- 分支算法使用新写的确定性伪随机参数，允许同一轮稳定重现；
- 不读取、改写或近似旧版分支算法和参数；
- 树的轮廓在小屏幕不得超出安全区。

### 8.3 盛放

- 总时长目标：2.5–3.5 秒；
- 花瓣从枝梢附近出现，再向心形轮廓填充；
- 心形只需在整体上可读，不做几何完美对称；
- 粒子数量按视口面积设置上限；
- 低性能设备允许降低花瓣数量，但不能省略“盛放”状态。

### 8.4 揭晓

- 总时长目标：1.5–2.2 秒；
- 信纸与树根区域形成连续场景，不弹出模态框；
- 标题、正文、计时按顺序进入；
- 不使用逐字打印整篇长文，避免阅读等待；可使用一行轻微书写感过渡；
- 页面焦点不自动跳到正文；
- 完成后 `live-region` 用一句简短文本宣布“树已经盛开，情书已出现”。

## 9. 计时规格

- 显示完整天数，以及小时、分钟、秒；
- 计时每秒更新一次；
- 页面不可见时可暂停渲染更新，恢复时按当前时间重新计算；
- 不累计 `setInterval` 漂移；
- 起点晚于当前时间时显示“故事将在 … 开始”，不出现负数；
- 无效日期显示“请设置有效的纪念日起点”，不抛异常；
- 计时不是核心动画的阻塞条件。

## 10. 声音规格

默认无声。

若用户主动开启：

- 只使用浏览器原生 Web Audio API；
- 不加载音频文件；
- 第一次明确点击声音开关后才创建或恢复 `AudioContext`；
- 声音由极轻的本地合成音组成，例如生长时的低音脉冲、盛放时的三音和弦；
- 音量有保守上限，关闭后快速淡出；
- 不自动播放，不保存跨页面偏好；
- Web Audio 不可用时隐藏或禁用声音开关，不影响视觉体验。

## 11. 响应式规格

### 桌面：`>= 900 px`

- 单屏完成主要体验；
- 树冠位于视觉中心偏上；
- 信件在树下或树根左下方展开，但不得回到旧版固定“左文右树”复刻；
- 内容最大宽度约 1180 px，使用流式布局。

### 平板：`600–899 px`

- 树冠缩小，信件保持 44–68 字符的舒适行长；
- 控件与安全区保持至少 16 px 间距。

### 手机：`< 600 px`

- 初始和生长阶段以一屏为目标；
- 揭晓后允许纵向滚动阅读；
- 触控目标不小于 44 × 44 CSS px；
- 360 × 640 CSS px 下主按钮、树冠、信件标题均可达；
- 横屏仍可完成操作，不要求单屏展示完整信件。

## 12. 无障碍规格

- 键盘可依次到达声音开关、开始按钮、重播按钮；
- 焦点样式清晰，不仅依赖颜色；
- 开始按钮具备可理解的可访问名称；
- 状态提示使用 `aria-live="polite"`，不逐帧播报；
- 装饰花瓣从辅助技术树中隐藏；
- 正文与背景满足 WCAG AA 对比度；
- 200% 页面缩放下不出现横向滚动；
- 支持 `prefers-reduced-motion`；
- 不用音效作为唯一反馈。

## 13. 性能与兼容性

- 首屏本地资源总量目标不超过 500 KB；若视觉确认后确需位图纹理，单独评估；
- 除可选纹理外，主要视觉优先 CSS、Canvas 或内联 SVG；
- 动画使用 `requestAnimationFrame`；
- 设备像素比做上限裁剪，避免高 DPR 画布内存失控；
- 页面卸载或重播时取消动画帧与计时器；
- 目标浏览器：当前版本 Chrome、Safari、Firefox、Edge；
- 直接 `file://` 环境必须可运行，不依赖 `fetch()` 读取本地 JSON。
