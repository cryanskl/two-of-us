# 四符片名擂台：首版内容与字形审计

> 审计日期：2026-07-25
> 审计范围：`experiences/versus/four-symbol-film-duel/config.js`
> 结论：**静态内容 Gate 通过；真实跨设备字形观察与双人盲测留给 UI 验收阶段**

## 1. 审计对象

首版数据包含：

- 48 个闭合 Emoji token；
- 4 个完整题包；
- 16 个 A/B 公平配对；
- 32 张原创虚构片名卡；
- 每卡 4 枚符号、4 个原创选项、1 个确定性聚光灯排除项；
- 每个题包双方完全相同的难度序列 `1 / 1 / 2 / 3`；
- 每个题包双方完全相同的类型序列 `城市 / 动物 / 奇幻 / 太空`。

数据校验只把 `authorship: "original-project-copy"` 且 `reviewed: true` 的卡
视作可用内容。此标记表示已完成本文件中的静态权利和指向审计，不替代后续
真实双人盲测。

## 2. 创作来源

所有微型故事、答案、干扰项、内部解释、题包名、中文 token 标签和概念词均在
本仓库中独立创作。创作时没有打开或改写第三方电影题库、影片数据库、剧情
简介、台词集、海报集、Emoji 素材包或开源猜电影项目。

题面不包含：

- 真实影片或系列片名；
- 真实演员、导演、人物或角色名；
- 真实对白、剧情梗概或经典场景复述；
- 工作室、影院、流媒体或游戏品牌；
- 海报、剧照、Logo、配乐、音效和视频；
- 厂商 Emoji 图片或第三方 Emoji 字体；
- Unicode/CLDR 数据文件或注释翻译。

## 3. 名称近似审计

审计先按精确答案短语检查，再按显著名词组合检查。对 32 个答案逐项执行：

1. 与题库内其他 127 个选项做 NFC 规范化后的精确重复检查；
2. 检查是否包含已知真实人物、角色、影视系列、工作室或平台名称；
3. 检查是否由著名影片标题只替换一个常用词得到；
4. 检查完整标题是否像品牌、系列名或已有商业服务；
5. 对容易形成固定表达的答案再做公开网页精确短语检索；
6. 若出现普通语句的零散用法，只要不指向影视作品或品牌，不视为冲突；
7. 若出现影视或品牌高度近似，必须改名后重新审计。

2026-07-25 将 32 个正式答案分为四组，使用带引号的完整中文短语做公开网页
精确检索，四组均返回零条索引结果。这个结果只表示在当次公开索引中未发现
精确重名，不代表穷尽全球作品、未索引内容、其他语言译名或未来新增名称；
因此仍保留人工影视指向检查与后续发布前复核。

## 4. 四符真实影视指向审计

每卡检查四符组合是否能直接复原某个广为人知的真实影片、角色或经典场景。
本轮审计采用以下停止条件：

- 组合包含可唯一识别的真实角色与专属道具；
- 四符能按顺序复述一部真实影片的核心剧情；
- 答案或干扰项使玩家只能依赖真实影视知识判断；
- 去掉原创选项后，题面仍强烈指向单一真实作品。

32 张卡均围绕日常物件、动物、天气、城市小事和抽象太空旅程组合。没有角色
名称、人物造型、专属道具或真实剧情关系。个别单独 token（如月亮、火箭、
列车）会出现在大量文化作品中，但其四符组合及配套答案没有唯一真实作品指向。

## 5. Token 与平台字形风险审计

### 5.1 数据级检查

闭合表遵守：

- 不使用旗帜和地区标志；
- 不使用肤色修饰符；
- 不使用家庭、职业或性别 ZWJ 组合；
- 不使用私用区字符；
- 不把颜色或朝向作为唯一答案线索；
- 不使用图片 URL、文件路径、HTML 或厂商导出字形；
- 中文标签只写稳定物体语义，不写题目解释。

表中少量字符带 VS16，以请求 Emoji 呈现；这不是厂商图片资源。数据校验会拒绝
ZWJ、肤色修饰符、旗帜区域指示符、标签字符和私用区码点。

### 5.2 人工字形风险分级

| 风险 | Token | 处理 |
|---|---|---|
| 低 | 日月星、雨、动植物、房屋、交通、常见物件 | 保留；含义不依赖厂商细节 |
| 中 | `🪿` 鹅、`🫖` 茶壶、`🪞` 镜子、`🪜` 梯子 | 保留中文等价标签；UI 验收时重点跨平台观察 |
| 中 | `☄️` 彗星、`🛰️` 卫星 | 保留；不依赖颜色和方向，重点检查 VS16 呈现 |
| 高 | 旗帜、肤色、家庭/职业 ZWJ、平台贴纸 | 未纳入闭合表 |

同一局双方共享同一设备与浏览器，因此字形差异不会造成局内资源不对称；但
不同设备可能出现语义不清或空框。后续 UI 必须让每个 glyph 的原创中文标签
保留在可访问树中，并提供对双方同时生效的可见文字等价模式。

### 5.3 尚未冒充完成的验证

当前阶段没有 UI，也没有在 Safari、Windows 或 Android 实机逐个观察 48 个
字形，因此不把“数据级低风险”写成“跨平台实机已通过”。正式安装前仍需：

- macOS Chrome 与 Safari；
- 至少一种非 Apple 平台；
- 默认符号模式与可见文字模式；
- 屏幕阅读器朗读顺序；
- 两位未参与创作的玩家对 16 对卡做盲测。

## 6. 公平性静态审计

每个题包固定四组 A/B：

| Pair | 难度 | 类型 |
|---|---:|---|
| 1 | 1 | 城市 |
| 2 | 1 | 动物 |
| 3 | 2 | 奇幻 |
| 4 | 3 | 太空 |

双方都获得 4 题、2 枚聚光灯和相同计分上限。选项数、符号数和提示能力完全
一致；聚光灯始终删除一个固定错误项。这里证明的是结构配平，语义难度仍需
盲测，不能仅由字段相等推出。
