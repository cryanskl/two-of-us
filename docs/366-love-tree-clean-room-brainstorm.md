# Love Tree clean-room 重制：Brainstorm

> 阶段：视觉与产品方向探索
> 范围：仅定义体验，不修改 `experiences/surprises/love-tree/`
> 结论：等待用户确认视觉概念后，才进入实现

## 1. 为什么重制

Love Tree 的核心惊喜仍然成立：收礼者轻触一颗心，看见一棵树在眼前长成、开出心形花冠，最后读到一封信与两个人共同走过的时间。

现有版本可运行，但它绑定了来源和授权不清晰的历史代码、jQuery / Jscex、商业歌曲文件、旧式固定宽度布局，以及一份原始压缩包。继续在旧实现上修补，会让来源边界、移动端适配和长期维护始终不清楚。因此本次采用 clean-room 重制：

- 只保留可观察的体验目标，不复制旧源码、动画参数、绘制算法、CSS、素材或文案；
- 从零设计原生 HTML / CSS / JavaScript 的状态机和生成式树木动画；
- 默认静音；未来如启用声音，只使用用户手势后启动的本地 Web Audio 合成；
- 旧实现的删除、替换和归档清理只写入后续计划，本阶段不执行。

## 3. 必须保留的体验承诺

一句话承诺：

> 轻触一颗心，让一棵只为对方生长的树开花，再把想说的话交给对方。

不可丢失的四个节拍：

1. **邀请**：安静、克制，画面只有一颗等待触碰的心。
2. **生长**：树干先出现，枝杈向两侧展开，反馈连续且可感知。
3. **盛放**：花朵逐渐聚成松弛、自然的心形树冠，而不是瞬间切换。
4. **揭晓**：个性化情书与共同时间出现；用户可重播，但不会误触跳过。

## 4. 三个视觉方向

### A. 暮蓝纸雕花园（推荐）

深暮蓝到墨靛的夜色背景，中央树木像被月光照亮的纸雕。花冠由珊瑚粉、莓果红、暖杏色的小叶片和心形花瓣组成，地面只有一圈柔和光晕。情书在盛放后以半透明暖纸页从树下舒展开。

优点：

- 由“夜色”到“盛放”的明暗变化天然适合惊喜节奏；
- 与旧版米白底、多色心形树形成清晰视觉区隔；
- 桌面端有沉浸感，移动端也能保持单一视觉中心；
- 可用 CSS 渐变、Canvas / SVG 和少量程序化粒子原生实现。

风险：

- 深色背景下要严格控制文字对比度和花冠饱和度；
- 不能把纸页做成通用浮层卡片，必须与树根和地面光晕形成连续场景。

### B. 晨雾植物标本

暖象牙纸背景，树木像植物标本与铅笔速写，花朵为干燥玫瑰色。情书排版接近一本被翻开的私人日记。

优点：

- 温柔、阅读友好；
- 对长文案和纪念日信息很包容；
- 打印感和手作感强。

风险：

- 容易接近旧版浅色背景与左文右树结构；
- 生长过程的戏剧性较弱。

### C. 午夜天文花园

树冠由星点和花瓣共同组成，枝杈像星座连线，最终在夜空中构成心形星云，情书像一封被星光照亮的信。

优点：

- 视觉记忆点强；
- 很适合粒子动画与环境音合成；
- 可将纪念日映射为星图细节。

风险：

- 容易喧宾夺主，使“树长成一封信”的主体变成泛星空主题；
- 粒子数量、性能与低动态模式需要更多工程控制。

## 5. 推荐方向：暮蓝纸雕花园

选择 A，原因不是“更华丽”，而是它最准确地服务四个体验节拍：

- 初始夜幕留白足够，心形入口能成为唯一焦点；
- 生长时，暖色枝叶在暗背景上有清晰的逐帧可见性；
- 心形花冠完成时能形成真正的“盛放”高潮；
- 暖纸页与夜色形成安静的阅读收束。

### 视觉原则

- **一个舞台**：无顶部导航、无卡片网格、无功能面板。
- **一个主动作**：入口只需要“轻触这颗心”。
- **有机而不甜腻**：使用莓红、暖杏与纸白，不使用大面积荧光粉。
- **细节来自自然**：枝杈不完全对称，花瓣密度有呼吸区。
- **文案由代码渲染**：生成概念图中的文字只表达位置和层级，生产实现不把文字烘焙进图片。

### 建议色板

| 角色 | 色值 | 用途 |
|---|---:|---|
| 夜幕 | `#0D1530` | 主背景 |
| 靛蓝 | `#18244A` | 空间层次 |
| 月白 | `#F5EFE5` | 正文与信纸 |
| 珊瑚 | `#FF7A78` | 主要花瓣 |
| 莓红 | `#C93F68` | 心形与强调 |
| 暖杏 | `#F2B48D` | 花冠高光 |
| 枝褐 | `#3B2928` | 树干与枝杈 |
| 微光 | `#E9C9A5` | 地面光晕与粒子 |

### 字体方向

- 标题和情书：系统衬线字体栈，优先中文宋体气质；
- 操作与计时：系统无衬线字体栈；
- 不引入需要联网的字体，不依赖外部 CDN。

### 桌面

### 移动端

```text
┌──────────────────────┐
│              声音：关│
│                      │
│  有一棵树，想长给你看 │
│                      │
│          ♥           │
│      轻触这颗心       │
│                      │
│    （树冠居中生长）    │
│                      │
│  （信在树下纵向展开）  │
└──────────────────────┘
```

移动端不是桌面画面的缩小版：树冠保持视觉中心，情书在盛放后占据可读宽度，允许自然向下滚动；计时拆成两行，避免横向挤压。

## 7. 体验文案候选

初始：

- 标题：`有一棵树，想长给你看`
- 主动作：`轻触这颗心`
- 辅助说明：`声音默认关闭`

生长：

- 状态提示：`它正在把想说的话，长成枝叶`

揭晓：

- 信件开头：`给你：`
- 示例正文：`从遇见你的那天起，平常的日子也有了光。`
- 计时：`我们已经一起走过 2,345 天 06:18:42`
- 次动作：`再看一次`

所有收礼文案、姓名和起始日期都应由后续配置层提供；示例只用于视觉层级，不写死成默认关系。

## 8. 动效与无障碍方向

- 总体验建议 9–12 秒：邀请响应立即发生，主生长约 5 秒，盛放约 3 秒，信件约 2 秒。
- 首次点击后立即出现枝干反馈，避免用户误以为未触发。
- 花瓣采用分区生成，不使用整张预渲染树冠的透明度切换。
- `prefers-reduced-motion: reduce` 下改为 3 个短淡入阶段，不做大量粒子。
- 树木动画区域提供文本替代；按钮是真实按钮，不依赖 Canvas 点击坐标。
- 颜色不是唯一状态信号；状态提示同步更新。
- 声音默认为关闭，且任何声音都只能由明确的用户操作开启。

## 9. 借鉴声明与非复制边界

本项目的体验命题受到仓库历史 Love Tree 页面“点击后树木生长、心形花冠盛放、随后展示情书与共同时间”这一可观察交互的启发。历史页面在 README 中记录为迁移自 `cryanskl/html_lovetree`，未找到可确认的上游许可证；因此新版本不会复制、改写或派生其源码、样式、绘图参数、素材、音乐、文案或压缩包内容。

若后续实现参考新的开源项目、算法文章或公共示例，必须在实现前核对许可证，并在 `ATTRIBUTION.md` 中逐项记录：

- 项目名称、作者与原始链接；
- 许可证名称与许可证链接；
- 具体借鉴了什么；
- 哪些内容没有复制；
- 本仓库做了哪些独立改写。

当前 brainstorm 阶段没有选用任何新的开源实现。

## 11. 需要用户确认的问题

在进入实现前，请用户明确确认：

1. 是否接受推荐的“暮蓝纸雕花园”方向？

4. 移动端揭晓后允许自然向下滚动，是否可以接受？
