# C 级局域网你画我猜规格

## 1. Brainstorm 结论

仓库已有 A 级“同机你画我猜”，C 级版本不应只是把同一页面打开两次，而要利用双设备真正分离秘密题目与猜词界面。

首批范围经过以下取舍：

| 方案 | 价值 | 复杂度与风险 | 本批决定 |
| --- | --- | --- | --- |
| 整张 Canvas 持续传图 | 实现直观 | 带宽大、移动端卡顿、不同尺寸失真 | 不采用 |
| 归一化笔迹增量同步 | 流量小、不同屏幕可重绘 | 要处理 pointer 与清空事件 | 采用 |
| 客户端各自判断猜对 | 代码少 | 并发时比分分叉，答案可能泄露 | 不采用 |
| 主机保存答案并权威计分 | 两端结果一致 | 主机断开需重置比赛 | 采用 |
| AI 自动识图提示 | 惊喜感强 | 引入模型、D 级能力和许可问题 | 后续可选增强 |
| 语音聊天 | 更接近线上游戏 | 麦克风、HTTPS 与 WebRTC 超出本批 | 不采用 |

## 2. 用户流程

1. 主机通过根启动器打开本地门户；
2. 两台设备打开“局域网你画我猜”；
3. 一方创建房间，另一方输入 5 位短码加入；
4. 主机开始 4 回合比赛；
5. 每轮自动轮换画家，只有画家设备收到题目；
6. 画家在本机 Canvas 作画，线段实时出现在猜词端；
7. 猜词端提交答案，主机规范化比较并广播结果；
8. 45 秒到时或猜对后进入下一轮，4 回合后展示共同得分；
9. 主机可重新比赛。

## 3. 状态与权威边界

主机保存完整状态：

```text
members, phase, roundIndex, score, drawerId,
answer, words, deadline, version
```

另一端只接收公开状态：

```text
phase, roundIndex, totalRounds, score, drawerId,
secondsPerRound, version
```

答案只通过定向消息发送给当轮画家；回合结束后才作为结果公开。`version` 单调增加，客户端忽略旧版本公开状态，避免延迟消息覆盖新回合。

主机断开后，共享房间会提升剩余成员为新主机；作品检测到角色变化后清空当前比赛并回到等待同伴，不尝试继承缺少答案的旧回合。

## 4. 共享协议扩展

现有 `room:action` 继续广播画笔、公开状态、结果、清空与重置。

新增通用 `room:direct`：

```js
socket.emit("room:direct", {
  roomId,
  targetId,
  type,
  data
}, callback)
```

服务端必须验证发送者和目标都属于同一房间，再只向 `targetId` 发送：

```js
{
  roomId,
  senderId,
  type,
  data
}
```

它用于：

- 主机把题目发给远端画家；
- 远端猜词者把猜测发给主机；
- 后续身份牌、秘密选择和定向提示。

不允许任意 socket ID 跨房间发送，也不把 `room:direct` 退化成普通广播。

## 5. Canvas 消息

每一笔被拆成线段：

```js
{
  x1: 0..1,
  y1: 0..1,
  x2: 0..1,
  y2: 0..1
}
```

坐标相对 Canvas CSS 宽高归一化，接收端按自己的尺寸重绘。颜色和线宽由本地固定样式决定；消息不接受任意 HTML、图片 URL 或大块二进制。只有当前 `drawerId` 的消息会被绘制。

## 6. 配置与最小默认值

- `rounds`: 4；
- `secondsPerRound`: 45；
- `words`: 不少于 12 个常见中文词；
- 主机每局随机洗牌后截取题目，不能固定采用公开题库前几项；
- 猜词规范化：去除空格、常见中英文标点并转小写；
- 分数：每猜对一题共同得 1 分，不增加速度奖励或对抗排名。

这些值集中在作品 `config.js`，以后可替换成两个人的私人梗题库，但真实私人内容不默认提交公开仓库。

## 7. 验收标准

- C 级、本地局域网、公网依赖为无；
- 两个页面可创建/加入同一房间并开始 4 回合比赛；
- 每轮只有画家页面显示题目，猜词页面与公开状态不含答案；
- 两端不同 Canvas 尺寸仍能看到相同笔迹；
- 非画家发来的 stroke 被忽略；
- 错误答案不加分，正确答案只由主机确认并让两端同步 +1；
- 超时、下一轮、最终结果与重开两端一致；
- 主机断开后比赛清空，不遗留答案、计时或画布；
- 自动化测试覆盖状态版本、角色轮换、规范化猜词、计分和结束；
- Chrome 双端覆盖完整一轮、错误答案、正确答案、画布和断线；
- README 有完整借鉴与来源声明。

## 8. 借鉴与来源声明边界

- 传统 Pictionary / 你画我猜：只采用通用玩法规则，没有复制题库、文案、视觉或源码；
- 本仓库 A 级“同机你画我猜”：复用仓库内部的共同计分与中文规范化思路，C 级状态和 UI 重新实现；
- [Socket.IO](https://github.com/socketio/socket.io) 4.8.1（MIT）：作为共享房间传输依赖，只调用公开 API；
- [Whitebophir](https://github.com/lovasoa/whitebophir)（AGPL-3.0）与 [Excalidraw Room](https://github.com/excalidraw/excalidraw-room)（MIT）：调研时仅用于比较自托管白板/房间架构，本批不复制、改写或打包其源码、视觉与素材。
