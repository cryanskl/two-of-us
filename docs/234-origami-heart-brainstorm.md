- 建议目录：`experiences/surprises/origami-heart/`
- 建议题名：**沿着折痕，折到你心里**
- 目标等级：A，双击 `index.html`，零安装、零服务、零公网

## 1. 为什么现在做

当前六个“已有纯逻辑、缺生产 UI”的候选都受明确视觉确认 Gate 约束，不能绕过。S16 尚未形成专属文档链，但有几个适合本批完整落地的条件：

- 单张纸、有限步骤、一个结果页，30 秒内可以理解；
- 不依赖题库、音频、图片、物理引擎、网络、权限或随机数；
- 与“套娃礼盒”的逐层拆除不同，本作是同一对象的逐步构造；
- 与“雾窗手写”的自由轨迹不同，本作只有五道冻结折痕；
- 规则可以由 reducer 完整证明，视觉可以由代码原生 CSS 完成。

## 2. 产品核心

这不是折纸模拟器，也不是考折纸知识的谜题。它是一段有限的触觉仪式：

1. 收礼者看到一张没有私密内容的方纸；
2. 按顺序完成五道折痕；
3. 每道折痕既可以拖动活动边，也可以按真实按钮完成；
4. 五道折痕完成后，主动把纸翻到背面；
5. 心形和准备者写下的称呼、标题、留言、署名此时才进入页面。

一句话规则：

> 沿着亮起的折痕，把这一张纸慢慢收好；最后翻过来，会有一句话等你。

## 3. 与现有作品的边界

| 相邻作品 | 相邻点 | S16 的新增机制 |
|---|---|---|
| `nested-gift` | 多阶段惊喜揭晓 | 同一张纸不断构造，不是移除四层包装 |
| `fog-window-letter` | Pointer 主路径、按钮替代、完成后私信 | 固定五道折痕，不采集或回放自由轨迹 |
| `instant-photo` | 拖动累积推进显影 | 每道折痕独立提交，不按总拖动距离连续解锁 |

| `paper-plane-mail` | 纸张主题与拖动 | 不做弹道、力度、碰撞或飞行关卡 |

## 4. 冻结交互

### 4.1 阶段

```text
intro
  → folding（step 0..4）
  → turning
  → complete
```

五道折痕固定为：

1. `bottom-up`：把下边收向中线；
2. `left-in`：把左角收进来；
3. `right-in`：把右角收进来；
4. `top-left-soften`：把左上尖角轻轻收圆；
5. `top-right-soften`：把右上尖角轻轻收圆。

这是一套为网页动画独立设计的仪式步骤，不声称对应某个传统折纸模型，也不从第三方折纸图解翻译或描摹。

### 4.2 Pointer 路径

- 当前步骤只有一个活动折边；
- `pointerdown` 后捕获当前 pointer；
- 沿当前步骤冻结方向计算投影进度，钳制到 `0..1`；
- `pointerup` 时进度不小于 `0.72` 才提交；
- 未达到阈值、`pointercancel`、`lostpointercapture`、失焦或页面隐藏都只清空临时手势，不改变 reducer；
- 临时进度只存在 app 层，不写入权威 state；
- 不由 `transitionend`、`animationend` 或当前 transform 值推进规则。

### 4.3 按钮与键盘路径

- 每一步都有一个原生按钮“折好这一步”；
- Enter、Space 和点击都派发同一个 `COMMIT_FOLD`；
- `ArrowRight` 可作为当前步骤快捷键，但拒绝 repeat；
- turning 阶段使用“翻到背面”按钮；
- 不要求拖动，不设置只靠形状或颜色才能理解的目标。

## 5. 私密内容边界

准备者在 `config.js` 中配置：

- `recipientName`
- `finalTitle`
- `finalMessage`
- `signature`
- 可选 `composeCompletionNote(summary)`

隐私承诺只覆盖正常页面流程：

- intro、folding、turning 的 DOM、属性、ARIA、live region 和公开 view 都不能包含这些字段；
- complete 时才创建私密 DOM；
- 不写入 URL、Storage、剪贴板、日志或网络；
- 刷新清空进度；
- 会查看源码或 JavaScript 内存的人仍能看到本地配置，这不是密码学保密。

## 6. 视觉方向

视觉冻结为 **夜灯下的一张双面信纸**：

- 背景是深墨蓝桌面，不使用图片；
- 正面是暖奶油纸，带细小纸纤维渐变和铜色折痕；
- 背面是低饱和莓红，完成后形成代码原生心形；
- 当前折边用实线、编号和文字共同标记；
- 完成页像摊开的私人短笺，不做模态框、翻卡、礼花或爱心雨；
- 标题、折痕、心形、纸纹和 favicon 均由 HTML/CSS/SVG 基本形原创绘制；
- 不生成或引入第三方图片、图标、字体、音效。

### 6.1 降级

- `prefers-reduced-motion`：步骤直接切到稳态，不做 3D 插值；
- 不支持 3D transform：使用 2D `clip-path` / transform 稳态和步骤列表；
- `forced-colors`：保留真实 border、outline、编号和步骤文案；
- CSS 全部失败：原生按钮和有序步骤仍可完成 reducer；
- JavaScript 失败：显示静态说明，不提前泄露私密配置。

## 7. 明确不做

- 自由折纸、网格编辑器、真实纸张物理或碰撞；
- 评分、计时、错误扣分、排行榜或成就；
- 随机折痕、多结局或分支故事；
- Canvas、WebGL、SVG path morph、图片切片或 3D 模型；
- 音乐、音效、震动、传感器或麦克风；
- 自动播放完成动画；
- 下载、截图导出、分享、账号、存储或公网请求。

## 8. 需要在规格中证明

1. 五道折痕只能按严格前缀完成；
2. 重复、越序和畸形 action 都不能推进；
3. 临时拖动永远不能污染权威 state；
4. turning 只有五步完成后可进入；
5. complete 前的公开 view 不含任何私密配置；
6. 所有状态和公开 DTO 都递归冻结且可 JSON 往返；
7. 按钮路径可以不使用 Pointer 完整完成；
8. A 级入口没有模块、fetch、远程资源或运行依赖。
