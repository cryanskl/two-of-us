## 1. 视觉命题

这是“一张午夜药房工作台上的私人配方账本”：深夜蓝布面承担秘密与角色，胡桃木承接真实桌面，羊皮纸账页承接可操作信息，黄铜配料章承担选择。它不是商业猜码棋盘的复刻，也不是 RPG 背包、赌场筹码盘或数据仪表盘。

视觉层级固定为：当前角色与轮次 → 当前四格任务 → 六种可选配料 → 唯一主行动 → 已提交历史。秘密设置与最终结算在桌面采用约 `28 / 72` 双栏；移动端改成真实单列，不压缩桌面布局。

## 3. 设计令牌

### 3.1 色彩

| 角色 | 值 |
| --- | --- |
| 夜蓝 `--night` | `#0b1420` |
| 抬升夜蓝 `--night-raised` | `#101c28` |
| 胡桃木 `--walnut` | `#2b1b16` |
| 羊皮纸 `--parchment` | `#eadbbd` |
| 深羊皮纸 `--parchment-deep` | `#d7c19c` |
| 墨色 `--ink` | `#30251e` |
| 黄铜 `--brass` | `#9b7440` |
| 亮黄铜 `--brass-bright` | `#c6a466` |
| 结果红 `--result-red` | `#7f3137` |
| 焦点 `--focus` | `#f3d79d` |

配料色沿用规格：红莓 `#c9656b`、柑橘 `#dfa547`、薄荷 `#67a483`、可可 `#8b604f`、蜂蜜 `#d2ae59`、海盐 `#88a6b5`。反馈的“同位”和“有料”必须同时使用不同形状、文字与数量，不能只靠颜色。

### 3.2 字体与尺度

- 展示标题、轮次、结算：`Songti SC`, `STSong`, `Noto Serif CJK SC`, Georgia, serif；
- 按钮、辅助说明、可访问状态：系统无衬线栈；
- 不下载字体，不依赖联网；中文缺字时以系统字体自然回退；
- 正文最小 `15px`，按钮最小触控尺寸 `44×44px`，数字比分使用等宽数字特性。

### 3.3 动效

- 控件反馈 `160ms`；
- 面板与阶段切换 `180ms`；
- 配料章落位 `220ms`；
- `prefers-reduced-motion: reduce` 下全部归零，不用动画承载结果或状态。

## 4. 布局合同

### 4.1 桌面

- `>= 900px`：稳定的 `28 / 72` 双栏，视口高度优先维持在 `100vh`；左栏只显示作品、轮次、角色/结算和隐私，右栏承担当前交互；
- 历史区在内容面板内部滚动，不能让主行动因历史增长而被推离视口；
- 四格输入一行，配料六枚以 `3×2` 或 `6×1` 自适应；结算两轮记录横向完整可读。

### 4.2 移动

- `390×844` 和 `320×700`：单列，标题/轮次缩短垂直占用；当前四格、反馈图例、六枚配料与主行动必须在首个可用交互区连续出现；
- 历史位于主行动之后，可继续向下滚动；不在窄屏保留固定左栏；
- 四格不得横向溢出，配料固定为 `3×2`，按钮文字不得截断。

## 5. 阶段投影与首屏文案

| 状态 | 首屏允许出现的内容 | 明确隐藏 |
| --- | --- | --- |
| `intro` | 标题、副题、开场、开始按钮、隐私说明 | 四格、历史、秘密、比分 |
| `setting` 未遮盖 | 轮次、配方师、设置规则、四格、六配料、藏好/遮住/清空 | 猜测历史、另一轮结果 |
| `setting` 已遮盖 | “配方已盖住”、恢复按钮、隐私说明 | draft 的 ID、名称、颜色、图形与占位数量 |
| `handoff` | 交给破译者、接手按钮、隐私说明 | secret、draft、历史 |
| `guessing` | 轮次、破译者、当前四格、反馈图例、六配料、提交/清空、公开历史 | secret 与设置草稿 |
| `round-result` | 本轮结论、公开秘密、本轮次数/未猜中、交换角色或最终按钮 | 可编辑输入 |
| `match-result` | 最终标题、2 比 3 等成绩、两轮摘要、重开、回作品集 | 当前 secret/guess/设置控件 |

不额外添加 eyebrow、状态胶囊、胜率徽章、等级标签、排行榜或重复标题。允许的装饰性图标只有草叶/枝条、锁、移除 X、重开箭头和反馈形状。

## 6. 图标与控件实现

六种配料在生产界面使用代码原生内联 SVG：三果一叶、六瓣切片、双叶、中缝豆、单滴、菱形晶体。每个配料按钮同时显示 `1–6` 编号与名称；生成概念中的写实位图配料章只定义尺寸、材质和构图，不作为可点击位图精灵复制。

四格中的移除按钮提供可读 `aria-label`；空格使用药瓶轮廓但不暗示配料；“同位”使用实心圆，“有料”使用菱形或空心环，并保留完整文本。装饰 SVG 一律 `aria-hidden`。

概念与生产背景均由本次项目生成；没有借用开源仓库、商业产品或网页中的图片、图标、字体和音效。

## 8. Fidelity 账本

| 概念意图 | 生产约束 / 决定 | 验收方式 |
| --- | --- | --- |
| 午夜药房 + 私人账本 | 生产背景只提供真实桌面，账页由 CSS 面板构成 | 截图与背景真源对照 |
| 桌面 28/72 双栏 | `>=900px` 固定比例；内容超高时右栏内部滚动 | 1440×900 |
| 移动真实单列 | 不缩放桌面；顺序为身份→当前输入→选料→行动→历史 | 390×844、320×700 |
| 四格是唯一当前任务 | setting/guessing 只保留一组四格，不叠加候选面板 | 全阶段 DOM 检查 |
| 六枚黄铜配料章 | CSS 圆章 + 内联 SVG + 编号 + 名称，不使用概念位图 | 颜色关闭/灰阶检查 |
| 羊皮纸有材质但可读 | 使用轻量 CSS 纹理/边框，正文对比优先 | 对比与缩放检查 |
| 设置态允许遮盖 | covered public view 不返回 draft，DOM 也完全移除 | 浏览器 DOM 检查 |
| 交接态不留秘密 | handoff DOM 不含 ID、名称、颜色或图标 | 浏览器 DOM 检查 |
| 猜测历史紧凑 | 桌面内部滚动、移动在主行动之后；反馈形状 + 文本 | 七行极限检查 |
| 最终 2 比 3 强调 2 | 采用 v2；较低分才用亮黄铜与下划线 | 金牌重放截图 |
| 背景无染色叠层 | 直接 `background-image`，面板自身不透明；失败用 CSS 渐变 | 资产开/关对照 |
| 图像不是规则依赖 | 禁图后全部文案、输入、反馈、结果和重开仍可用 | 阻断图片实玩 |
| 控件保持实体感 | 内阴影、双边框、短动效；不使用玻璃拟态和霓虹 | 概念并排检查 |
| 动效不承载状态 | reduced motion 下零时长，notice/文字仍报告动作 | 媒体查询检查 |
