## 1. 设计任务

为一个给伴侣准备、双击本地 HTML 即可玩的中文惊喜页面设计完整多状态界面。它是一台“桌面夸夸印刷机”：收礼者拉动一个原生把手，每次由三段纸卷拼出一句完整夸奖；第 3–6 次会出现唯一“特别同频”，展开准备者的私人结语。

视觉必须表达认真、亲密、手作和印刷触感，而不是赌场刺激。页面无账号、无付费、无输赢、无分数、无联网、无历史持久化。

概念图是后续 HTML/CSS 实现的视觉规格，不是生产 UI 位图。标题、说明、列标签、短句、按钮、历史与结语全部保留为 code-native 文本；ImageGen 只定义布局、材质、灯光、形体和可分离无字装饰。

## 2. 核心视觉方向

### 2.1 一句话方向

一台放在安静书桌上的精致小型凸版印刷机：深梅红哑光机身包住三条奶油纸卷，珊瑚色把手像一枚可亲手拉下的句号，墨蓝文字与少量旧黄铜压边让每句夸奖像刚刚为一个人印好。

### 2.2 视觉性格

- 创意强度：7/10；有鲜明实体隐喻，但不做主题乐园式机柜；
- 密度：低到中等；首屏只有一个焦点——三列压纸框与把手；
- 背景：明确为柔和浅粉陶土色纸面，不是真白，也不是米黄网页模板；
- 机身：深梅红、哑光、略有手工喷漆质感；
- 纸卷：奶油白，只有细微纤维和压痕；
- 主动作：珊瑚红实体把手，与机身分离但不荧光；
- 正文：墨蓝，高对比；
- 点缀：少量旧黄铜，只用于压边、铆钉和终局双线；
- 终局：静态星形压印和双线边框，不使用彩纸、金币雨或爆炸光效；
- 阴影：短、柔、接触式，强调桌面小物而非悬浮卡片；
- 字体气质：中文标题为有书卷感的宋体/衬线回退，正文与控件为清楚的人文黑体；不使用远程字体。

## 3. 必须生成的八张协调概念

八张图必须属于同一设计系统：相同机身比例、压纸框、把手、色温、字体气质、阴影与黄铜细节。每张都要是完整可读界面截图，不是 moodboard、局部特写或多屏拼贴。

### C1：桌面 ready 主屏

- 原生尺寸：`1504×1046`，桌面完整首屏；
- 阶段：计划已排好、尚未拉动；
- 必须同屏：题名、有限保证、三列压纸框、阶段说明、主把手；
- 三列纸卷只有无语义短横/纸纹，不出现任何未来短句；
- 三个稳定列标签按 `moment → shine → echo`；
- 结果、历史与结语区域尚未展开，不用空卡片占位；
- 页面不可滚动；机器是唯一大形体，避免再套一层巨型圆角卡。

### C2：桌面 spinning / 上一结果保留

- 原生尺寸：`1280×800`；
- 阶段：第二次或以后正在组合；
- 压纸框至少 `720×300`；
- 三列用可实现的错峰纵向运动提示，不能用不可读的真实未来文字、运动模糊答案或赌场符号；
- 上一次已经公开的完整句仍在结果区；
- 按钮原位显示 disabled 文案，不移动焦点位置；
- 题名、保证、机器、上一结果和主动作同屏，无横向滚动。

### C3：桌面普通 result

- 原生尺寸：`1504×1046`；
- 阶段：一次普通夸奖已经印好，可继续；
- 三列分别显示当前三段，完整句在机器下方全宽排版；
- 历史使用开放式纸条/印刷清单，不做重复卡片网格；
- 本图只需展示 1–2 条历史，不出现特别同频标识或私人结语；
- 主动作仍是同一个实体把手与原生按钮区域。

### C4：桌面 jackpot 终局

- 原生尺寸：`1504×1046`；
- 阶段：特别同频；
- signature 三段与完整句清楚可读；
- 显示“特别同频”文字、静态星形压印、双线边框和私人结语；
- 历史按第 4 节冻结的 jackpotSpin=3 三句 fixture 顺序完整呈现，不得重复或自造句子；
- 结语像从机身下方抽出的一张私人信笺，但不变成弹窗或独立营销卡；
- “再夸一局”仍在原把手位置；不出现庆祝粒子、奖池或中奖数字。

### C5：移动端 result 重排

- 原生尺寸：`390×844`；
- 阶段：普通 result；只画一张完整页面，不做两个手机并排 mockup；
- 使用第 4 节 QA-only 最大长度三段与 61 字素完整句；390px 优先保留三列并排，每列文字允许自然换行；
- 完整句在三列下方全宽，按钮至少 48px 高；
- 本状态可见内容顺序为题名 → 保证 → 三列 → 完整结果 → 历史 → 把手；完整 DOM 仍保留隐藏的特别结语、fallback 与 live region 固定节点；
- 顶部必须保留足够呼吸，不把题名压成海报小字；
- 不出现横向滚动、底部悬浮导航、浏览器壳或手机设备边框。

### C6：320px 最大文本堆叠 Gate

- 原生尺寸：`320×568`；
- 阶段：普通 result，使用第 4 节 QA-only 最大长度称呼、三段与 61 字素完整句；
- 三列按 `moment → shine → echo` 垂直堆叠；
- 连接提示暂作为视觉提案写成 `第一段 · 我看见的你`、`第二段 · 发亮的样子`、`第三段 · 留给我的感觉`；这三句不是既有冻结文案，必须随概念单独确认；
- 保留题名、有限保证、三段标签、完整句、历史和按钮；允许纵向滚动，但禁止横向滚动；
- 此图只冻结约 320 CSS px 的重排意图，不能替代真实 200%/400% zoom 验收。

### C7：平板 768px 最大文本 Gate

- 原生尺寸：`768×1024`；
- 阶段：普通 result，使用第 4 节 QA-only 最大长度三段与完整句；
- 三列保持并排，完整句在下方全宽，按钮命中区至少 48×48 CSS px；
- 历史保持开放印刷清单，不退化成卡片网格；
- 零横向溢出，页面可纵向滚动但主要机器、结果和把手关系清楚。

### C8：320px 准备失败

- 原生尺寸：`320×568`；
- 阶段：intro 准备失败，显示诊断与“重试准备”；
- 三列只有无语义空纸纹，并按 `moment → shine → echo` 堆叠；
- 保留题名、有限保证、三段标签、诊断和按钮；允许纵向滚动，禁止横向滚动；
- 不新增错误图标、技术错误码、帮助链接、网络提示或第二个动作。

概念图只允许使用本节文字；生成图中文字若失真，只作为布局占位，生产实现仍逐字采用下列 code-native 文本。

- 列标签：`我看见的你` / `发亮的样子` / `留给我的感觉`

### ready

- 主说明：`第一句，等你来拉。`
- 主按钮：`拉一下，夸夸你`

### spinning

- 主说明：`正在把三段心意排在一起。`
- 主按钮：`正在组合…`

### 普通 result 示例

### QA-only 最大长度排版 fixture

以下文字只用于 C5–C7 的排版压力概念和后续测试配置，不是默认库存，也不会出现在正常默认流程：

- recipient（12 字素）：`给我所有温柔和勇气的你呀`
- sender（12 字素）：`一直认真看见你的那个我呀`
- moment（18 字素）：`你愿意在忙乱以后慢下来认真陪我的时候`
- shine（18 字素）：`总会把每一个普通日子慢慢又温柔地照亮`
- echo（22 字素）：`让我更愿意相信两个人可以一直稳稳走向很远以后`
- compose 后完整句（61 字素）：`你愿意在忙乱以后慢下来认真陪我的时候，总会把每一个普通日子慢慢又温柔地照亮，让我更愿意相信两个人可以一直稳稳走向很远以后。`

这些字符串分别达到规格上限，不含配置禁止的内嵌全角逗号、句号、换行或控制字符；标点只由完整句合成器添加。正式实现仍需建立每列六条都达到合法上限的独立测试配置，概念中的单条 fixture 不能替代机器验证。

### jackpot

- 主说明：`特别同频到了，这些都是真心话。`
- 结构标题提案：`特别同频`（规格要求有标题但未冻结精确字符串，必须随概念单独确认）
- 三段：`你愿意慢下来陪我的时候` / `会让安心变成很具体的事` / `让我觉得身边有你真好`
- 完整句：`你愿意慢下来陪我的时候，会让安心变成很具体的事，让我觉得身边有你真好。`
- 私人结语：`你，这些不是碰巧，是我真的一直这样看见你。——我`
- 主按钮：`再夸一局`

### intro / 准备失败

- 主说明：`正在把这一轮排好。`
- 失败诊断：`暂时没排好，请重试准备`
- 主按钮：`重试准备`

### fallback

- 提示：`本机随机不可用，本轮使用固定惊喜顺序`

不要在标题上方增加 eyebrow、kicker、类别、徽章或 A 级标签。不要增加导航、分享、收藏、设置、音量、剩余次数、概率、分数或“幸运值”。

`第一段 / 第二段 / 第三段` 连接提示来自早期响应式要求，但精确组合文案尚未在规格冻结，只允许出现在 C6 作为待确认提案。`特别同频` 独立标题同样是待确认视觉提案。当前结果标题、历史标题、私人结语标题、fallback 区标题、无 JavaScript 提示和页面隐私说明也都未冻结；首轮概念不得自行发明这些标题。若视觉层级确实需要，必须在概念评审中单独列为新增文案提案。

## 5. 容器与组件合同

### 页面骨架

- 页头为开放式排版，不使用导航栏；
- 有限保证是正文段落或窄纸条，不是 pill/badge；
- 机器是一个有真实形体的单一主容器，不在外面再套 dashboard panel；
- 三列共用一个压纸框，但各自有稳定标签和纸卷窗口；
- 完整结果是机器输出的一张连续纸，不拆成三张卡；
- 历史是有编号/压痕节奏的印刷清单，不做 card grid；
- 私人结语是一张展开信笺，与机器相连；
- 主按钮语义仍是原生 `<button>`，视觉可将可点击面与实体把手组合，但命中区域必须清楚。

### 允许的装饰

- 无字纸纹、纸边压痕、铆钉、黄铜压线、印刷定位十字、静态星形压印；
- 一处极轻的桌面接触阴影；
- spinning 状态纸纹错峰位移；
- jackpot 信笺缓慢展开的表现提示。

### 禁止的装饰与组件

- BAR、7、铃铛、樱桃、金币、筹码、硬币槽、奖池、赔率、payline、现金、提现；
- 真实赌场品牌或可识别 trade dress；
- 彩纸雨、焰火、霓虹、强 glow、bokeh/orb、金色爆炸、旋转警灯；
- hero eyebrow、pill、badge、假指标、图标行、默认 bento/card grid；
- 额外菜单、分页、模式切换、锁轴、重转、自动播放、分享或导出；
- 把 UI 文本、短句或按钮烘焙进生产背景资产。

## 6. 交互与状态提示

- ready：把手有明确可按/可拉的视觉姿态，焦点环不会被形体遮挡；
- spinning：三列错峰，`正在组合…` 明确 disabled；上一条公开结果可保留，未来 stop 不出现；
- result：三列停止后，三段与完整句形成从上到下的阅读流；
- jackpot：文字、星形压印与双线三者共同表达，不只靠颜色；
- reduced motion：同一布局直接切换结果，不依赖甩动、模糊、缩放或粒子；
- forced colors：机身边界、纸卷、按钮、星形与双线在系统色下仍能区分；
- 图片阻断：所有关键信息、按钮和完成路径仍由 HTML/CSS/textContent 存在。

视觉概念接受后，再单独生成以下可分离无字资产；当前概念图不可直接裁切为生产素材：

## 9. 接受 Gate

八张首轮概念必须逐张用 `view_image` 检查，任一命中以下情况即退回重做：

1. 看起来仍像赌场机柜或含任何禁止符号；
2. 只画 hero/机器局部，没有完整页面、状态或下游内容；
3. 文本、按钮、三列和结果层级无法提取；
4. ready/spinning 提前显示未来短句；
5. 390px 把三列缩成不可读窄条，或使用 CSS order 思维反转阅读序；
6. 使用重复卡片网格、巨型圆角 wrapper 或未经许可的额外 UI；
7. 终局只靠金色/粒子表达，没有“特别同频”文字与结构；
