# 一眼看穿：视觉搜索对决的规格

- 状态：`implemented`
- 日期：2026-08-01
- 作品：`experiences/versus/spot-the-one/`（A 级 · 双人对抗）

## 为什么做这一个

对 75 个已收录体验做玩法主题盘点后，「视觉搜索 / 观察力」是一块完整的空缺：`starlight-keepsake-search` 是单人惊喜的从容探照，`fog-navigation` 是口述导航，24 个对抗作品里没有任何一个以“看”为核心能力。与 `reaction-duel`（纯反射）、`photo-slider-race`（操作竞速）、`memory-bid`（记忆）相比，本作让两个人比的是**并行视觉比对**——水平相近的两个人也会互有胜负。

## 核心决策

### 一、题面是确定性函数，两边绝对公平

每一题由整数散列从（种子 + 题号 + 格号）推出：同一颗种子永远给出同一组题，`logic.test.js` 可以逐题穷举断言“有且仅有一处差异”。两块面板来自同一份数据，`panelCells(round, "right")` 只替换差异格，因此双方看到的题面与差异严格一致，不存在“我的那边更难”。

### 二、差异永远包含几何变化，颜色只是辅助

差异维度按题号在旋转 / 大小 / 线宽之间轮换，明度偏移只作为附加提示。每个图形都带一根从圆心指向外圈的指针，所以任何旋转差异对任何图形都清晰可见——不存在“圆形转了看不出来”的死角，色觉不同的玩家也不会吃亏。

### 三、点错只罚自己

点错的一方被锁定 `lockMs`（默认 1.5 秒），锁定期间不能作答，但对方完全不受影响。这与 `reaction-duel` 的“抢跑送分”属于同一类对称罚则：错误的代价是把机会让给对方，而不是直接送分，搜索类玩法里后者会让一次手滑显得过重。

### 四、每题必有一人得分，加时因此收敛

回合没有超时——题面一直在那里，总有人先看出来。常规题打完若平局则自动加时；因为每题恰好产生一分，一道加时题就一定分出胜负，状态机不需要处理“无限加时”。

### 五、难度只随题号变化

题面从 3×3 逐题放大到 7×7 封顶，几何差异的幅度随题号变小（前三题旋转差 90°，之后 45°）。难度与比分无关，领先者不会被系统追打，落后者也得不到补偿——胜负只来自两双眼睛。
