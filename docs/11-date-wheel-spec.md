# A 级“今晚做什么”约会转盘规格

## 1. Brainstorm 结论

这款作品是一台本地约会决策器：准备者预先写好私人候选，也可以两个人现场一起使用；点击一次，转盘公平选出今晚的安排。

| 方案 | 价值 | 复杂度与风险 | 本批决定 |
| --- | --- | --- | --- |
| 单一等概率转盘 | 30 秒内理解，候选容易定制 | 玩法轻但目标明确 | 采用 |
| 候选权重 | 可控制出现频率 | 容易变成不透明的“作弊转盘” | 不采用 |
| 自动防重复 | 结果看似丰富 | 悄悄改变每次等概率承诺 | 不采用 |
| SVG 扇区 | 标签清晰、缩放稳定、无需第三方库 | 要处理角度与文字方向 | 采用 |
| Canvas 转盘 | 绘制直接 | 语义内容和高分屏排版需额外处理 | 不采用 |
| 历史与收藏 | 便于回顾 | 引入本地存储和额外状态 | 后续可选 |

作品名为“今晚做什么”。首版不加权重、防重复、历史、配置编辑器、音效、彩纸、联网、账号、分享或多设备房间。

## 2. 用户流程

1. 准备者编辑 `config.js` 中的标题、提示和 2–12 个约会候选；
2. 对方或两个人一起双击作品目录的 `index.html`；
3. 页面同时展示转盘和候选清单；
4. 用户点击或用键盘触发“转一次”；
5. 应用先选定等概率结果，再让转盘旋转 3–4 圈并停到对应扇区；
6. 结果区显示候选标题与补充说明，并通过 `aria-live` 宣布；
7. 用户可以再次转动；每次相互独立，允许连续抽中同一项。

## 3. 最小配置

`config.js` 使用 A 级作品一致的普通全局对象，不采用 ES Modules：

```text
eyebrow, title, instruction,
spinButtonText, resultPrefix,
items: [{ label, detail }]
```

- 候选数最少 2 个、最多 12 个；超出范围在初始化时给出明确降级提示；
- `label` 用于扇区和结果标题，`detail` 用于结果说明；
- 页面统一用 `textContent` 写入私人文案，不接收 HTML 字符串；
- 色板由页面按候选顺序自动循环，不暴露主题配置；
- 默认配置只放示例约会，不提交真实地址、票据、兑换码或隐私内容。

## 4. 公平选择与角度模型

逻辑层先选结果，再计算动画终点：

1. 优先使用 `crypto.getRandomValues()` 取得 32 位无符号整数；
2. 将整数除以 `2^32` 得到 `[0, 1)` 随机值，`floor(value × itemCount)` 得到索引；
3. 每个扇区角度为 `360 / itemCount`；指针固定在正上方，目标旋转角把中奖扇区中心对齐指针；
4. 在当前累计角度上增加至少 3 个整圈，再加到目标角的最短正向差值；
5. 结果索引是权威值，不能在动画结束时根据 CSS transform、帧时间或像素位置重新推断；
6. `prefers-reduced-motion` 下直接或短时跳到相同目标角，随机结果不变。

按钮在旋转中禁用，动画结束只结算一次。再次旋转重新独立抽样，不读取上一次索引。

`logic.js` 保持无 DOM 纯函数，至少测试随机边界映射、非法随机值、扇区角度、目标旋转对齐、结果索引与旋转圈数不改变，以及配置候选的清洗边界。

## 5. SVG 与页面结构

- 使用原生 SVG 生成 2–12 个扇区、分隔线和短标签；不引入图表或转盘库；
- 整个 wheel group 围绕中心旋转，固定指针不动；
- 长标签在配置清洗阶段限制显示长度，完整文本仍出现在候选语义列表和结果区；
- 移动端转盘宽度不超过容器，390×844 无横向溢出；
- 结果卡在旋转前显示温和占位，不提前暴露预选结果；
- 不自动播放音频、不震动、不请求权限。

## 6. 可访问与降级

- “转一次”使用原生 `<button>`，支持 Enter 和 Space；
- 候选用真实 `<ul>` 同步展示，颜色不是唯一信息；
- SVG 使用说明性可访问名称，不要求用户从图形读取全部候选；
- 结果标题与说明通过 `aria-live="polite"` 宣布，动画不抢焦点；
- 旋转中按钮文案或忙碌状态明确变化；
- JavaScript 不可用时，HTML 保留示例候选与说明，不显示伪造随机结果；
- `prefers-reduced-motion` 下取消长时间旋转与结果位移动画。

## 8. 本地与隐私边界

- 等级：A，直接双击作品 `index.html`；
- 公网依赖：无；第三方运行依赖：无；
- 不使用 `fetch`、XHR、WebSocket、远程字体、CDN、统计或本地存储；
- 候选只存在本地 `config.js` 和页面内存中；
- A 级兼容使用普通相对脚本与本地样式，不依赖服务器 MIME 或 CORS。

## 10. 验收标准

- 根门户和作品目录双击入口都能打开作品；
- 2、6、12 个候选均能正确生成等分扇区与语义列表；
- 注入确定随机值时，每个索引和目标角度可预测；真实连续旋转均停到结果对应扇区；
- 旋转中重复点击不二次结算，结束后可再次旋转；
- 允许连续抽中同一项，不存在隐藏防重复；
- 键盘可触发，结果由 `aria-live` 宣布，reduced motion 正常；
- 390×844 无横向溢出，长标签不破坏转盘；
- Chrome 控制台无 warning/error，页面无公网请求；
- `npm test`、`npm run verify` 与 `git diff --check` 通过；
- README 包含完整“借鉴与来源声明”。
