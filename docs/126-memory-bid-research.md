# V04“记忆竞拍”定向调研：这一串，我还记得

调研日期：2026-07-19。

## 结论

V04“记忆竞拍”适合实现为 A 级同机双人对抗作品“这一串，我还记得”，工作 ID 为 `memory-bid`。推荐完全原创实现，不引入第三方运行时，不复制现成游戏的代码、视觉、音频、名称、测试或素材。

它填补的机制不是又一个“看灯复述”游戏，而是：两人共同看过一串旅行纪念物后，公开竞价自己能按顺序记住多少件；一方加价、另一方退出后，最高出价者必须现场证明。证明成功由出价者得分，失败则由对手得分。比赛固定四轮，双方各先手两次，四轮后总分更高者获胜；2–2 时平局。

该机制满足本仓库的五项进入条件：

1. 主分类唯一：双人对抗；
2. A 级可行：经典脚本、相对路径、无服务端、无账号、无公网；
3. 首局可在 30 秒内说明：“看一串、报数量、最高者按顺序证明”；
4. 去掉音乐和私人图片后，核心仍成立；
5. 最小版本可控制为一个入口、一种升价机制和一个结果页。

## 为什么选择 V04

创意池 60 项中，按原机制完成数为：单人惊喜 10、双人合作 12、双人对抗 8。V04 能补充当前最少的对抗类别，同时与已有作品形成清晰差异：

| 已有作品 | 已覆盖机制 | V04 的新增机制 |
| --- | --- | --- |
| 回声擂台 | 轮流复现并追加公开音序，按错即负 | 不追加序列；双方先对自己的记忆能力定价，再由最高者承担证明 |
| 藏好这一味 | 一人设密、一人根据部分反馈破解 | 双方看过同一公开序列，不存在一方掌握答案的角色优势 |
| 数字凑靶 | 共享市场草拟与结果距离 | 竞价对象不是资源，而是“我能正确复述的前缀长度” |
| 气球胆量局 | 主动止盈与随机爆点 | 风险来自公开承诺和证明，不来自隐藏随机阈值 |

因此 V04 新增的是“公开升价 → 证明责任 → 风险转移”的对抗样板。

## 推荐的原创规则

### 1. 比赛结构

- 两名玩家，默认显示为“你”和“TA”；
- 比赛固定 4 轮，每轮恰好产生 1 分，双方各有 2 次先手；
- 每轮展示 8 件旅行纪念品；
- 六种物件每轮至少各出现一次，其中两种各重复一次；
- 每轮开价者严格交替，避免固定先手；
- 一局的四轮序列在开始时由一个 seed 确定生成，相同 seed 与动作日志得到相同结果。

### 2. 展示模式

开始前二选一，整场冻结：

- **自动经过**：每件出现固定时长，中间有固定遮挡间隔；提供暂停与继续；
- **自己翻页**：一次只显示一件，玩家点击“收好，下一件”后才换下一件，没有倒计时。

两种模式展示同一序列、使用同一竞价和计分。手动模式不是跳过玩法，也不会同时显示已看过的物件。

### 3. 公开升价

- 开价席第一次必须选择 2–8 中任一数量，不能在无人出价时退出；
- 之后双方交替行动，只能选择严格高于当前值的数量，或点击“就到这里”；
- 一方退出后，当前最高出价者进入证明；
- 出价到 8 时立即进入证明，没有无意义的“再加价”或平价动作；
- 所有竞价历史保留玩家、数量和顺序，结果不能只从最后一个按钮推断。

### 4. 证明与计分

- 证明者从六件物品中依次选择 `N` 件，目标是复述原序列前 `N` 件；
- 证明没有时间限制，可以删除末项或清空，提交后不能修改；
- 证明者可以点击“这轮认输”主动结束证明，按证明失败结算；
- 全部 `N` 项按位相等：证明者得 1 分；
- 任一位置错误：对手得 1 分；
- 本轮结果才同时揭晓完整八件序列、证明前缀、首个错误位置和本轮得分；
- 第 1–3 轮结果后交换开价席并开始下一轮；第 4 轮结束后比较总分，可能产生玩家胜利或 2–2 平局。

这让“喊得更高”同时提高潜在控制权与失败风险，不需要货币、下注损失或现实支付隐喻。

## 公平性与状态边界

### 开价公平

公开严格升价没有同价；开价席逐轮交替。固定四轮让玩家 0 和玩家 1 各有两次先手。测试必须覆盖玩家 0 / 玩家 1 获胜、4–0、3–1、2–2 和重开后开价席复位；平局不加赛，避免重新引入额外先手差异。

### 随机公平

随机序列不决定哪位玩家得分，两人观看同一内容。生成目标是不可预知、可重放和避免视觉单调，而不是声称密码学均匀：

1. UI 用 `crypto.getRandomValues()` 生成非零 32 位 seed；
2. reducer 的纯函数只接收 seed，使用冻结的整数 PRNG；
3. 每轮由六件唯一物品加两件不同重复物组成；
4. 通过确定性洗牌和相邻重复修复得到八件序列；
5. 没有 Web Crypto 时使用固定非零 fallback seed，仍可完整游玩，只是不可预测性下降。

### 阶段公开投影

权威状态可以保存四轮序列，但 UI 必须只接收阶段 view：

- intro：不含 seed 与序列；
- reveal：只含当前可见物件，遮挡间隔与暂停时不含物件；
- bidding：不含完整序列和当前物件；
- proof：不含答案，只含证明草稿；
- round-result：才含本轮完整序列与对照；
- match-result：只含已经公开的轮次摘要。

每次阶段变化重建阶段 DOM，不能把整串放在 `hidden`、`data-*`、`aria-hidden` 或 CSS 背面。

## 计时与生命周期

规则层不调用 `setTimeout()`、`Date.now()` 或 `performance.now()`。自动展示由 UI 计时器派发显式动作；每次阶段、暂停、重开或页面隐藏都递增 `playbackGeneration`，迟到回调携带旧 generation 时必须无效。

页面隐藏或窗口失焦时：

- 当前物件立即从公开 view 和 DOM 删除；
- 自动展示进入暂停，不在后台跳过；
- 返回页面不会自动继续，必须点击“继续展示”；
- 恢复时从被打断的同一物件重新完整展示，避免少看一部分时间；
- 手动模式也盖住当前物件，恢复后重新显示同一件。

## 键盘与无障碍

- 所有动作使用原生 `<button>`；
- `1–6` 只在物件选择区拥有焦点或证明阶段激活时选择对应物件；
- Backspace 删除证明草稿末项，Escape 只执行当前阶段有明确文案的暂停或清空；
- 竞价按钮显示完整数字与动作语义，不用只靠上箭头；
- 六种物件同时具备中文名、序号、独立轮廓和颜色；
- 首个错误位置用序号、文字和形状标识，不只变红；
- `aria-live` 只播报阶段、出价、退出和结果，不逐帧播报聚光动画；
- 自动模式可暂停，手动模式无计时；证明与竞价均无倒计时；
- `prefers-reduced-motion` 下取消滑入和翻牌位移，只保留即时显隐；
- `forced-colors` 下物件、当前出价、证明槽和得分仍由边框、文字与图案区分；
- 320、390、768、1280px 无横向溢出，主动作至少 48px。

## 最小测试 Gate

### 逻辑

1. 相同 seed 生成深相等的四轮序列；每轮八件、六种齐全、两种各重复、无非法 ID；
2. 开价席逐轮交替，首次只能 2–8，后续只能严格加价或退出，8 自动锁定证明；
3. 无人出价不能退出，错误玩家、平价、降价、越界和多余字段全部拒绝；
4. 证明草稿长度严格等于 bid，删除、清空、提交和首错位置确定；
5. 证明成功给出价者 1 分，失败或主动认输给对手 1 分；固定四轮后覆盖 4–0、3–1、2–2 与两侧获胜；
6. reveal / bidding / proof view 不泄露完整序列；round-result 才揭晓；
7. 暂停、恢复、旧 generation、重复动作、错阶段动作和任意阶段重开；
8. 相同 seed + action log、深克隆日志和 JSON 往返得到深相等终态；
9. 配置逐字段回退、结语策略冻结摘要、异常与越界安全回退；
10. 公共状态、view 与配置递归冻结且断开引用。

### 静态与浏览器

1. `file://` 经典脚本和相对资源 Gate；
2. Network 为 0，无模块 MIME、CDN、联网/存储 API 和仓库共享依赖；
3. 自动展示、暂停/继续、手动翻页、完整升价、退出、正确/错误证明、换轮、总结果与重开；
4. 页面隐藏/失焦后当前物件不在 DOM，恢复不自动播放；
5. 320×700、390×844、768×1024、1280×800 无溢出和主动作裁切；
6. 键盘可完成一整轮，焦点在阶段切换后落到标题或首个合法动作；

### 独立审计修正

初稿采用“先得 3 分、最多 5 轮”。独立规则审计指出，五轮会让一方拥有三次先手，且升价博弈可能放大这一差异。因此实现前修正为固定四轮、双方各先手两次；同时增加“这轮认输”，让证明阶段在没有倒计时的情况下仍有明确退出路径。
