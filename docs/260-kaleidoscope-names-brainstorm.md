# “把名字折成同一束光” Brainstorm：两轴校准与主动揭晓

- 日期：2026-07-25
- 稳定工作 ID：`kaleidoscope-names`
- 对应调研：[`259-kaleidoscope-names-research.md`](./259-kaleidoscope-names-research.md)
- 主分类：单人惊喜
- 目标等级：A（`file://` 直开）
- 目标：冻结首版产品选择，供 spec、design、plan 和后续生产共同使用

## 1. 想做出的感觉

页面像一枚放在桌上的小型折光镜。它不是自动播放的屏保，也不是要用户耐心等完
一段动画。体验者读到准备者留下的两条线索，亲手决定“折成几面”和“朝向哪里”。

每次换一个离散值，花纹立即形成新的稳定构图。接近正确值时，文字提示和环形
刻度变得更完整；两项同时命中时，图案安静下来，但名字仍没有自动暴露。体验者
最后按一次“照见我们”，两枚标记才从中央留白中出现，接着读到准备者的留言。

希望留下的不是“我转对了一个滑杆”，而是：

> 两条只属于我们的线索，最后把两个名字折进同一个图案。

## 2. 冻结的一句话玩法

> 根据两条私人线索选择镜面阶数、转动相位；两项都对齐后，主动照见藏在花纹里
> 的两枚名字标记和一段留言。

30 秒教学只补三句：

- 先从 4–9 面中选一个折面；
- 再拖动 24 格相位，让两项状态都变成“已对齐”；
- “已贴近”只代表答案在附近，不会告诉你该往哪边改。

## 3. 四个方向与取舍

| 方向 | 体验 | 结论 |
| --- | --- | --- |
| 单旋钮隐藏角度 | 连续转到容差区间即显字 | 排除；与月相拨盘过近，Pointer 精度也无意义 |
| 自由玩具 | 任意旋转/缩放/换色，没有结束条件 | 排除；可观赏但不是完整惊喜项目 |
| 照片万花筒 | 导入本地照片并切片镜像 | 排除首版；扩大为图片工具和 B 级隐私/解码范围 |
| 折面 + 相位 exact | 两条线索、两种离散参数、唯一命中、主动揭晓 | **采用**；规则清楚、键盘等价、A 级可测 |

## 4. 情绪与阶段

```text
intro
  → tuning
      ├─ 继续调整
      └─ aligned
           → complete
```

### 4.1 Intro：先把两束光放到桌上

只展示：

- 公共标题“把名字折成同一束光”；
- 一句固定说明；
- “开始折光”按钮；
- 一枚不含配置标记的静态图案。

不展示线索、当前答案、私人标记、结尾标题、留言或署名。开始必须是用户主动
动作，不因页面加载、延时或恢复标签页自动进入。

### 4.2 Tuning：两条线索，两项选择

固定顺序：

1. 折面线索与 4–9 六个原生按钮；
2. 相位线索与 0–23 原生 range；
3. 两项当前状态；
4. 万花筒投影；
5. 一句不会泄露方向的总状态。

两项可以任意顺序修改。第一次进入使用安全默认值，不保证“远”，但默认配置
不得一开始就已命中。每次有效变化都立即重算，不设置“提交答案”按钮。

### 4.3 Aligned：先安静，再决定要不要看

第二项命中后：

- 权威 phase 原子进入 `aligned`；
- 六个折面按钮与 range 立即禁用；
- 花纹一次性切换到静态完整构图；
- 状态写“这束光已经对齐”；
- 出现唯一主动作“照见我们”。

不自动显字，不播放倒计时，不在按钮的 `aria-label`、隐藏节点或 Canvas 中放入
两枚标记。aligned 可以停留任意久。

### 4.4 Complete：两个标记，一段话

主动确认后创建：

- “左边的光 / 右边的光”两个语义位置；
- 两枚准备者配置的简短标记；
- 结尾标题、正文和署名；
- “再折一次”按钮。

重开回到新 intro，并卸载 complete 私人节点。首版不记住已完成状态。

## 5. 输入决定

### 5.1 折面：六个明确按钮

折面用真实 `<button>`，显示：

```text
4 面 / 5 面 / 6 面 / 7 面 / 8 面 / 9 面
```

采用按钮而不是第二个 range：

- 用户能一眼看见完整答案集合；
- 触屏可以直接跳到某一档；
- Tab/Enter/Space 是原生行为；
- “选几面”与“转到哪里”形成不同的认知任务；
- 当前选中项可用 `aria-pressed` 与文字同时表达。

### 5.2 相位：24 格原生 range

相位用：

```html
<input type="range" min="0" max="23" step="1">
```

公开显示 `第 n / 24 格`，不是角度小数。视觉刻度可以像时钟，但规则不把
`phaseStep=0` 定义为具体时区或真实时间；准备者的线索负责赋予私人意义。

不加自绘圆形 Pointer dial。未来设计可以把 range 与圆环视觉关联，但不能把
Canvas 当命中区，也不能删除原生 range。

### 5.3 不采用的输入

首版不使用：

- 双指旋转、捏合、设备倾斜、摇一摇；
- 鼠标滚轮全局拦截；
- 只支持字符键的快捷键；
- 长按、速度、路径长度或压力；
- 麦克风、摄像头、传感器、震动或音频。

## 6. 反馈强度

每项状态只有三档：

| 状态 | 条件 | 可见文案 |
| --- | --- | --- |
| `far` | 不满足 near / exact | “还没贴近” |
| `near` | 折面差 1；相位环形距离不超过 2 | “已经贴近” |
| `exact` | 与目标严格相等 | “已对齐” |

不提供：

- 更大/更小、顺时针/逆时针；
- 百分比、距离数字、热/冷连续温度；
- 答案自动吸附；
- 尝试次数、用时、评分或失败。

这样默认答案最多可以靠有限尝试完成，但私人线索仍显著缩短路径。错误不会扣除
任何东西，near 也不触发特殊动画或声音。

live region 每次只播一次稳定摘要，例如：

```text
折面已经贴近；相位还没贴近。
```

range 连续拖动时，只在离散值真正改变时更新可见文本；读屏播报应在 `change`
或经过节流的 `input` 上发生，不能一帧一条。

## 7. 几何与规则分层

权威逻辑只输出整数 pattern model：

```js
{
  turnUnits: 2520,
  folds: 7,
  phaseStep: 11,
  wedges: [
    { index: 0, rotationUnits: 1155, mirrored: false },
    // ...
  ]
}
```

Canvas app 把 `rotationUnits` 换成弧度，重复绘制一组原创的三条折线/弧带。
Renderer 可以丢帧、缩小、关闭动效或完全失败，但不能改变：

- 当前选择；
- near/exact；
- phase 转换；
- REVEAL 权限；
- 私人内容何时公开。

图案不是验证码。Canvas 看不清、系统处于 forced-colors、图片被阻断或用户不看
画面时，文字线索和控件仍能完成同一状态机。

## 8. 内容与个性化

首版配置只允许：

```text
publicTitle
publicInstructions
foldHint
phaseHint
targetFolds
targetPhase
marks[2]
finalTitle
finalMessage
signature
```

所有文案都是纯文本。`marks` 是两枚简短称呼标记，不要求是拉丁首字母：

- 可以是一个汉字、一个拉丁字母、两个短 code point；
- 可以相同；
- 不允许 HTML、换行控制、双向控制符或超长字符串；
- 默认示例用虚构标记，不提交真实姓名。

最有价值的用户贡献点是未来 `config.js` 中的两条线索与两枚标记。当前阶段没有
生产脚手架，不要求用户提前写无法运行的内容；实现阶段再在有校验和默认值的
上下文里提供这一入口。

## 9. Code-native 视觉方向

只冻结语义，不在本阶段生产 UI：

- 中央是一枚低对比、可缩放的圆形折光图；
- 外圈表达折面重复，内圈表达 24 格相位；
- 左右标记在 complete 后进入两个稳定留白，不做爆炸式飞入；
- 状态和控件在真实 DOM，不画进 Canvas；
- 颜色必须配合轮廓、文字和纹理状态，不承担唯一信息；
- 背景、线条和标记均由 CSS/Canvas 原生绘制；
- 不需要 ImageGen、照片、纹理包、远程字体、图标库或 SVG 素材；
- 不模仿具体万花筒玩具、品牌、艺术家纹样或开源 demo 外观。

精确颜色、排版、构图、响应式与视觉确认应由后续独立 design 文档冻结。design
若要改变控件、阶段、内容可见性或规则，必须返回 spec，而不能由 CSS 临时创造。

## 10. 动效与声音

正常模式：

- 选择值改变后，用一次不超过 240ms 的几何过渡；
- near/exact 只改变静态轮廓和文字；
- complete 标记可用一次 `opacity` 淡入，但不平移、缩放或旋转进场。

reduced-motion：

- 所有状态直接投影；
- 不持续旋转、不补播历史；
- complete 直接创建标记和留言；
- 状态机和焦点时序不等待动画。

首版无声音。音效不是完成反馈，也不为音频增加开关、AudioContext 或共享依赖。

## 11. 焦点、读屏与降级

- Intro 激活后焦点到 tuning 标题；
- 折面按钮选择后焦点留在原按钮；
- range 操作后焦点留在 range；
- 进入 aligned 后焦点移到“照见我们”；
- complete 后焦点移到结尾标题；
- restart 后焦点移到公共标题；
- 状态变化用一个 `role=status`，不使用 assertive alert；
- Canvas 有简短说明，当前数值与状态从相邻 DOM 读取；
- Canvas 失败时显示静态 CSS fallback 和固定说明，不阻断按钮/range；
- no-JS 只显示公开介绍和启用 JavaScript 提示，不渲染私人内容；
- forced-colors 保留边框、focus ring、`aria-pressed` 文本与状态；
- 320px、200% text、400% zoom 不横向溢出。

## 12. 隐私决定

阶段可见性必须按“创建/卸载 DOM”执行，不能只靠 `hidden` 或透明度：

| 内容 | intro | tuning | aligned | complete |
| --- | --- | --- | --- | --- |
| 公共标题/说明 | 是 | 是 | 是 | 是 |
| 两条线索 | 否 | 是 | 是 | 可保留 |
| 当前值与状态 | 否 | 是 | 是 | 可保留摘要 |
| 两枚 marks | 否 | 否 | 否 | 是 |
| final title/message/signature | 否 | 否 | 否 | 是 |

配置源文件可读，所以这是“正常页面不提前展示”的叙事隐私，不是加密。README
必须明确告诉准备者：发送整个目录就等于发送其中的明文配置。

## 13. 明确不做

首版不加入：

- 单旋钮容差、连续角度物理或自由惯性；
- 随机题、每日题、难度、计时、分数、排行榜或成就；
- 自动解答、方向箭头、答案吸附；
- 照片/视频导入、截图导出、下载、分享、二维码；
- WebGL、shader、粒子系统、第三方 Canvas/数学库；
- 音频、震动、传感器或权限；
- 账号、storage、URL 配置、网络或分析；
- 多主题、调色器、纹样编辑器或默认随机配色；
- 用户自定义 folds 范围、phase 格数或 near 阈值；
- 将 marks 预绘在 Canvas、CSS content、模板或隐藏 DOM；
- 自动播放、持续自转、视差、闪烁或庆祝爆闪。

## 14. 进入 spec 的冻结决定

1. 稳定 ID `kaleidoscope-names`，主分类 surprise，A 级本地直开；
2. 唯一核心是 `folds ∈ [4,9]` 与 `phaseStep ∈ [0,23]` 的二维 exact 校准；
3. 两条公开线索分别对应两个轴；
4. 折面用六个原生按钮，相位用原生 range；
5. far/near/exact 不提供方向，错误无惩罚；
6. `2520` 整数圈单位只负责 pattern model，Canvas 不参与规则；
7. `intro → tuning → aligned → complete`，aligned 后控制锁定；
8. marks/final 只在主动 REVEAL 后创建；
9. Canvas failure、键盘、触屏、读屏与 reduced-motion 都有完整等价路径；
10. 首版零网络、权限、存储、运行依赖、素材与持续动画；
11. 玩法、图案、默认内容与实现完全原创；仅用标准校准平台边界。

规格阶段把这些决定变成 exact schema、常量、action/state、公开 DTO、错误语义、
DOM 合同、测试矩阵与验收 Gate，不重新扩展产品范围。
