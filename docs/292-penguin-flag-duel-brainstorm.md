# 企鹅冰原夺旗：brainstorm

## 已知约束

本轮只选择产品与规则方向，不创建生产目录或 UI。

- 候选 ID：`penguin-flag-duel`
- 对外标题：企鹅冰原夺旗
- 分类：双人对抗
- 等级目标：A，`file://` 双击直开
- 设备：同一设备、同一屏幕、同时输入
- 必须有：低摩擦移动、碰撞、中立旗、拾旗、撞落、回基地、对称地图、明确平局
- 输入：WASD + 方向键，以及等价双指触控
- 确定性：60 Hz 固定步、逐 tick 输入重放
- 素材：原创 CSS/内联 SVG 几何，不用真实品牌或现成企鹅素材
- 当前决策：Conditional Go

## 一句话体验

> 两只企鹅在一块低摩擦冰场上争夺中央旗；抢到只是上半场，带着旗滑回自己的基地且不被撞落，才算真正得分。

情绪目标不是硬核物理模拟，而是“看见对方刹不住、临门被撞掉旗、压哨滑进基地”的轻松欢呼。

## 方向发散

### 方向 A：单旗往返赛

一面中立旗，双方从各自基地出发。触旗后携带，碰撞掉落，回己方基地得分。

优点：

- 夺旗身份最清楚；
- 同一张地图自然产生去程抢位和返程追逐；
- 规则可以用一句话解释；
- 状态量小，适合严格重放；
- 与 `soft-sumo`、`orbit-star-race` 差异最大。

风险：

- 持旗者如果不减速，领先方可能无法被追上；
- 中路直线可能成为唯一最优路线；
- 掉旗判定和进基地判定的同刻顺序必须冻结。

### 方向 B：双旗偷家

双方基地各有一面旗，玩家去对面偷旗并送回自己的基地；自己的旗不在家时不能得分。

优点：

- 更接近传统 capture-the-flag；
- 攻守转换丰富；
- 可以出现交换旗和守家。

风险：

- 单屏两人时双方可能各拿一面旗互不相见；
- “本方旗是否在家”增加解释和僵局；
- 两面旗、两套归还规则显著扩大同刻状态空间；
- 第一版容易从轻游戏变成规则说明页。

### 方向 C：传旗进门

中央旗不是携带物，而是可被碰撞推动的冰块；把它撞进己方门得分。

优点：

- 物理反馈直接；
- 不需要持有状态；
- 双方始终围绕同一物体。

风险：

- 本质接近冰上足球；
- 会弱化“拾取、持旗、撞落”的候选要求；
- 复杂物体碰撞比专用持旗状态更难稳定；
- 与 `paper-soccer` 的产品印象更近。

### 方向 D：分段接力夺旗

每次拿旗后必须依次穿过两个检查点再回基地，检查点顺序左右镜像。

优点：

- 避免中路直返；
- 可以制造更长追逐；
- 路线选择更可见。

风险：

- 检查点增加认知负担；
- 规则从“抢了带回家”变成记路线；
- 第一版很难证明检查点真的提升乐趣。

## 决策

选择 **方向 A：单旗往返赛**。

原因：

1. 它是满足候选身份的最小闭环；
2. 一面旗避免双旗交换导致的僵局；
3. “同刻等距不归属、碰撞先掉旗、再判断得分”可形成完整原子规则；
4. 固定对称图和无随机输入让确定性证据最强；
5. 第一版可在不增加技能键的情况下，靠惯性、路线和身体拦截产生对抗。

方向 B、C、D 均不进入第一版，也不预留隐藏规则。

## 核心循环

```text
倒计时
  → 双方从镜像出生点滑向中央旗
  → 一方拾旗
  → 持旗者减速返程 / 对手预测路线拦截
  → 被撞则掉旗，双方重新争夺
  → 携旗进入己方基地得分
  → 短暂重置
  → 先到 3 分，或 90 秒后比较比分
```

这个循环中有三个可读的戏剧点：

- 抢旗：谁能用惯性更准确地切过中央点；
- 护旗：持旗者不能只按住回家方向，需要提前刹车和绕障碍；
- 截旗：追击者不必接触旗，只需选择对方返程轨迹上的交点。

## 规则定案

### 场地

- 固定逻辑尺寸 `1024 × 640`；
- 左右镜像；
- 左右基地各占 144 逻辑单位深度；
- 中央旗固定在 `(512, 320)`；
- 两名玩家分别出生在 `(160, 320)` 与 `(864, 320)`；
- 上下各放置一对镜像的薄冰岛，打破全程直线最优解；
- 障碍最薄尺寸必须大于玩家单 tick 最大位移与直径相关的安全阈值。

不使用随机地图、移动障碍、缩圈或地面道具。

### 移动

- 每席有静止和八方向意图；
- 按方向施加加速度，松开后弱阻尼滑行；
- 斜向加速度用固定查表归一；
- 玩家可通过反向输入制动，但不会立即停下；
- 玩家和墙有低回弹，碰撞不能增加系统总速率；
- 持旗时加速度和最高速度都降为普通状态的 75%。

不增加冲刺、蓄力、体力条或技能键，以免靠近 `soft-sumo`。

### 旗

- 无主旗与玩家圆形触区相交即可进入候选拾取；
- 只有一名候选时由该玩家拾取；
- 两人同刻都符合时，比较移动/碰撞完成后的距离平方；
- 距离更近者拾取；完全相等则保持无主；
- 旗跟随携带者，但逻辑中保存 `carrierSeat`，不把旗作为第三刚体；
- 持旗者与对手发生玩家碰撞时先掉旗；
- 掉旗点取碰撞后两玩家中心的整数中点并限制在可通行区域；
- 掉旗后 15 tick 内不可拾取；
- 掉旗 480 个有效 tick 后仍无人拾取，则回中央；
- 得分后旗立刻回中央。

“有效碰撞”指该 tick 玩家圆形发生重叠并执行了位置修正；仅擦过视觉外圈不掉旗。

### 计分与终局

- 携旗者中心进入自己的基地即得 1 分；
- 同 tick 若同时碰撞对手和进入基地，先掉旗，因此不得分；
- 目标分数 3；
- 有效比赛时间 5400 tick（90 秒）；
- 任一席先到 3 分立即结束；
- 时间归零时高分者胜，同分为平局；
- 最后一个 tick 的规则结算先完成，再检查时间；
- 得分后 90 tick 重置倒计时，双方回出生点，期间计时停止；
- 暂停和恢复倒计时也不消耗有效时间。

## 状态与阶段草案

```text
intro
input-check
countdown
playing
paused
capture-reset
match-result
```

`input-check` 是外层输入能力检查，不修改比赛胜负状态。核心规则只接收标准化意图：

```text
START
STEP { intents: [0..8, 0..8] }
PAUSE { reason }
RESUME
RESTART
```

UI 按键按下态不写进核心状态；每个固定 tick 编译为一对意图后才写入重放日志。

## 输入设计

### 键盘路径

- 左席：WASD；
- 右席：方向键；
- 按 `KeyboardEvent.code`，不按字符；
- 同轴相反方向相消；
- Escape 暂停/恢复；
- 四组双人斜向矩阵自检逐项展示检测结果；
- 自检失败时保留开局按钮，但提示改用双指触控。

### 触控路径

每席一个 3×3 方向盘：

```text
↖  ↑  ↗
←  ·  →
↙  ↓  ↘
```

- 中央格不是动作键；
- 每个方向是原生 `button`；
- 两席各绑定一个 pointerId；
- capture 以后即使手指滑出也保持当前方向，松开/取消才清除；
- 玩家换方向需抬起再按另一个格，避免一个触点跨格时产生浏览器差异；
- 控制区 `touch-action: none`，页面其他区域仍允许正常滚动。

不设计虚拟摇杆，因为连续角度会使键盘与触控不等价，也增加漂移和死区调参。

## 同刻冲突表

| 同一 tick 事件 | 结果 |
| --- | --- |
| 两人等距碰到无主旗 | 无人拾取 |
| 两人都碰旗但距离不同 | 更近者拾取 |
| 持旗者碰到对手并进入基地 | 先掉旗，不得分 |
| 掉旗后两人仍与旗重叠 | 15 tick 锁定，不能立刻拾取 |
| 计时最后 tick 发生得分 | 得分有效，再判终局 |
| 一方到 3 分且时间同时归零 | 目标分终局成立 |
| 后台导致长帧 | 暂停，不补算 |
| 两席同轴输入相反键 | 该席该轴为 0 |

## 视觉方向

### 主题

“夜蓝冰面上的两条围巾”：

- 背景为深蓝静态渐变；
- 冰场是浅青轮廓和少量原创裂纹；
- 左席使用圆尾围巾和点阵基地纹；
- 右席使用燕尾围巾和条纹基地纹；
- 旗用中性暖黄，避免偏向任一席；
- 玩家身体用简单椭圆和小几何，不追求现成卡通角色相似度。

### 信息层级

1. 顶部固定：比分、有效时间、暂停；
2. 中部：完整冰场、旗的占有/锁定状态；
3. 底部或两侧：两席控制说明与触控方向盘；
4. 中央覆盖层：倒计时、暂停、得分重置和结果。

旗的状态不能只靠位置：

- 无主：旗杆完整；
- 被携带：旗出现在玩家背后，并在计分条标注“持旗”；
- 锁定：旗周围显示静态断续环和数字；
- 回中央：用一次短淡入，不做长距离飞行动画。

## 降动效方向

默认动画只包含玩法本身的位移和非常短的得分反馈。降动效下：

- 关闭雪粒、背景漂移、镜头晃动、缩放和弹跳；
- 得分反馈改为静态高亮与文字；
- 旗回中央直接切换或短淡入；
- 不改变物理速度、tick、碰撞或比赛时长。

不加入闪烁、频繁旋转和全屏冲击波。

## 声音决策

第一版不加入音频文件或 Web Audio。原因：

- 声音不是闭环成立条件；
- 自动播放限制会增加首开分支；
- 无声环境和本地直开仍应完整；
- 原创音效也需要额外试听和降噪验收。

未来若加入，必须默认可静音、首个用户手势后启用，并单独记录素材来源。

## 失败与降级

| 条件 | 行为 |
| --- | --- |
| JavaScript 不可用 | 显示静态说明，不展示伪造的可玩状态 |
| 键盘矩阵自检失败 | 保留开局，明确建议触控 |
| Pointer Events 不可用 | 不宣称触控支持；键盘仍可开局 |
| 页面失焦/隐藏/pagehide | 清输入并暂停 |
| 帧间隔 >250 ms | 清 accumulator 并暂停 |
| 状态或动作 schema 非法 | fail closed：回安全初始态或忽略非法动作 |
| 非有限数、越界整数 | 拒绝进入物理运算 |

## 明确不做

- 联网房间、排行榜、AI 对手；
- 随机地图、随机风向、随机旗位；
- 双旗偷家、检查点、缩圈；
- 冲刺、技能、道具、体力；
- 自定义图片上传或名字持久化；
- 外部字体、第三方企鹅素材、真实品牌；
- 粒子系统、音频、振动；
- 跨刷新保存或导出重放。
