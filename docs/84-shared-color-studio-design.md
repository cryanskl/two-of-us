## 2. 视觉主张

唯一创意方向是“**夜间纸上调色桌**”：两个人不是在操作数字仪表盘，而是在深墨蓝桌面上共同调一张真实有纤维感的色笺。

- 背景：深墨蓝未涂布桌面，低对比纸纤维；
- 焦点：目标色笺较小，共享调色纸较大；
- 结构：开放排版和黄铜分隔线，不使用 dashboard 卡片墙；
- 材质：撕边纸、干刷颜料、哑光黄铜；
- 颜色：目标和当前色是唯一高彩度焦点；
- 字体性格：题名/色笺名为高对比中文宋体，按钮/状态/刻度为克制黑体；
- 动效：颜料边缘轻微呼吸、刻度游标短滑、成功盖章轻落；不做闪烁、粒子、烟花或摇屏。

## 3. 第一视口与容器模型

### 3.1 桌面 playing，1504×1046

```text
标题（居中）                             倒计时（右上）
              2 / 5 海玻璃

          [目标小色笺] [共享大调色纸]

玩家 1 · 色相                 玩家 2 · 明度
12 格环形展开轨                 9 格线性轨
方向/距离                       方向/距离
[A 逆时针] [D 顺时针]          [J 深一点] [L 亮一点]

                   持久状态行
```

- 页面内容最大宽度：`1120px`；
- 标题区不包卡，色笺与控制区也不包进巨型圆角外壳；
- 目标色笺约为共享色笺宽度的 60%；
- 两个控制区用一条细黄铜竖线和各自标题分隔，不使用两张独立 panel；
- 倒计时与标题同层，个位秒数不推动标题水平位置；
- 底部状态行可在 1046px 内可见，但优先级低于四个按钮。

### 3.2 移动 playing，390×844

概念原图是 853×1844，与 390×844 比例一致。实现按真实 390×844 验收：

```text
标题
2 / 5 海玻璃 · 17.4 秒
[目标色] [当前色]
玩家 1 色相 + 12 格轨 + 状态
玩家 2 明度 + 9 格轨 + 状态
[A 逆时针] [D 顺时针]
[J 深一点] [L 亮一点]
```

- 概念中的桌边碗/刷只来自背景裁切，不能用绝对定位 UI 模拟；
- 四按钮保持 2×2，每个最小高度 56px；
- 轨道允许压缩格间距，不隐藏目标/当前指针、格号或方向文字；
- 390×844 优先一屏完成；320×700 可自然滚动，不以缩到不可读换一屏；
- 手机色笺并排，目标约 42%，当前约 58%；320px 若文字拥挤可改成等宽，但仍并排。

### 3.3 桌面 complete，1504×1046

- 页面标题和一句完成标题在纸册外；
- 中央是唯一允许的大型纸册容器；
- 五张色笺在纸册内形成轻微弧线/错位，不能变成规整五列数据卡；
- 每张显示名称、代码原生色块与 H/L 坐标；
- 结语、`5 张色笺 · 共同完成` 和“重新调一册”形成一条垂直终点；
- 不用弹窗、遮罩、奖杯、星星、彩带、重复结果标题或统计卡。

## 4. 设计令牌

### 4.1 颜色

```css
--ink-950: #06131f;
--ink-900: #091a29;
--ink-800: #102638;
--paper-50: #f4efe3;
--paper-100: #e9dfcc;
--paper-ink: #292923;
--brass-300: #dfb36f;
--brass-500: #b77b35;
--teal-300: #61b9ad;
--teal-500: #249b92;
--danger-soft: #c77b70;
--focus: #f6d79d;
```

- 背景必须是深墨蓝，不替换为纯黑、紫色或暖棕；
- 纸面是自然暖白，不能把整个页面背景改成奶油白；
- 黄铜只用于细线、刻度编号、计时和重点边框，不能铺大面积渐变；
- 目标/当前色由配置坐标派生，不硬编码成概念中的海玻璃色。

### 4.2 字体

仅用系统字体，无远程字体：

```css
--font-display: "Songti SC", "STSong", "Noto Serif CJK SC", serif;
--font-ui: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", sans-serif;
```

建议桌面字号：

| 用途 | 大小 / 行高 | 字重 |
| --- | --- | --- |
| H1 | `clamp(2.4rem, 4vw, 4.4rem) / 1.05` | 600 |
| 倒计时 | `clamp(2rem, 3vw, 3.6rem) / 1` | 500 |
| 色笺名/玩家标题 | `1.5rem / 1.25` | 600 |
| 方向状态 | `1.1rem / 1.45` | 500 |
| 按钮 | `1rem / 1.1` | 650 |
| 坐标/刻度 | `0.78rem / 1.3` | 550 |

移动端 H1 `clamp(1.85rem, 8vw, 2.55rem)`；按钮文字不得依赖浏览器默认 16px。

### 4.3 间距、线与阴影

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-6: 24px;
--space-8: 32px;
--space-12: 48px;
--rule: 1px solid rgb(223 179 111 / 0.72);
--paper-shadow: 0 14px 34px rgb(0 0 0 / 0.26);
--control-radius: 8px;
--paper-radius: 3px;
```

- 按钮只有小圆角，不使用 24px/999px 胶囊；
- 纸片边缘用 CSS `clip-path` 或轻微不规则 pseudo-element 表达，不能把每个区块变成圆角 card；
- 聚焦环 `2px solid var(--focus)` + `3px` offset，在墨蓝和纸白上都清楚。

## 5. 组件与图标清单

### 5.1 允许的组件族

- `StudioHeader`：H1、轮次名、稳定宽度倒计时；
- `ColorPaper`：target/current 两种尺寸变体；
- `HueRail`：12 个圆形色点、当前实心/外环、目标虚线箭头；
- `LightnessRail`：9 个方形阶梯、当前实心/外环、目标虚线箭头；
- `AxisStatus`：玩家编号、轴名、距离、方向、matched；
- `ControlButton`：键帽 + 动作文字；
- `RoundResult`：success/timeout 两种开放式结果行；
- `ColorAlbum`：complete 独有的纸册和五张色笺；
- `LiveStatus`：视觉低调但持久的状态行。

禁止新增 tab、导航栏、侧栏、设置 drawer、徽章、进度 pill、统计卡、模态框或卡片网格。

### 5.2 图标/符号

概念中只允许：

- 当前指针：向下实心小三角，CSS border 或内联 SVG；
- 目标指针：虚线竖杆 + 向下空心/青色三角；
- matched：小型对勾 + 双环，不只变绿；
- 状态提示：圆圈内 `i`，内联 SVG，1.5px 黄铜线；
- 返回作品库：左向细箭头，可用内联 SVG；
- favicon：原创的两滴颜料汇合成一张小色笺，不使用 emoji。

所有图标使用 `currentColor`、清楚 viewBox、圆角端点和统一 1.5–2px 线宽。按钮方向不能只用文本字符箭头替代概念的指针图形。

## 6. 允许文案清单

### 6.1 首屏/playing

以下是首屏允许出现的可见文案；除配置中的色笺 title/note 外，不增加说明标签：

- `把颜色调到一起`；
- `{round} / 5 {title}`；
- `{seconds} 秒`；
- `目标色`；
- `我们调出的颜色`；
- `H {current}/12 · L {current}/9`；
- `玩家 1 · 色相`；
- `玩家 2 · 明度`；
- `还差 {n} 格，逆时针转` / `顺时针转`；
- `还差 {n} 格，再深一点` / `再亮一点`；
- `色相已经合拍` / `明度已经合拍`；
- `A 逆时针`、`D 顺时针`、`J 深一点`、`L 亮一点`；
- `玩家 1 只调色相，玩家 2 只调明度。`。

ready/countdown/暂停/结果所需文案以规格和 config 为准，但不得在首屏增加 hero eyebrow、玩法徽章或冗余副标题。

### 6.2 complete

- `把颜色调到一起`；
- `五张颜色，都被我们收下了`；
- 五张固定 title；
- `你转过色相，我照亮明暗。最后留下的是我们一起调出的颜色。`（默认，可由 composeStudioResult 改写）；
- `5 张色笺 · 共同完成`；
- `重新调一册`；
- `返回作品库`。

### 6.3 Above-the-fold copy diff Gate

浏览器验收必须抓取首屏可见文本，与 6.1/6.2 对照。新增、删除、重命名或重复的可见文字均需修复或列为有理由的刻意偏离。

## 7. 媒体与资产处理

### 7.1 生产背景

- 用 `body::before` 或页面固定背景层加载 `pigment-table.webp`；
- `background-size: cover`，默认 `background-position: center`；
- 桌面保留左上纸角、右上黄铜碗和右下笔尖；
- 手机可裁掉右上/右下物件，不能为了保留装饰压缩 UI；
- 不在背景上添加着色 overlay；若文本对比不足，只能调整内容区的局部实色底/阴影或使用同色 edge fade；
- 图片加载失败时以 `--ink-950` + 两层低对比 radial/noise-like CSS 背景降级，不创建占位框。

### 7.2 代码原生内容

以下绝不能烘焙进背景或概念截图：标题、色笺名、坐标、倒计时、色块、两条刻度、目标/当前指针、按钮、结果、色册条目。它们必须是真实 DOM/CSS 状态。

### 7.3 生成记录

- 工具：内置 ImageGen；
- 概念提示词：完整本地双人调色 UI，指定桌面 playing、移动 playing、桌面 complete 三种状态；
- 生产提示词：无字、无 UI、中央 80% 留空的深墨纸上调色桌；
- 禁止项：水印、文字、品牌、人物、霓虹、玻璃拟态、卡片墙；
- 原创边界：没有输入、临摹或编辑第三方项目截图/素材。

## 8. 核心工作流与状态视觉

### 8.1 ready

- 使用 playing 的同一桌面，不引入营销 hero；
- 主色笺显示第一题的目标/起点预览；
- 四控制可见但 disabled；
- 唯一主按钮“开始调色”；
- 说明一行，不增加规则卡列表。

### 8.2 countdown

- 倒计时取代右上 round timer，主舞台不变；
- 四按钮保持 disabled；
- 只用数字/轻微缩放，不闪屏、不遮罩整页。

### 8.3 playing

- 当前色块即时更新；
- 当前游标用 140–180ms 短滑；
- 距离数字与方向文字同步；
- 轴命中用对勾/双环/`已经合拍`，但另一条轴仍可操作；
- 24 秒以下不改变页面大面积颜色，10 秒以下可让计时黄铜色变成柔和珊瑚色，不能闪烁。

### 8.4 paused

- 不使用弹窗；在主舞台上方显示一条纸签 `调色暂停了` 与“继续”；
- 当前颜色和刻度仍可见但控制 disabled；
- 隐藏/失焦自动暂停不抢焦点。

### 8.5 round-result

- success：共享色笺出现克制盖章线框和 title；按钮 `收下这张`；
- timeout：目标/当前并列保留，文字 `时间到了，颜色没有丢。一起再调一次。`；按钮 `再调一次`；
- 不用 modal overlay，不隐藏差异信息，不播放失败红屏。

### 8.6 complete

- 切换到纸册构图；
- 五张色笺由 completed 数据生成；
- 色册 title/坐标/色块是 DOM；
- “重新调一册”是唯一主按钮，“返回作品库”是次级文字链接。

## 9. 响应式与可访问性 Gate

| 视口 | Gate |
| --- | --- |
| 320×700 | 无横向溢出；四键 2×2、≥52px；轨道/状态不截断；允许自然纵向滚动；结果一次滚动可达 |
| 390×844 | 目标/当前并排；四键 ≥56px；关键玩法尽量一屏；双人区域等权；标题/个位秒不挤压 |
| 1504×1046 | max-width 生效；目标小/当前大；两轴同层；四键与状态线首屏；complete 五张不重叠 |

共同：

- 200% 字号仍可完成；
- 色彩之外有文字、数字、形状和刻度；
- focus-visible 清楚；
- reduced motion 关闭非必要运动；
- `role=status` 不逐 tick 宣读；
- 键盘、鼠标、触摸使用同一 action；
- 背景加载失败不降低文字对比或移除结构。

## 10. 实现前提取清单

- 背景色锁定：深墨蓝，不是白/奶油/紫；
- 容器锁定：开放式舞台；只有 complete 有纸册；
- 目标/current 尺寸关系锁定：桌面 0.6:1，移动紧凑并排；
- 轨道锁定：hue 圆点、lightness 方块；
- 指针锁定：当前实心白、目标青色虚线；
- 按钮锁定：黄铜细边、小圆角、内嵌键帽；
- 字体锁定：系统宋体 + 系统黑体；
- 媒体锁定：背景无 overlay，CSS fallback；
- 首屏允许文案锁定：见第 6 节；
- 禁止组件锁定：无卡片墙、pill、badge、modal、侧栏、设置面板。

## 11. 刻意偏离与可实现性裁决

概念图是视觉规范，不是运行截图。预先允许的偏离只有：

1. 移动概念原图为 853×1844；实现按其比例在真实 390×844 验收；
2. 概念中的中文个别字形/坐标与真实配置可能不一致；代码必须以规格准确文案和 H/L 索引为准；
3. 概念纸撕边由 CSS clip-path/pseudo-element近似，不要求逐像素复刻随机纤维；
4. 完成态概念有实体书页影像；实现用 CSS 纸册容器和生产背景组合，不新增第二张 book bitmap；
5. 320×700 允许纵向滚动，而概念只覆盖移动 390 比例；
6. 系统字体因平台不同存在字形差异，但层级、大小、行高和 serif/sans 角色必须保持。

除此之外，布局、文案、颜色温度、组件族、背景处理或状态结构的变化都不是默认自由发挥，必须在验收 ledger 解释并修复可修复漂移。
