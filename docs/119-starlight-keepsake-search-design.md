## 2. 视觉命题

这是“共享夜晚的旧木桌”，不是侦探游戏、寻物商品页、SaaS 面板或婚礼请柬。玩家移动一盏克制的暖光，让五件平常物品依次从深靛夜色里留下来。

核心原则：

1. **先看夜色，再看控件**：桌面舞台占主要面积，控制栏像书页边注；
2. **光只揭示，不评分**：光圈表达当前位置和连续停留，不出现分数、连击、倒计时或猎物准星；
3. **发现会留下**：已找到物品获得稳定微光，名称与短句进入 DOM 列表，未找到秘密不预埋；
4. **完成是整间屋子变暖**：第五件同 tick 撤去暗幕并出现完整信，不弹奖杯、彩屑或通用模态框；
5. **素材不拥有规则**：背景像素不参与命中；目标几何、停留 tick 和发现顺序只来自 reducer。

- 标题、纪念物名和完成信优先用系统中文衬线：`Songti SC, STSong, Noto Serif CJK SC, Georgia, serif`；控件与状态用 `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`。

## 4. 生产背景与坐标校准

最终背景由首张生产图做一次位置纠正后接受。第一版氛围合格但车票、双杯和星光偏离预设热区；第二版提供更干净的负空间与唯一目标，因此 P4 以接受资产的实测视觉中心校准规格。一次校准后坐标冻结，逻辑与前端不得各自再猜。

| ID | 物件 | 1000×620 中心 / 半径 | 视觉说明 |
| --- | --- | --- | --- |
| `k1` | 空白旧车票 | `(180,100) / 64` | 左上，抽象短线不可作为秘密文本 |
| `k2` | 两只杯子 | `(800,105) / 82` | 右上，两杯合计一个目标 |
| `k3` | 即时照片 | `(295,455) / 70` | 左下，画面内容不可读 |
| `k4` | 黄铜钥匙 | `(685,455) / 70` | 右下，保留链条但只算一个目标 |
| `k5` | 窗边星光 | `(948,360) / 52` | 右侧窗内，热区向内覆盖边缘 |

## 5. 页面结构

### 5.1 桌面目标 1280×800

```text
┌──── 编辑式控制栏 26–29% ────┬──────── 夜桌舞台 71–74% ────────┐
│ 标题 / 阶段说明             │ 背景 → 暗幕 → 已发现微光          │
│ 主操作 / 直接点亮           │ 当前光圈 → 停留环 → 完成暖光      │
│ 1 / 5 圆点                  │                                    │
│ 已发现名称与短句            │                                    │
│ 本地 · 不保存               │                                    │
└─────────────────────────────┴────────────────────────────────────┘
```

- searching 时控制栏可滚动但标题、进度与至少一个操作应在首屏；舞台不被 DOM 卡片覆盖。
- complete 保持同一双栏，左栏把说明区替换为短信，动作改为“再找一次”和“回到作品集”。
- Canvas 仅承担舞台投影并 `aria-hidden="true"`；阶段、进度、发现列表、信和操作都是真实 DOM。

### 5.2 移动目标 390×844 与 320×700

- 单列顺序：短标题 → 一行说明与进度 → 舞台 → 操作 → 已发现列表 → 隐私尾注。
- 舞台宽度接近视口，保持 1000:620；390×844 首屏至少看到完整舞台与主操作上缘，完整列表允许向下滚动。
- 概念稿是 852×1846 的完整长页参考，不等于浏览器首屏；实现不得为了复刻长画布而制造空白。
- 320px 下操作纵向排列；舞台以 `touch-action: none` 接受拖动，舞台外仍保持普通页面滚动。

## 6. 舞台分层

从后到前：

1. `keepsake-night.jpg` 或深靛/胡桃木 CSS 回退；
2. 整体暗幕，complete 时撤去；
3. 已发现目标的稳定局部微光；
4. 当前可移动光圈与边缘羽化；
5. 连续停留进度环，只在命中未发现目标时显示；
6. complete 的五个细小标记与整体暖色；
7. 舞台外 DOM 控制栏、稳定 live region、发现列表和完成信。

若 Canvas 2D context 不可用，隐藏空舞台假象，展示背景和可读说明，并把“直接点亮”提升为主操作。背景加载完成只触发重绘，不派业务 action。

## 7. 状态投影

| phase | 舞台 | 控制栏 |
| --- | --- | --- |
| `intro` | 背景全暗，光心居中但不累计 | 标题、完整短句、“先把灯放下”“直接点亮” |
| `searching` | 暗幕、光圈、匿名热区、已发现微光 | 进度、暂停、直接点亮、真实发现列表 |
| `paused` | 画面冻结，停留环不推进 | 暂停原因、继续、直接点亮 |
| `complete` | 整体变暖、五件均可见、五个克制标记 | 完整信、5/5、再找一次、回作品集 |

`direct` 可从部分发现进入 complete，但 reducer 的 `foundIds` 仍保持真实 0–4 项；完整五项只通过 `revealedItems` 投影。视觉可以全部照亮，状态不得伪造历史。

## 8. 冻结文案与概念差异

- 主标题固定为“把夜晚照成我们”。
- 首屏说明以规格/config 为真源；桌面概念的“有些小事藏在暗处，等你慢一点，把光停在它们身上。”可作为默认文案。
- 主动作：intro“先把灯放下”，searching“暂停一下”，paused“继续找”，complete“再找一次”。
- 等价路径固定保留“直接点亮”；不隐藏、不弱化为无焦点装饰。
- 进度使用“已经亮起 n / 5”和五个可见圆点，不只靠颜色。
- “本地 · 不保存”持续存在；不新增分享、导出、上传、保存或统计。
- 概念票面、信件和发现短句只是构图示例；生产 DOM 使用 config，图片内任何伪文字都不可复制、朗读或作为规则输入。

## 9. 动效与无障碍

- 光圈直接跟随输入，不做滞后追踪；停留环按整数 tick 投影，不能用 CSS 动画伪造进度。
- 已发现微光可在 180ms 内淡入；完成整体升温不超过 600ms，不缩放信件，不放彩屑。
- reduced motion 下取消淡入与呼吸，只保留立即状态变化。
- 页面隐藏、失焦、pointer cancel/lost capture 和超过 250ms 帧间隔都冻结累计；视觉与 reducer 同步暂停。
- 颜色不是唯一提示：DOM 提供阶段、n/5、当前命中进度和发现名称；live region 只在阶段或发现变化时播报，不逐 tick 播报。
- forced colors 下隐藏背景与暗幕装饰，以系统色显示光圈、停留环、进度和按钮边界。

## 10. Fidelity ledger 与刻意偏离

| 维度 | 概念意图 | 生产约束与决策 |
| --- | --- | --- |
| 布局 | 桌面窄左栏 + 大夜桌 | 保留双栏；低宽转单列，不做卡片网格 |
| 色彩 | 深靛、胡桃木、琥珀、羊皮纸 | 保留色温；正文对比不足处提高到可读值 |
| 材质 | 旧纸、陶杯、黄铜、木纹 | 背景位图承载；控件不模拟玻璃或霓虹 |
| 光圈 | 暖琥珀圆形揭示 | Canvas 实时绘制，图片不烘焙暗幕或光圈 |
| 热区 | 五件可识别物品 | 以接受背景实测中心校准一次，像素不参与命中 |
| 双杯 | 概念完成态有两个装饰标记 | **明确改为一个目标、一个进度单位** |
| 票面 | 概念含可读车票细节 | **明确不复制**；运行背景仅抽象伪线，秘密在 DOM |
| 进度 | 1/5、2/5、5/5 与圆点 | 保留文字和圆点；停留进度另用单环 |
| 移动 | 长页完整内容 | 保留内容顺序；首屏按 390×844 重新压缩，不照搬画布高度 |
| 完成 | 同一场景整体变暖 + 左栏信 | 保留；信为 DOM 内联区域，不是图片或模态框 |
| 控件 | 琥珀主按钮、深色次按钮 | 原生 button、48px、可见焦点、键盘可达 |
| 隐私 | 本地 · 不保存 | 零存储、零网络；持续可见 |
| 图标 | 概念有锁与小圆标 | 用 CSS/原生 SVG，不引入图标依赖 |
| 背景裁切 | 概念靠边星光 | 保持完整比例，禁止 cover 丢失右侧目标 |
