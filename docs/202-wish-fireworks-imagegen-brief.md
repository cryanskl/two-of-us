## 1. 视觉任务

为一个直接双击 `index.html` 即可打开的中文情侣惊喜页面设计完整多状态界面。收礼者主动开始后，选择五档高度，以按住/松开或直接点击的方式依次点燃三束必定成功的烟火。每一束只公开一个 9×9 点阵字；默认依次是“我 / 爱 / 你”。第三束落定后，页面才展示图案说明、称呼、私人标题、留言和署名。

这不是跨年晚会、婚庆海报、赌场式奖励、粒子技术 demo 或射击游戏。目标气质是：午夜、亲密、克制、有期待，像两个人在安静屋顶把三句话交给夜空。

首轮必须生成十五张独立、清晰、可实现的完整页面概念，不以一张压缩总览或研究板代替状态细节：

1. `W1`：1504×1046 desktop intro，未主动开始；
2. `W2`：1280×800 desktop ready0，准备第一束；
3. `W3`：1280×800 desktop holding，第一束正在蓄光；
4. `W4`：1280×800 desktop bursting1，第二束上升/成字中；
5. `W5`：1504×1046 desktop ready2，前两字已留下；
6. `W6`：1504×1046 desktop complete，完整默认结果；
7. `W7`：390×844 mobile ready1，第一字已留下；
8. `W8`：390×844 mobile complete，完整结果流；
9. `W9`：844×390 landscape complete；
10. `W10`：844×390 landscape ready2，完整横屏控制；

## 2. 冻结视觉方向

### 2.1 核心意象

方向为“午夜屋顶的一封活字夜空信”：

- 背景是深靛蓝、近黑蓝的无人物夜空与极克制的屋顶/窗台下沿，不出现城市地标、烟花大会或观众；
- 一条横向“留字轨”承接已经完成的点阵字，像薄纸压痕与星图刻线的结合，不做三个卡片槽；
- 烟火点使用暖象牙白与柔金，当前升空轨迹可带少量沉珊瑚色；不使用饱和红、霓虹彩虹或全屏闪白；
- 点燃控制像一枚低矮、哑光、可握住的屋顶发射台：深梅红或氧化铜色，只作为唯一强交互形体；
- 完成结果像从夜空下沿展开的一张窄幅信纸，中文衬线内容字体与克制的无衬线控件字体分工明确；
- 光晕只服务当前烟火点与焦点层级，不使用 bokeh、漂浮 orb、满屏 glitter 或无意义星星铺底。

创意强度约 7/10，低到中密度。一块夜空是唯一主舞台，三字留痕是第二层级，complete 的开放信笺是最终层级。

### 2.2 页面构图

- 页头开放排版，不做导航、Logo、hero eyebrow、badge、pill 或巨型圆角 wrapper；
- DOM 视觉顺序必须保持：页头 → 固定说明 → 夜空舞台 → 已公开三字列 → 进度 → 发射控制 → 完成结果 → 主动作 → 固定隐私说明；
- desktop intro 用大面积安静夜空与一个明确的 `开始点光`，不展示发射控制、字位或未来结果；
- ready/holding/bursting 让夜空占主要面积，已公开字列贴近舞台下沿，进度与控制组成一组开放式操作带；
- complete 保持同一夜空与三字位置，结果信笺在其后自然展开，不覆盖舞台，也不变成 modal、翻面贺卡或居中浮层；
- 390px 使用单列：题名与说明 → 夜空 → 已公开字列 → 状态 → 发射控制/结果 → 主动作 → 隐私说明；
- 844×390 可让夜空与结果并排，但不得改变 DOM 阅读顺序、裁掉署名/重播或产生横向滚动；
- 不使用 card grid、bento、dashboard panel、carousel、tab、HUD、浮动工具条或排行榜结构。

### 2.3 签名组件语言

允许的 4 个视觉母题：

1. **三段留字轨**：只为已完成前缀呈现真实字符与点阵余辉；未完成位置不画轮廓、问号、锁或占位卡；
2. **五档高度刻线**：原生 select 保持真实可操作外观，其容器可复用发射台的细刻线，但不能伪装成仪表、瞄准器或概率条；
3. **按住光槽**：holding 可在 `按住蓄光` 按钮/发射台内显示单向、非闪烁的蓄光填充；不增加百分比、计时、等级名或“完美”区间；
4. **夜空短笺**：complete 的五节点结果维持一张开放纸面的阅读流，不拆成五张卡，也不加入分享、下载或收藏控件。

图标只允许极简上升方向与重播方向的生产 SVG，并且只有接受概念确实需要时才使用；按钮文字不能由图标替代。不得使用 emoji、烟花字体图标或第三方图标字体。

## 3. 状态概念合同

### W1 — desktop intro

- H1：`今晚，点三束光`
- 固定说明：`按住蓄光，松开就会发射；也可以选好高度后直接点燃。每一束都会成功。`
- 夜空只有无语义、低对比的静态轮廓，不能出现火箭、点阵字、三字槽位、已完成束数或私信形状；
- 唯一动态主状态：`还没点亮第一束。`
- persistent 主按钮：`开始点光`
- 不显示高度 select、点燃按钮、已公开字列内容或结果信笺；
- 固定隐私说明在页面结尾可见，不能变成安全 badge 或“已加密”声明。

### W2 — desktop ready0

- 唯一动态主状态：`准备点燃第 1 / 3 束。`
- 已公开字列为空，夜空中不出现“我”的目标、轮廓、label 或未来任一字符；
- 发射控制精确显示 `烟火高度`、原生五档 select、`按住蓄光`、`直接点燃` 和 `无需蓄满，每一束都会成功。`；
- select 概念选中 `中`，其余选项不展开为自制下拉面板；
- 不显示主动作与结果；两个点燃入口必须同层级、命中面清楚，但“按住”可作为主要操作。

### W3 — desktop holding

- 同 W2 的第一束与空白已公开字列；
- `按住蓄光` 保持原生按钮身份和文字，可见 pressed 状态与单向蓄光槽；
- 不增加百分比、计时、震动波、瞄准线、成功区、失败区或“松开得分”；
- 夜空可显示一枚尚未升空的低位暖光，但不能显示当前目标点阵或字符；
- `直接点燃` 仍在同一组件族中，不能因概念帧而消失或改名；
- 状态仍使用 public view 的 `准备点燃第 1 / 3 束。`，不发明 holding 专属主文案。

### W4 — desktop bursting1

- 已公开字列只有第一字 `我`；当前第二束正上升或径向成字，第一字保持稳定可读；
- 唯一动态主状态：`第 2 / 3 束正在升空。`
- 当前第二束可以显示其实际高度的点阵目标/表现帧，但字符 `爱` 不能进入已公开字列、可见 label 或任何说明文字；未来第三字不得出现；
- select 保持可见且可预选下一束；`按住蓄光` 与 `直接点燃` 保持原节点外观，以文字、边框和 `aria-disabled` 可感知状态表达暂不可用；
- 只表现一束烟火，不出现自动连放、背景循环烟花、多重快速子爆、全屏白闪、运动模糊或屏幕震动。

### W5 — desktop ready2

- 已公开字列严格按序显示 `我`、`爱`，不存在第三个占位框；
- 唯一动态主状态：`前两束已经留下；准备第 3 / 3 束。`

- `无需蓄满，每一束都会成功。` 仍可见，不加入胜率、命中或倒计时；

## 5. 组件与实现边界

- H1、说明、状态、select、按钮、已公开字列、结果与隐私说明必须是 code-native HTML；
- Canvas/CSS grid 只绘制无语义点、轨迹与 9×9 表现，不用 `fillText` 绘字，不从字体/像素反推业务状态；
- intro/ready 不得把未来字、target、结果以 hidden/template、ARIA、attribute、CSS `content`、SVG text、Canvas text 或离屏缓存预置；
- `ol#revealed-glyphs` 是一条开放留字轨，只创建已完成前缀，不做三个预设卡槽；
- 五档高度使用原生 select；按住与直接点燃是同一控制族的原生按钮，不画假下拉、旋钮、准星或自制 slider；
- bursting 时两按钮保留原节点、tabindex 与可见文字，以 `aria-disabled`、真实边框和文字状态表达暂不可用；
- 主动作在 intro/失败/complete 复用同一原生按钮形体；
- focus 使用至少 3px 清楚 outline，不依赖 glow；pressed、aria-disabled、complete 不得只靠颜色；
- complete 结果保持五节点开放排版，不把整张概念、带字夜空或结果信笺栅格图作为生产 UI；
- motion 只表现单束有限的上升、成字、保持和淡出；不自动、不循环、不闪烁、不震屏。

## 6. 生产资产候选

概念接受后再决定是否生成下列可分离无字资产；首轮概念图不可直接裁切：

1. `ink-night-grain.webp`：无人物、无城市地标、无星座、无文字的低对比深靛纸面/夜空颗粒，可平铺；
2. `rooftop-edge.webp`：无物件、无 Logo、无灯牌的低矮屋顶或窗台剪影，边缘可自然融入背景；
3. `launcher-patina.webp`：无控件、无刻度数字、无文字的深梅红/氧化铜哑光微纹理；
4. `night-letter-fiber.webp`：无字、低对比、可平铺的暖象牙短笺纤维。

运行时只保留能显著提升已接受概念保真的资产。烟火点、轨迹、9×9 字、按钮和 UI 文字均由代码生成；不生成预渲染烟火、带字背景、按钮位图或图标位图。

每个生产资产必须记录完整 prompt、生成日期、工具、模型暴露状态、原生尺寸、格式、SHA-256、第三方输入“无”、使用位置、降级方式与是否进入运行时。

## 7. ImageGen 自然语言总简报

每张状态图都携带以下共同方向，再附加第 3 节的精确状态：

> 设计一套完整、可落地为本地 HTML/CSS/JavaScript 的中文情侣惊喜互动页面，公开 H1“今晚，点三束光”。视觉方向是“午夜屋顶的一封活字夜空信”：深靛近黑的安静夜空、极克制的屋顶下沿、暖象牙与柔金烟火点、少量沉珊瑚轨迹、深梅红或氧化铜的哑光发射台，以及 complete 后才展开的窄幅夜空短笺。气质亲密、克制、有期待，7/10 创意，低到中密度；夜空是唯一主舞台，已完成的 9×9 点阵字沿一条开放留字轨出现，不做三张卡。页面不使用导航、Logo 区、巨型外层卡片、card grid、dashboard、HUD、计分或装饰性 UI。原生五档 select、“按住蓄光”“直接点燃”和主动作都保持 code-native、清楚可读，真实 UI 文本不烘焙进背景资产。严格遵守阶段隐私：intro/ready/holding 不出现当前或未来字的目标、label 或私信；bursting 可表现当前束点阵但当前 label 仍不公开；只按落定前缀显示真实字符；第三束 complete 才出现完整三字与五节点私信。不要标题上方 eyebrow/kicker/badge/pill，不要节庆舞台、城市烟花大会、人物、婚庆海报、赌场奖励、射击准星、卡通火箭、霓虹彩虹、饱和红爆闪、全屏白闪、bokeh、满屏 glitter、自动/循环烟花、多重快速子爆、emoji、fake metrics、倒计时、分数、概率、完美区、分享或额外控件。设计必须具备清楚的中文排版、可提取的颜色/字体/间距/边框/组件规则、可实现的响应式结构，并能在 reduced-motion、forced-colors、无 Canvas 与无 JavaScript 时完整降级。

## 8. 接受 Gate

十五张概念必须逐张原尺寸 `view_image`；任一命中即重做：

1. 只画夜空 hero 或烟花局部，没有完整页面、状态、控制和结果延续；
2. intro/ready/holding 提前出现当前/未来字的点阵、label、槽位或私密字段；
3. bursting 把当前字符加入已公开字列、显示 future label，或同时放多束烟花；
4. complete 不是三个离散 9×9 点阵字，或五段结果缺失、错序、不可读；
5. 原生 select 被替换为假仪表/slider，两个点燃入口缺失、改名或看不出可操作状态；
6. 390/320px 横溢、压缩中文、控制叠进夜空、结果覆盖舞台或主动作不可达；
7. 依赖动画、透明、glow、渐变或颜色才能理解 pressed/aria-disabled/complete；
8. 出现节庆晚会、婚庆、赌场、射击、品牌烟花、人物、emoji、trade dress 或饱和红爆闪；
9. 使用导航、卡片网格、三字卡槽、巨型圆角 wrapper、badge/pill、假指标或未经许可的额外控件；
10. 各状态夜空、点阵、发射台、短笺、按钮或中文字体气质明显漂移；
11. 真实 UI 文本被烘焙进不可编辑背景，或概念只能靠整张截图实现；
12. reduced-motion、forced-colors、无 Canvas、无 JavaScript 或准备失败删掉必要文字/路径，或伪造已经解锁；
13. 任一帧含自动循环、全屏闪光、twinkle/flicker/strobe、shake 或会被理解为失败/得分的反馈。

接受前必须提取并冻结：背景颜色性质、完整 token、字体回退、内容/控件字号与行高、spacing scale、夜空与三字比例、select/点燃/主按钮组件、图标清单、focus/pressed/aria-disabled、信笺布局、移动/横屏重排、允许首屏文案、资产清单和至少五项 fidelity ledger。

用户明确接受后，概念才升级为生产视觉规格。接受前不得创建 `experiences/surprises/wish-fireworks/` 的生产页面代码。

## 9. 浏览器保真 Gate

概念接受不等于实现验收。页面完成后仍必须验证：

- `1504×1046`、`1280×800`、`768×1024`、`390×844`、`320×568`、`844×390`；
- 1504/1280 桌面的 200% text 与 1280 宽的 400% zoom；
- intro、ready0/1/2、holding、bursting0/1/2、complete、准备失败、reduced-motion、forced-colors、Canvas null/throw 与禁用 JavaScript；
- 五档 select、按住/松开、直接点燃、Pointer cancel/lost capture、键盘 click、跨设备 ghost click、后台第三束完成焦点与 replay；
- 最大合法 recipient/sender/patternLabel/finalTitle/finalNote 与三份 16/48 active 两端字形配置；
- 无 JavaScript 时只显示冻结的五项静态内容，不含束数、进度、发射控制、主动作、字或结果；
- 零横向溢出、零 console error/warning、零公网/失败请求、零 storage/permission；
- 不出现常驻 RAF、无限/交替闪烁、全屏亮度切换或自动下一束。

使用 Browser/IAB 完整点燃三束并截图；同一 QA pass 对接受概念与最新浏览器截图分别执行 `view_image(detail="original")`。fidelity ledger 至少比较文案、布局、夜空比例、点阵、配色、字体、间距、控制状态、短笺与响应式十项。任何设计评审会指出的可修问题都必须继续修正。
