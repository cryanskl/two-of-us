## 2. A 级直开边界

入口只加载相对 `styles.css`、`levels.js`、`logic.js`、`app.js`、本地背景和本地图集，脚本均为经典脚本。作品不依赖 setup/start、统一 Node 服务、Pillow、FFmpeg、Matter.js、CDN、远程字体、账号或公网；图像生成与去绿只发生在开发期，不进入作品运行链路。

本轮 Chrome 控制接口的 URL 安全策略不允许把 `file://` 页面纳入自动控制，因此真实交互与视觉在仓库本地 `http://localhost:4174` 静态服务上完成。A 级直开能力由经典脚本加载顺序、全部相对资源、禁用网络/存储 API 扫描、Node 加载和目录完整性共同证明；这是验收工具边界，不改变作品代码或启动等级。

## 3. Chrome 真实交互

使用真实 Chrome 页面完成以下流程：

1. 点击“开始牵引”，先让珊瑚玩家向上、青色玩家向下，确认两套输入可以在同一时段生效；
2. 暂停后持续发送两套移动输入，Canvas 无障碍位置文案保持完全相同；点击“继续”恢复；
3. 点击“重来”，再使用页面实际键盘/触控控制沿原创路线完成第一幕 S 弯、第二幕别针上方路线与第三幕错位窄门；
4. 每幕只在吊坠进入绷框、两枚线轴收束并稳定保持后出现“穿下一针”；最终进入 `game-complete`，显示“这一针，我们一起穿过了”；
5. “玩法”对话框唯一打开并由“知道了”关闭；“重新游玩”回到第一幕 `playing`，位置恢复出生区；
6. 320px 窄屏用可见方向盘分别向右长按，珊瑚线轴从约 `119` 移到 `152`，青色线轴从约 `119` 移到 `142`；
7. 模拟 `prefers-reduced-motion: reduce` 后媒体查询为真，张力条 transition 为 `0.00001s`，规则与触控仍可运行；
8. 浏览器 warning/error 为 0。

三幕通关全部经真实 UI 事件推进，没有在页面上下文内写入、替换或跳过规则状态。验收期间浏览器自动控制连接曾在一个超长连续动作中超时；重新建立独立标签后把实玩拆成逐段真实输入并完整通关，未发现作品状态或页面脚本错误，因此不记录为产品缺陷。

## 4. 响应式与触控

| 视口 | 结果 |
| --- | --- |
| 1586×992 桌面 | `scrollWidth = innerWidth = 1586`；16:9 Canvas 为 1586×892，完整操作轨紧随其后，无横向溢出 |
| 390×844 触屏 | `scrollWidth = innerWidth = 390`，`scrollHeight = innerHeight = 844`；Canvas 为 390×219，两套方向盘并排，8 个按钮均 52×52px |
| 320×700 窄屏 | `scrollWidth = innerWidth = 320`，页面纵向高度 929px；两套方向盘纵向排列，无横向滚动 |

390px 把完整主玩法和双方向盘压进一个首屏；320px 则保留 52px 触控目标并允许纵向滚动。这里优先保证两个人实际可按，不把按键压缩成难以命中的装饰。

## 5. 视觉忠实度

最终桌面 ready、桌面完成和 390×844 ready 截图分别与 [`docs/assets/tethered-heart/`](./assets/tethered-heart/) 的冻结概念图在同一次本地图片检查中对照：

1. **文案**：标题、幕数、共同牵引语义、暂停/重来/玩法与完成句保留冻结方向；
2. **布局**：桌面保留顶栏、单一大画布、覆盖式主动作和底部开放操作轨；移动端依次为标题、画布、张力、双方向盘与工具；
3. **排版**：标题使用系统宋体栈，操作与状态使用系统无衬线，键位与编号使用等宽字体；
4. **色彩**：深桑葚布面、暖羊皮纸、旧黄铜、珊瑚与氧化青和规格 token 一致；
5. **资产**：运行页只加载一张本地背景和一张 `4 × 2` 透明图集；丝带由状态端点实时绘制；
6. **容器**：黄铜外框包裹同一 16:9 规则世界，操作轨不拆成卡片网格；
7. **响应式**：390px 保留并排双控，320px 才改为纵向；Canvas 始终保持规则世界宽高比；
8. **动效**：张力、碰撞、收针和火花只是状态投影；减少动态效果后仍保留位置更新和完成判定。

有意差异是冻结概念使用更自由的软垫尺度和大量边缘针线装饰，生产页把障碍严格对齐到可测试的 `960 × 540` 碰撞几何，并减少会干扰路线判断的装饰。移动概念是一张长幅氛围稿，生产版在 390×844 把双控制器收进首屏；这是为了双人同时操作，不是视觉遗漏。
