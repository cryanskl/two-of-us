## 1. 视觉任务

为一个直接双击 `index.html` 即可打开的中文情侣惊喜页面设计完整多状态界面。收礼者在玻璃雪球中收集上、右、下、左四阵风，主动让雪落下；雪点组成 9×11 图案后，页面才展示准备者写下的称呼、标题、私信和署名。

这不是圣诞电商页、商业贺卡、粒子技术 demo、摇手机工具或儿童卡通游戏。目标气质是：冬夜、亲密、安静、有仪式感，像有人把一封信藏进床头的玻璃雪球里。

首轮必须生成十张独立、清晰、可实现的完整页面概念，不以一张压缩总览代替状态细节：

1. `G1`：1504×1046 desktop gathering，已收上、左两阵风；
2. `G2`：1280×800 desktop armed，四阵风已齐；
3. `G3`：1280×800 desktop settling，雪点正在归位；
4. `G4`：1504×1046 desktop complete，完整默认结果；
5. `G5`：390×844 mobile gathering，已收右一阵风；
6. `G6`：390×844 mobile complete，完整结果流；
7. `G7`：844×390 landscape complete；
8. `G8`：320×568 preparation failure，稳定重试路径；
9. `G9`：1280×800 accessibility comparison，同一构图清晰展示 reduced-motion 静态 complete、forced-colors complete 与无 Canvas CSS-grid complete 三种独立面板。
10. `G10`：320×568 no JavaScript，静态、安全、不伪造解锁。

G9 只用于提取降级规则，不是生产页面中的模式切换器或三栏组件。

## 2. 冻结视觉方向

### 2.1 核心意象

方向为“冬夜床头的一只私人玻璃雪球”：

- 一只占据首屏视觉中心的厚壁玻璃球，不使用现成品牌轮廓；
- 深莓红到乌梅色的低矮底座，像被长期握过的哑光漆面；
- 奶油白雪点，少量暖金细线只用于底座边缘和方向刻度；
- 背景是深墨蓝冬夜与很克制的床头/书桌光域，不出现窗外城市、人物或圣诞树；
- 页面文案像一封安静的夜间短笺，使用清楚的中文衬线内容字体回退与克制的无衬线控件字体回退；
- 玻璃高光、桌面接触影和底座材质形成深度，但不以 glow、bokeh 或满屏粒子制造“浪漫”。

创意强度约 7/10，低到中密度。一个雪球是唯一主形体，结果信笺是 complete 后的第二视觉层级。

### 2.2 页面构图

- 页头开放排版，不做导航栏、Logo 区或巨型圆角 hero wrapper；
- 固定隐私说明在所有状态靠近页面结尾稳定存在，不做 badge、锁形图标或安全认证卡；
- desktop gathering/armed/settling 以“文字左上、雪球居中偏左、方向控制与进度靠近雪球右下”为主；
- complete 保留同一雪球位置，默认心形在球内落定；结果信笺从底座下方或右侧安静展开，但必须服从 DOM 阅读顺序；
- 390px 使用单列：题名与说明 → 雪球 → 2×2 方向按钮 → 状态 → 结果（仅 complete）→ 主动作；
- 844×390 可让雪球与控制/结果并排，但不能锁定方向、裁掉主动作或造成横向滚动；
- 不使用 card grid、bento、dashboard panel、轮播、tab、modal 或浮动工具条。

### 2.3 签名组件语言

允许的 4 个视觉母题：

1. **风向刻痕**：上、右、下、左按钮使用同一组细金刻线和中文方向字，收好后增加真实 `✓ / 已收好`；
2. **玻璃边缘双线**：外圈冷蓝高光与内圈极细暖色反射，forced-colors 下退化为真实双 border；
3. **雪痕进度**：状态文字旁只允许四个极小的静态刻点或底座刻痕，不能替代真实进度文字；
4. **展开短笺**：complete 的五节点结果保持开放纸面阅读流，不拆成五张卡。

图标只允许方向箭头与勾选标记。箭头应是稳定、简洁、同一 stroke 的 SVG 风向符号，不使用 emoji、雪花字体图标或第三方图标字体。

## 3. 状态概念合同

### G1 — desktop gathering

- H1：`等雪停下`
- 固定说明：`把四阵风收进雪球里。等雪慢慢落下，会有一句话留在里面。`
- 雪球中只有固定 72 枚无语义散雪，不能出现心形、字母、目标网格或私信轮廓；
- 上、左显示“已收好”，右、下保持可操作；
- 主状态：`已收好 2 / 4 阵风；还差：右、下`
- 不显示主动作，不显示称呼、patternLabel、finalTitle、finalNote 或 sender；
- 拖动面可以通过底座轻微风向刻痕暗示可拖，但不能伪装成 slider/joystick。

### G2 — desktop armed

- 四个方向按钮均显示 `✓ / 已收好`，并呈现不可继续收风的状态；
- 主状态：`四阵风都在了。准备好，就让雪落下。`
- persistent 主按钮：`让雪落下`
- 雪球仍只有中性散雪，不能提前出现目标点阵或私信；
- 视觉应表达“静止等待确认”，不能自动爆发、闪烁或倒计时。

### G3 — desktop settling

- 主状态：`雪正在慢慢找到位置。`
- 同一主按钮显示 `正在落下…`，视觉 disabled，但仍保留同一按钮形体；
- 雪点可以出现从散落到默认心形目标的路径提示，但不能出现 patternLabel、称呼、标题、私信或署名；
- 不画物理碰撞 HUD、轨迹调试线、百分比、倒计时、进度条或加载 spinner；
- 动态含义通过 900ms 的短促归位表达，概念图应选择中段清楚帧，不使用运动模糊遮住点阵。

### G4 — desktop complete

- H1 仍为 `等雪停下`；
- 雪球内是清楚的 9×11 默认心形点阵，不使用文字轮廓、emoji 心或连续实心图；
- 主状态：`雪已经停下，留言在这里。`
- 结果信笺精确可读：
  - `一颗由雪花拼成的心`
  - `给 你`
  - `雪停以后，是你`
  - `风停下来的时候，我还是最想把这句话留给你。`
  - `——我`
- 主按钮：`再看一次`
- patternLabel 是雪球图案的可见说明，结果标题是唯一程序化焦点目标；
- 信笺不能遮挡雪球、方向按钮或“再看一次”，也不能变成贺卡套模板。

### G5 — 390px mobile gathering

- 已收右一阵风；主状态：`已收好 1 / 4 阵风；还差：上、下、左`
- 雪球直径 280–320px，四方向为视觉一致的 2×2 原生按钮，每个可见命中面至少 48px；
- 保持“上、右、下、左”的 DOM/阅读顺序，不为视觉对称反转 order；
- 首屏可以纵向滚动，但不能横溢、压缩中文、隐藏状态或把按钮叠进玻璃球；
- 不显示移动端专属菜单、底部导航、手势教程浮层或“摇手机”。

### G6 — 390px mobile complete

- 同 G4 的默认心形、五段结果与精确文案；
- 保持单列 DOM 阅读流，结果信笺在状态后、“再看一次”前完整展开；
- 雪球 280–320px，私信允许自然换行，署名与主动作不能被首屏高度假设裁掉；
- 方向按钮保持 2×2 与已收好语义，页面允许纵向滚动、零横向溢出；
- 不把结果做成 overlay、modal、翻面卡或覆盖雪球的绝对定位纸片。

### G7 — 844×390 landscape complete

- 同 G4 的默认结果与精确文案；
- 雪球约 210px，左侧或中部可见；结果与主动作在右侧形成短而完整的阅读流；
- 不锁定横屏、不裁掉署名与“再看一次”，允许必要的纵向滚动但零横向滚动；
- 控制尺寸、文字行高与焦点环不能因横屏而缩成装饰。

### G8 — 320px preparation failure

- H1 与固定说明仍可见；
- 同一个进度状态节点显示：`暂时没准备好，请重新准备。`
- persistent 主按钮显示：`重新准备`
- 不显示方向已收集、心形、结果信笺、异常详情、路径、配置或技术错误码；
- 页面可纵滚、零横溢，按钮命中面至少 48px；
- 失败视觉克制，不使用红色警报卡、toast、modal、错误插画或“崩溃”语言。

### G9 — 降级比较

- reduced-motion：直接展示与 G4 相同的静态 complete，不能依靠淡入、漂移、缩放或摇晃才能理解；
- forced-colors：系统背景/文字/按钮/Highlight、真实边框、方向字、`✓ / 已收好` 和可见 patternLabel 足以表达全部状态；
- 无 Canvas：用 9×11 CSS grid 绘制同一心形，图案层 `aria-hidden`，真实结果文本保持不变；
- 三种面板都不出现模式切换器、技术标签以外的虚构 UI；标题仅作为概念注释，不进入生产页面。

### G10 — 320px 无 JavaScript

- 只显示 H1 `等雪停下`、固定说明、一个无语义静态雪球轮廓、提示 `请开启 JavaScript 后再收集四阵风` 与固定隐私说明；
- 隐藏四方向按钮、进度状态、主动作和结果子树；
- 雪球轮廓中不能出现心形、目标点、已收方向、私信轮廓或“完成”暗示；
- 不显示错误码、安装步骤、刷新建议、下载按钮或外部链接；
- 可纵向滚动、零横向溢出，中文在 320px 下完整可读。

## 5. 组件与实现边界

- 真实 H1、说明、状态、方向标签、结果与按钮必须是 code-native HTML 文本；
- 雪点与玻璃内无语义表现由 Canvas 绘制；Canvas 不绘制任何文字；
- Canvas 不可用时，CSS grid 绘制点阵；业务状态不从像素或动画读取；
- 玻璃、底座、信笺、风向刻线和按钮必须能用语义 HTML/CSS、Canvas 基本几何与少量分离无字资产实现；
- 四方向按钮是同一组件族，不使用四种无关图标或卡片造型；
- 主按钮在 armed/settling/complete/失败 intro 复用同一节点与同一组件形体；
- focus 使用至少 3px 的清楚 outline，不依赖阴影；disabled/pressed/complete 不能只靠颜色；
- 结果信笺维持五节点开放排版，不能用 hidden/template 预置；
- 不把完整概念截图、带字雪球或结果信笺栅格图作为生产 UI。

## 6. 生产资产候选

概念接受后再决定是否生成下列可分离无字资产；首轮概念图不可直接裁切：

1. `winter-night-grain.webp`：无人物、无窗景、无文字的低对比深墨蓝纸/墙面颗粒，可平铺或大面积覆盖；
2. `berry-base-patina.webp`：无 Logo、无按钮、无高光结构的深莓哑光漆微纹理；
3. `letter-paper-fiber.webp`：无字、低对比、可平铺的暖白短笺纤维；
4. `table-light.webp`（仅 CSS 无法忠实表达时）：无物件、无品牌的柔和桌面光域，边缘可自然融合背景。

运行时只保留能显著提升已接受概念保真的资产。CSS 足够时不为“使用 ImageGen”而增加图片；方向箭头和勾选使用可访问的生产 SVG/文本，不生成位图图标。

每个生产资产必须记录完整 prompt、生成日期、工具、模型暴露状态、原生尺寸、格式、SHA-256、第三方输入“无”、使用位置、降级方式与是否进入运行时。

## 8. 接受 Gate

十张概念必须逐张原尺寸 `view_image`；任一命中即重做：

1. 只画雪球 hero 或局部，没有完整页面、状态、控制和结果延续；
2. gathering/armed 提前出现心形、目标网格或任一私密字段；
3. settling 出现 patternLabel、称呼、标题、私信或署名；
4. complete 不是 9×11 离散点阵，或五段结果缺失/顺序错误；
5. 方向按钮不像同一组件族、缺少文字、命中面不清楚或移动端不是 2×2；
6. 390/320px 发生横溢、文字压缩、控制叠进雪球或主动作不可达；
7. 依靠动画、透明、渐变、阴影或颜色才能理解 pressed/disabled/complete；
8. 出现圣诞/商业贺卡/品牌收藏雪球/儿童卡通/人物/emoji/trade dress；
9. 使用导航、卡片网格、巨型圆角 wrapper、badge/pill、假指标或未经许可的额外控件；
10. 各状态背景、玻璃、底座、雪点、按钮或中文字体气质明显漂移；
11. 真实 UI 文本被烘焙进不可编辑背景，或概念只能靠整张截图实现；
12. forced-colors、reduced-motion 或无 Canvas 面板删掉必要文字、方向或完成路径。
13. 无 JavaScript 概念显示方向按钮、进度、主动作、心形、私密结果或任何已解锁暗示。

接受前必须提取并冻结：背景颜色性质、完整 token、字体回退、内容/控件字号与行高、spacing scale、玻璃/底座比例、方向按钮与主按钮组件、箭头/勾选 SVG 规格、焦点/pressed/disabled、信笺布局、移动/横屏重排、允许首屏文案、资产清单和至少五项 fidelity ledger。

用户明确接受后，概念才升级为生产视觉规格。接受前不得创建 `experiences/surprises/snow-globe-message/` 的生产页面代码。

## 9. 浏览器保真 Gate

概念接受不等于实现验收。页面完成后仍必须验证：

- `1504×1046`、`1280×800`、`768×1024`、`390×844`、`320×568`、`844×390`；
- 1504/1280 桌面的 200% text 与 1280 宽的 400% zoom；
- gathering、armed、settling、complete、准备失败、reduced-motion、forced-colors、Canvas null/throw 与禁用 JavaScript；
- 最大合法 recipient/sender/patternLabel/finalTitle/finalNote 与 16/72 active 两端配置；
- 纯 Pointer、纯键盘、Pointer 与按钮混合、前台/后台完成焦点；
- 无 JavaScript 时只显示冻结的五项静态内容，不含方向按钮、进度、主动作、心形或结果；
- 零横向溢出、零 console error/warning、零公网/失败请求、零 storage/permission。
