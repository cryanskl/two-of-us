# 「把月亮拨回那一天」视觉设计清单

> 接受日期：2026-07-18。设计依据为 [`67-moon-phase-secret-spec.md`](./67-moon-phase-secret-spec.md)，概念由 OpenAI ImageGen 生成，仅作为视觉规格，不在运行时显示。

## 1. 已接受概念

- [桌面完整校准态 1504×1046](./assets/moon-phase-secret/concept-desktop.png)；
- [手机完整校准态 853×1844](./assets/moon-phase-secret/concept-mobile.png)；
- 运行月面纹理：[`../experiences/surprises/moon-phase-secret/assets/moon-surface.png`](../experiences/surprises/moon-phase-secret/assets/moon-surface.png)，1254×1254。

桌面采用 34/66 不对称双列，左侧承载标题、线索和主动作，右侧只有一个大型圆形校准仪。手机保持标题 → 校准仪 → 读数 → 线索 → 主动作的单列顺序。

## 2. 设计系统

| 类别 | 规则 |
| --- | --- |
| 背景 | 真深蓝 `#0b1220`，允许轻微纸纹感，但运行版不依赖背景图片 |
| 仪器表面 | `#151f30` 深蓝珐琅 + `#aeb9c8` 冷银边，不使用暖木或黄铜 |
| 月面 | `#e7e3dc` 珍珠灰纹理；相位暗面用 `#0b1220` 的可动画遮罩 |
| 强调 | 钴蓝 `#4169a8` 表示当前读数，朱红 `#c86659` 只用于指针和主动作 |
| 标题/线索 | 本机中文宋体/serif，文学感但保持可读；标题为页面唯一大字 |
| 仪器 chrome | 窄体 sans-serif，数字允许 tabular nums；按钮显式定义字号，不继承浏览器默认 |
| 几何 | 大圆环、细刻度、方形读数槽、4–12px 小圆角；不使用胶囊、卡片网格或大浮层 |
| 动效 | 180ms 刻度旋转，620ms 月面揭晓；reduced motion 为 `.01ms` |

## 3. 允许的首屏文案

概念接受后，首屏只允许以下代码原生文本：

- `把月亮拨回那一天`；
- `跟着三条线索，把月份、日期和月相拨回那一天。`；
- 三条配置线索；
- `开始校准` / `核对这一天` / `再找一次`；
- 当前年份、月份、日期、月相名；
- `月份` / `日期` / `月相` 与必要键盘/拖动提示；
- 三项对齐反馈；
- 完成阶段才出现的配置称呼、标题与正文。

禁止新增 eyebrow、badge、统计、难度、天文精度营销、登录/分享、装饰性英文品牌或说明卡。

## 4. 组件与资产清单

| 组件 | 概念证据 | 实现约束 |
| --- | --- | --- |
| 返回按钮 | 左上 48px 银线圆按钮 | 原生 link + 自制 SVG 箭头 |
| 月份环 | 12 等分外环、朱红指针 | DOM 生成 1–12 月；概念错字/重复刻度不能复制 |
| 月相环 | 八个相位围绕中央月面 | DOM/CSS 生成八相缩略图和当前选择；名称始终可读 |
| 中央月面 | 大号珍珠灰月球 | 本地纹理 + CSS 相位遮罩；缺图用三陨石坑回退 |
| 日期控件 | 机械数字槽 | 当前年只读，月/日明确；日使用 ± 48px 按钮 |
| 线索 | 三条开放式细线 | 原生 list，不包成三张卡，不显示日期数字答案 |
| 主动作 | 单一朱红/钴蓝矩形按钮 | 桌面约 360×76，手机全宽至少 56px 高 |
| 反馈 | 概念未展开 | 使用同一三条细线下的文字状态，不新增 modal 或 toast |

## 5. 响应式提取

### 1504×1046

- 页面无滚动；左栏宽约 440px，校准仪直径约 860px；
- 标题 64–76px，线索 20–24px，主动作 28–32px；
- 校准仪可以略超出右侧视觉边界，但 DOM `scrollWidth` 必须等于 `clientWidth`；
- 标题、三线索、主动作和读数在同一首屏。

### 390×844

- 概念是 853×1844 高分辨率长图，目标运行视口为 390×844 CSS 像素；
- 校准仪宽不超过 `calc(100vw - 24px)`；
- 第一屏看到完整标题、月面主体和至少一个可执行调节；其余线索/核对动作允许短滚动；
- 320px 仍保留 48px 操作目标，不通过缩字或隐藏功能来消除溢出。

## 6. 图标与月相表现

- 只有返回、左右调节、日历 ±、线索星芒和三项反馈符号；
- 统一 1.5–2px 冷银描边、圆角端点，选中态才使用朱红/钴蓝；
- 八相缩略图由圆面 + 暗面遮罩生成，不使用 Unicode 月亮 emoji；
- 中央月面相位必须与当前中文名同源，不能靠独立 CSS 类手写第二份映射。

## 7. 生成式概念的已知非权威部分

- 桌面概念的月份环出现重复/缺失月份，手机日期环也不是严格 1–31 顺序；
- 桌面月相缩略图并非完整八相科学示意；
- 这些属于 ImageGen 在密集刻度上的常见误差。运行版必须由纯逻辑常量生成准确序列，不以像素位置或概念文字为数据源；
- 手机概念的“上弦月”与图中亮面方向只作为风格参考，运行版按统一 phase index 投影。

## 8. ImageGen 提示词摘要

三次均使用内置 ImageGen：

1. 桌面：完整 1504×1046 校准态，34/66 双列，午夜纸面、冷银圆形仪器、精确中文标题/线索/动作，禁止卡片网格和伪 dashboard；
2. 手机：同系统 390×844 目标布局，标题、完整圆形仪器、读数、三线索和全宽主动作，允许短滚动；
3. 月面：正交、无字、无边界、均匀光照的珍珠灰月表纹理，完全铺满方形画布，供 CSS 圆形裁切与相位遮罩。

最终实现必须在 Browser 截图后与桌面/手机概念同轮 `view_image`，并写至少五项保真账本。
