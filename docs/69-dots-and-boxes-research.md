# A 级「线框占地」定向调研

> 调研日期：2026-07-18。目标是把创意池 V06「线框占地」收敛为一个可双击、无公网依赖、两人同机轮流且可完整验证的领地对抗作品。

## 1. 选题结论

下一件作品采用：

- 作品名：**这一格归谁**；
- 目录 ID：`dots-and-boxes`；
- 主分类：双人对抗；
- 启动等级：A，直接双击本目录 `index.html`；
- 设备：一台电脑、平板或手机，两人轮流点击；
- 核心动作：连接相邻点；闭合方格就归当前玩家并继续行动；全部 16 格归属后高分者胜；
- 首版边界：固定 4×4 方格、两名本地玩家、一局与重开；不做 AI、在线匹配、棋盘尺寸选择、账号、历史战绩或长期存储。

当前对抗目录已有反应、连续输入、止盈、算式、图路径、顺序记忆与局域网棋类，但还没有“领地闭合 + 连续行动”的样板。这个玩法的规则能在 30 秒内解释，去掉声音和图片后仍成立，并且不需要服务器或第三方运行依赖。

## 2. 传统规则与术语边界

AAAI 论文《Solving Dots-And-Boxes》给出清楚的规则定义：棋盘大小按**方格数**计；玩家轮流连接水平或垂直相邻点；补上第四边者获得该格并必须再画一条线；所有边完成后，占格较多者胜。论文还指出，即使规则简单，小棋盘也有很大的状态空间。

本作遵循这些传统规则：

1. 每次只能选择一条尚未使用的水平或垂直相邻边；
2. 新边若闭合一个或两个方格，这些格都归当前玩家；
3. 本步至少闭合一格时当前玩家继续，否则换手；
4. 16 格全部归属后结束；高分者胜，同分为平局；
5. 玩家不因“已有可闭合方格”而被强制选择它，仍可选择任意合法边。

一手规则来源：[Barker 与 Korf，Solving Dots-And-Boxes，AAAI 2012](https://ojs.aaai.org/index.php/AAAI/article/download/8144/8002)。论文只用于确认公开规则、规模术语和状态空间性质；不复制论文算法、图表、数据或求解器。

## 3. 为什么固定 4×4 方格

固定 4×4 方格等于 5×5 点、16 个可占方格和 40 条唯一边：

```text
horizontal = 5 × 4 = 20
vertical   = 4 × 5 = 20
total      = 40
```

| 方案 | 优点 | 风险 | 结论 |
| --- | --- | --- | --- |
| 3×3 方格 | 24 条边，首局短 | 局势过早进入强制链，重玩空间小 | 不采用 |
| 4×4 方格 | 手机仍可读，16 格能形成多段链条，约 5–8 分钟 | 需要严谨处理双格同时闭合 | 采用 |
| 5×5 或自定义 | 更接近传统长局 | 手机点击区变小，配置与测试面显著扩大 | 首版不采用 |

首版以“完整、短局、同机可达”为目标，不声称采用锦标赛标准棋盘，也不提供 AI 或最优策略提示。

## 4. 规范边模型

相邻方格共享同一条物理边。若每个方格分别保存 `top/right/bottom/left`，就会产生重复真值：一次落边必须同步写入最多两个对象，状态校验和撤销都更脆弱。

本作只保存唯一规范边 ID：

```text
H:r:c  // 第 r 条点行，从第 c 个点向右
V:r:c  // 第 r 条方格行，第 c 条点列向下
```

范围：

- `H:r:c`：`r = 0..4`，`c = 0..3`；
- `V:r:c`：`r = 0..3`，`c = 0..4`；
- 方格 `B:r:c`：`r = 0..3`，`c = 0..3`。

一条水平边最多邻接上、下两个方格；一条垂直边最多邻接左、右两个方格。落边后只检查这些邻格是否四边齐全，不扫描全盘。纯逻辑状态保存规范边集合、16 格归属、双方分数、当前玩家、阶段、步数与上一手结果；DOM 不拥有规则真值。

## 6. 本地实现与交互边界

- 使用经典脚本和原生 DOM/CSS，完整作品目录可单独复制并通过 `file://` 运行；
- 每条未占边都是原生 `<button>`，点击区至少 44×44px，视觉线可以更细；
- 已占边禁用并显示落边玩家颜色；方格归属同时使用颜色、玩家符号和分数，不只靠颜色；
- 当前回合、闭合格数、继续行动与换手都由状态机投影视图，不从动画回调决定；
- 一步闭合两格时计两分、只增加一步、当前玩家继续；
- 页面不保存对局，不请求网络，不写 Cookie 或本地存储；刷新即开始新局；
- `prefers-reduced-motion` 下取消占格和落边动画，但不改变规则或焦点顺序。

## 7. 风险与验证 Gate

| 风险 | Gate |
| --- | --- |
| 相邻格对同一边看法不一致 | 状态只保存 40 条规范边；邻格由边 ID 派生 |
| 一条边同时闭合两格只记一分 | 构造双闭合局面，断言同一步新增两名同 owner 方格与两分 |
| 闭合后错误换手 | 捕获一格/两格均保留当前玩家；普通落边严格换手 |
| 重复点击改变步数或分数 | 重复/越界/斜边操作返回同一状态引用 |
| 终局提前或漏判 | 16 格归属、40 边完成、双方分数和阶段互相校验 |
| 颜色成为唯一信息 | 方格显示 `A/B` 或双方自定义短名；状态文案和分数明确 |
| 手机边按钮难点 | 390px 与 320px 实测每条可用边点击区、无横向溢出 |
| 连续行动时焦点丢失 | 落边后焦点移动到下一条可用边；真实键盘回归 |
| 参考项目边界不清 | README 固定两个 MIT commit、一个无许可证候选，并写零复制声明 |
