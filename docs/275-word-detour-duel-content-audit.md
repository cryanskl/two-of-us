## 1. 结论

本次提交包含精确 `6 主题 × 3 难度 × 4 张 = 72 张`原创卡。每张均独立编写
target 与四个 forbidden，没有抓取、翻译、改写或洗牌商业、社区、开源题库，
也没有使用商业示例、角色、歌词、台词、名人、品牌或时事。

自动结构审计与人工语义审计均通过；本审计不宣称单个常用词由仓库独占，只声明
本套目标选择、禁用提示组合、难度分配和 schedule 编排为独立创作。

## 3. 可玩性抽样

逐卡检查至少保留两类不直接说禁词的描述路径，例如：

- “订书机”仍可从装订用途、桌面动作和最终效果描述；
- “潮汐”仍可从周期变化、海岸观察和时间规律描述；
- “默契”仍可从共同完成、无需提醒和相互预判描述；
- “防波堤”仍可从所在位置、保护作用和结构形态描述。

这类审计只证明卡片不是被四个提示完全封死，不提供可直接照读的游戏答案句。

## 4. 结构与公平审计

- cards：72；
- 每主题：12；
- 每难度：24；
- 每主题×难度：4；
- 每卡 forbidden：4；
- card ID 与规范化 target：全局唯一；
- target 与全库任一 forbidden：无 exact 冲突；
- target 与同卡 forbidden：不互为完整子串；
- schedules：3 套 × 4 hand × 6 card；
- 72 个 card ID 在全部 schedule 中恰好使用一次；
- 每 hand：六主题各一、难度 1/2/3 各二、24 个 forbidden exact 唯一；
- 每套中两位描述者各 12 张、每主题各二、每难度各四。

2026-07-25 复核修正了两项内容：

- `daily-04` 的“钥匙圈”包含目标“钥匙”，改为独立限制“随身”；
- `action-09` 的“纸张”与同 hand 的 `daily-09` 重复，改为“翻折”。

全库不同卡片之间仍允许常用 forbidden 在不同 hand 复用；结构 Gate 禁止的是
同卡重复、target 冲突/包含和同一 hand 的 exact 重复，不声称 288 个 forbidden
全局唯一。

## 5. 来源边界

Hasbro、USPTO、美国版权局和标准来源只用于确认商业品牌、表达、无障碍和生命周期
边界；这些来源不提供本作的卡片内容。完整 URL 与未复制范围见项目
`ATTRIBUTION.md`。

原创性属于仓库作者的来源声明，文件本身不能法证式证明“互联网上从未出现过相同
常用词组合”。本轮两次独立审阅分别完成：

- 内容审阅：逐项读取 72 个 target 和 288 个 forbidden，检查商业示例、品牌、
  人物/作品、敏感主题、身份预设、时效和基本可绕开性；
- 结构审阅：运行 validator、schedule 和敌对变异测试，检查数量、分布、exact
  冲突、同卡包含、同 hand 重复和确定性。

两次审阅均未发现第三方题库、代码或素材进入项目；此结论不冒充全网相似度搜索或
法律意见。

后续新增或替换任何卡片，都必须重新运行结构测试并补同等的原创、权利、敏感、
中立和时效审计；不能向数组末尾随意追加未经 schedule 分配的词。
