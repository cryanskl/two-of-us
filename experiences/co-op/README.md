# 双人合作

这一类作品让两个人在同一目标下交流、创作或解谜，例如你画我猜、共同拼图和默契任务。

作品可以单设备同屏、轮流交接，也可以采用 C 级局域网双设备：一台设备本地启动房间，另一台在同一 Wi-Fi 加入，不要求账号或公网服务。

## 已收录

- [同机你画我猜](./hot-seat-pictionary/)：单设备热座交接，六轮累计共同得分。
- [双光点归巢](./twin-light-maze/)：单设备同屏双控，互踩压力板开门并一起抵达出口。
- [同心牵引](./tethered-heart/)：单设备同屏双控，用两条有张力的丝带共同牵引一颗布艺心穿过针脚。
- [为你引航](./lighthouse-passage/)：单设备同屏非对称双控，一人转动灯塔光束，一人驾驶小船安全入港。
- [节拍接力](./rhythm-relay/)：单设备热座轮换，复现并亲手追加双音序列，共同把三拍接到十拍。
- [默契电报码](./telegraph-codebook/)：单设备轮流交接，按六码本发送三拍短长讯号并共同完成译码。
- [双人小馆](./kitchen-relay/)：单设备同屏分工，传菜员选食材，装盘员追滑槽，共同完成四张订单。
- [靠近一点](./closer-cards/)：单设备面对面轮流回答六张原创谈话卡，不评分、不记录，也可以随时换一张。
- [把颜色调到一起](./shared-color-studio/)：单设备同屏分轴控制色相与明度，共同对齐五张目标色笺。
- [把信号接回来](./signal-repair-manual/)：单设备面对面分持星路与规则，靠口述接回唯一正确分支并交换角色。
- [这一拍，刚好和你](./four-hands-harmony/)：单设备同屏分持低音与高音，在 200ms 内同步按住并共同完成五次和弦。
- [慢一点，也和你一起](./same-pace-star/)：单设备同屏轮换领拍，依次按住、接住并松开四个节拍，共同点亮六次星光。
- [稳稳地，和你一起向前](./steady-together/)：单设备同屏托住天平两端，让滚珠穿过相反坡势并一起抵达终点。
- [一起，把家搬进来](./moving-home-together/)：单设备同屏控制沙发两端，在固定门厅里共同平移、转弯并把它放稳。
- [月面，保持有光](./moon-base-power/)：单设备同屏双席合作，一人控制供电与联络，一人安排三类舱段负载，共同稳定三次月面班次。
- [雾里，跟着你走](./fog-navigation/)：单设备轮流交接，领航员限时看全图，驾驶员只看脚边 5×5 雾窗，靠口述走完四段路线。
- [这一场雨，我们一起接](./cloud-recipe/)：单设备同屏双控，两人各守云朵一端，把接雨区间调到唯一正确宽度，共同接齐三份天气配方。
- [把两边，拉成我们](./together-zipper/)：单设备同屏双控，左右席在公共时间窗各拉一次，逐齿合上三段共 15 颗拉链齿。
- [把七天，养成一朵花](./seven-day-garden/)：单设备公开轮流，从两只有限工具篮选卡，精确照料七张花签并共同养成一朵花。
- [把星光，一笔一笔交给你](./constellation-relay/)：单设备公开轮流，两席沿同一当前线头各接五根线，避开非法相交与无解前缀，共同完成双翼星鸢。
- [把影子，跳成我们](./shadow-duet/)：单设备同屏双控，两席同时保持目标姿势六小拍，共同收集六幕纸幕合照。
- [转一点，推一点，刚好回家](./capsule-docking/)：单设备同屏分权，一席转、一席推，让同一艘纸模舱体满足六项 Gate 并完成三段对接。
- [我听见了](./i-heard-you/)：本机语音模型把两个人轮流说的话整理成可编辑草稿，确认后让两句话相遇。
- [同心解锁](./together-lock/)：两台设备加入本地房间，同时按住完成合作机关。
- [隔屏画猜](./lan-pictionary/)：两台设备轮换画家，秘密题目与猜词通过定向消息传送。
- [和你一样](./compatibility-quiz/)：两台设备各自密封回答八道二选一题，收齐后同时揭晓默契答案。

更多候选与实现顺序见 [双人合作类调研](../../docs/20-co-op-research.md)。
