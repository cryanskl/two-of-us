# 这一圈，和你同时到

一个同一设备、双人实时合作的本地小游戏。两个人各控制一颗星：按住进入更快的
内轨，松开回到更慢的外轨；提前调整各自累积的路程，让两颗星在同一个逻辑
tick 穿过不同角度、不同半径的两扇门。

## 启动

直接双击本目录的 `index.html`。无需安装、终端、服务器、账号或网络；页面使用
经典相对脚本，可通过 `file://` 运行。

## 操作与规则

- 左边按住 `F`，右边按住 `J`；
- 触屏时，两个人可以分别按住页面底部的两个控制区；
- 按住走内轨，每 tick 前进 3 格；松开走外轨，每 tick 前进 2 格；
- 两颗星必须在共同窗口内、同一个逻辑 tick、沿各自要求的轨道穿过门位；
- 五圈的路线负担会交换，任一方保持不动或一直使用同一轨道都无法独自通关；
- `Escape`、窗口失焦、页面隐藏、页面离开或不可靠长帧会清空输入并回到当前圈
  说明，不会补算后台时间；
- 失败只重试当前圈，五圈完成后可以选择“再走一遍”完整重开。

## 本地与隐私

本作品只使用本目录内的 HTML、CSS 和 JavaScript，以及浏览器原生 DOM、SVG、
Keyboard Events、Pointer Events、Page Visibility 和
`requestAnimationFrame`。它不使用公网请求、远程字体、图片、音频、Canvas、
WebSocket、Service Worker、cookie、localStorage、sessionStorage、IndexedDB、
权限 API、统计或账号系统，也不收集、保存或上传输入与进度。

`config.js` 是可直接编辑的本地明文配置，不是加密存储；适合改名字和文案，但
不要放入不希望随文件一起分享的秘密。

## 实现边界

规则以 30Hz 固定步运行，角度使用 `0…719` 的安全整数。渲染层只读取核心公开
view；SVG 中的星、轨道和门位只表达权威状态，不参与穿门、成功、失败或重试
判断。左右席位使用相同速度、动作能力、窗口与控制面积，并用“琥珀六角点纹”
和“雾蓝四角横纹”同时提供形状、纹理和颜色区分。

公开作品名只使用“这一圈，和你同时到”。`twin-orbit` 仅是仓库内部目录 ID，
不作为页面标题、logo、favicon 或公开英文名称。
