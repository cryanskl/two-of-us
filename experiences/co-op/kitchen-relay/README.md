# 双人小馆

一款 A 级本地双人合作游戏：传菜员从三条滑槽里选出订单下一样食材，装盘员在食材到达前把盘子移到同一条滑槽。洒落三次前一起完成四张订单即可出餐成功。

## 打开

直接双击 `index.html`，或从仓库根目录运行 `start.command` / `start.bat` 后在统一门户打开。页面没有安装步骤，也不依赖服务器。

## 两位玩家

- **传菜员**：`A / D` 循环选择三条滑槽，`W` 发出当前食材；
- **装盘员**：`← / →` 移动盘子；食材飞行期间仍可补位；
- 鼠标和触屏可以使用页面上的食材牌与按键；
- 盘子和食材处于同一条滑槽且食材正好是订单下一样，才算接稳。

接错食材或没有接到都会累计一次洒落，但已经正确装盘的步骤不会清空。每张订单三样食材，完成后明确进入下一单；四单全出完共同成功，累计三次洒落则本轮结束。

## 随机与动画边界

- 每轮从六张内置菜谱无偏抽四张，每一步的三条滑槽恰好包含一个正确食材和两个不同干扰项；
- 浏览器使用 `crypto.getRandomValues` 与拒绝采样，不回退到 `Math.random`；
- 每件在途食材有单调 token；动画完成、计时器兜底或页面失焦只能结算当前 token 一次；
- 减少动态模式会缩短飞行等待，但不会改变接取规则。

## 隐私与本地边界

- 不联网、不上传、不保存，不请求文件、相机、麦克风、剪贴板或传感器权限；
- 订单、盘子、洒落与结果只在当前页面内存中，刷新即清空；
- 所有策略信息公开，没有隐藏答案或私人内容。
