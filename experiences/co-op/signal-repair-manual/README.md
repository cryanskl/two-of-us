# 把信号接回来

一款两人面对面、同机游玩的 A 级合作推理体验。操作员只能看到三条故障星路，领航员只能看到三条优先规则；两人通过口述，在 45 秒内接回唯一正确的分支。四轮逐轮交换角色，超时可以原题重试，没有生命、爆炸、分数或排行榜。

## 打开方式

直接双击 `index.html` 即可游玩，也可以从仓库统一门户打开。作品使用经典脚本和本地资源，不需要安装依赖、联网、账户、麦克风或浏览器存储。

## 操作与摆放

- 桌面宽屏：把设备放在两人中间，北席内容会整体旋转 180°；
- 窄屏：页面取消旋转，按单列提示依次交接设备；
- 两席分别点击“我准备好了”，第二席确认后会直接开始本轮；
- 操作员点击 A/B/C 分支，也可以按键盘 `A`、`B`、`C`；
- `Escape` 暂停，页面隐藏或窗口失焦也会暂停，返回后必须手动继续。

本作采用同桌荣誉制：playing 时两类信息同时存在于页面，不应被当作安全秘密。`config.js` 中的双方称呼和私人传输会随目录一起分发，提交或分享仓库前请先检查内容。
