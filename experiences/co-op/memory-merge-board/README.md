# 把小事，合成我们的故事

`memory-merge-board` 是一个尚未安装的非视觉核心候选。两个人共用一页
4×3 回忆线索：整理者决定整页滑动方向，补页者从两张公开线索中选择一张并决定
来向边缘落点；有效完整回合后交换职责。相同主题、相同阶段的线索会合成，完成的
章节离开棋盘进入共同相册。

## 当前阶段

本目录当前只允许包含：

- 经典脚本与 CommonJS 同构的冻结配置；
- 纯规则与 reducer；
- 三个固定关卡；
- 确定性求解器与黄金路径；
- Node 项目测试；
- README 与借鉴声明。

本阶段明确没有 `index.html`、`styles.css`、`app.js`、favicon 或浏览器资产，
因此还不能直接打开、不能计入 catalog，也不声称已经 installed。视觉、键盘、
Pointer、响应式和真实 `file://` Gate 留待用户确认视觉提案后实施。

## 固定核心合同

- 棋盘为 3 行 × 4 列，共 12 格。
- 主题为地点、味道、声音、照顾。
- 阶段为碎片、片段、故事、章节。
- 只有同主题、同阶段的相邻线索可在一次整盘滑动中合成。
- 新合成结果在同一次滑动中不能再次合成。
- 章节形成后离开棋盘。
- 有效滑动后，补页者从公开候选中选择碎片并放到来向边缘。
- 补页成功后交换整理者与补页者。
- 三个不同主题章节共同完成关卡。
- 分享继续与留白具有相同规则后继，不记录选择。
- 关卡与供给完全固定，不使用随机数、分数或最高分。

## 隐私、依赖与运行边界

- 项目级第三方运行依赖：0。
- 网络、账号、服务、浏览器存储与设备权限：0。
- 姓名、日期、照片、音频、视频和自由文本输入：0。
- 规则核心不使用 DOM、时钟、随机数、网络、存储或权限 API。
- 未来完整页面必须使用仓库内普通相对资源并支持直接 `file://` 打开。

## 核心测试

核心完成后使用：

```bash
node --test experiences/co-op/memory-merge-board/*.test.js
npm test
npm run verify
```

三关必须由确定性求解器证明可解，黄金路径必须能经真实 reducer 重放，正式关还
必须证明候选选择与边缘落点存在实质分支并保持在固定状态访问上限内。

## 核心文件

- `config.js`：4×3 棋盘、四主题、四阶段、双席与原创分享文案。
- `logic.js`：线索校验、整盘滑动、一次合并、章节出板、状态机与公共 view。
- `levels.js`：三个冻结关卡和经求解器确认的黄金动作路径。
- `solver.js`：Node 专用的有界确定性最佳优先搜索、动作枚举、重放与分支分析。
- `logic.test.js`：规则、不变量、失败与 hostile 输入测试。
- `solver.test.js`：三关可解性、确定性、分支、状态上限和静态边界测试。

## 固定关卡证明

求解器不使用随机探索。它按固定动作顺序和稳定优先级搜索，以 canonical state key
去重，并在状态上限前给出可由真实 reducer 重放的 witness。

| 关卡 | 访问状态 | 生成状态 | 黄金动作 | 完整回合 | 实质候选分支 | 多落点分支 |
|---|---:|---:|---:|---:|---:|---:|
| `first-page` | 4161 | 6769 | 28 | 8 | 5 | 8 |
| `crossed-notes` | 4161 | 6769 | 28 | 8 | 5 | 8 |
| `album-night` | 4163 | 6771 | 28 | 8 | 5 | 8 |

测试使用 10,000 个访问状态的严格 Gate；默认求解器上限 120,000，只作为未来内容
诊断边界。任一关超过测试 Gate、路径不确定、replay 失败、少于三次完整换位，或
正式关少于两次实质候选/多落点分支，测试都会失败。
