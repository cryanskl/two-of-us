# 同机你画我猜

一个 A 级双人合作游戏。两个人在同一台设备轮流看词、隐藏题目、画画和猜词，六轮累计共同得分。

## 启动

直接双击 `index.html`。无需安装、服务器或网络。

## 定制

在 `config.js` 修改题库、回合数和单轮时间。题库数量必须不少于回合数。

## 标签

`双人合作` · `A 级` · `单设备轮流` · `鼠标/触屏/键盘` · `公网依赖：无`

## 借鉴与来源声明

玩法使用传统 Pictionary / 你画我猜的通用规则。本实现根据本仓库的“热座交接遮挡 + 共同得分”规格独立编写，没有复制或改写调研候选中的源码、题库、视觉或素材，也没有第三方运行依赖。

除传统玩法规则外，本作品的交接状态机、画布交互、计时、计分、界面和示例题库均在本仓库内独立实现。
