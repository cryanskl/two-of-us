# 七日小花园视觉资产

本目录的三张 PNG 是 2026-07-21 使用 OpenAI 内置 ImageGen 以纯文字提示生成的原创生产资产，没有第三方图片输入：

- `garden-table-background.png`：清晨窗边空花桌背景；
- `plant-states.png`：由洋红底源稿本地去底得到的 8 阶段 RGBA 植物图集；
- `completion-keepsake.png`：带 7 片叶印的完成手账背景。

源稿、生成方式、尺寸、SHA-256、去底参数与概念审校见 [`docs/163-seven-day-garden-design.md`](../../../../docs/163-seven-day-garden-design.md)。运行时关键信息全部由 DOM/CSS 表达；图片缺失时页面必须切换到 CSS 备用植物与纯色纸面，不能影响规则或操作。
