# 把七天，养成一朵花

「把七天，养成一朵花」是一款本地单设备双人合作游戏。两个人各有一只公开的工具篮；七天中每天各出一张浇水、补光或修剪卡，让两张卡合上当日花签，同时为后面的日子留够工具。

## 启动

本作为 A 级本地体验，无需安装依赖或启动服务器。

1. 双击本目录的 `index.html`；
2. 点击“开始这七天”；
3. 两个人按照页面提示轮流接手，完成七日照料。

macOS 也可在仓库根目录运行：

```sh
open experiences/co-op/seven-day-garden/index.html
```

页面通过 `file://` 直接运行。请保留 `index.html`、`styles.css`、`config.js`、`logic.js`、`app.js` 与 `assets/` 的相对位置。

## 玩法

- 七日花签、双方工具篮、植物状态和当天已经放下的卡始终公开；
- 每天两席各选择一张卡，先行动的人逐日交换；
- 当天两张卡既要合上花签，也要为后面的日期留够工具；
- 没合上时，两张卡都会归还，只重新商量今天；此前完成的日期不会回退；
- 交接不是秘密遮屏，只用于防止连续误触并明确下一位操作者；
- 可点击原生工具按钮，也可用 `W` 浇水、`S` 补光、`P` 修剪。

页面不会显示唯一完整路线，也不会在失败时指出哪一席应该换成哪张牌。完成页只记录共同照料，不计算分数、速度、排名或个人贡献。

## 同机信任边界

请在同一台设备上轮流操作。页面能够保证每天需要两个不同席位各提交一次，但无法识别现实中是谁按下按钮，也不会使用账号、摄像头、传感器或身份验证来监控操作者。

## 本地配置

准备者只需修改 [`config.js`](./config.js) 中的两个称呼和 `composeCompletionNote(summary)`。默认配置无需修改即可完整游玩。

称呼会去除首尾空白并按 Unicode code point 截至 12 字；空白、重复或畸形称呼整组回退。结语函数只收到递归冻结、与真实状态断开的完成摘要，应返回不超过 120 个 code point 的纯文本；空白、超长、Promise、异常或尝试修改摘要都会回退到安全结语。配置不能改变七日花签、工具库存、先手、求解器、失败条件、视觉资产或来源声明。

## 本地、隐私与无障碍

- 使用经典脚本顺序 `config.js → logic.js → app.js`，没有构建步骤、模块脚本或第三方运行依赖；
- 不使用网络、CDN、远程字体、账户、服务端、统计、分享、存储、Cookie、随机数、真实日期、音频、振动、媒体或传感器；刷新即重置；
- 每个阶段通过真实 DOM 重建，键盘焦点会进入新阶段标题，状态变化通过独立的 polite live region 播报；
- `prefers-reduced-motion` 会关闭表现动画，forced-colors 会保留原生边框、文字、状态图形和焦点环；
- 三张运行时图片加载失败时，CSS 植物、纯色纸面、真实花签、工具篮、按钮和结果仍能完成全部流程。

详细依据见[定向调研](../../../docs/161-seven-day-garden-research.md)、[产品与实现规格](../../../docs/162-seven-day-garden-spec.md)、[视觉设计](../../../docs/163-seven-day-garden-design.md)与[实施计划](../../../docs/164-seven-day-garden-plan.md)。

## 生成资产说明

三张运行时 PNG 均由本项目在 2026-07-21 使用 OpenAI 内置 ImageGen、仅以本项目原创纯文字提示生成，没有输入第三方图片、开源项目截图、商业素材或角色。背景只承担清晨窗边光线与花桌材质，植物图集只承担八阶段质感，完成图只承担标本手账氛围；规则、日序、库存、席位、卡牌、状态、按钮与摘要全部由本地 DOM/CSS 和规则层表达。尺寸、SHA-256、图集去底处理与完整台账见 [`assets/README.md`](./assets/README.md) 和 [`ATTRIBUTION.md`](./ATTRIBUTION.md)。
