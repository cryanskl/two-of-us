# 节拍接力

两个人在同一台设备上轮流接住一段双音序列：先看见并听见珊瑚拍 / 青绿拍，按原顺序复现，再亲手追加一拍交给对方。把 3 拍接到 10 拍即共同完成。

## 怎么打开

这是 A 级体验。直接双击本目录的 `index.html` 即可游玩，不需要执行 `npm install`、启动服务或连接公网；也可以从 Two of Us 根门户打开。

## 怎么玩

1. 点击“开始接力”，把设备交给当前一棒；
2. 当前玩家点击“准备好了”，看纸带亮起并听两种音色；
3. 播放结束后用 `F / J` 或两枚大按钮按原顺序复现；
4. 全部正确后任选一拍追加，交给下一棒；
5. 双方轮流把序列接到 10 拍。共有三次共享回声，失误后由同一玩家重听。

Web Audio 只是渐进增强：关闭声音或浏览器不支持音频时，纸带与按键高亮仍提供完整信息。页面切走或失焦会取消正在播放的计时器，回来后必须明确从头重播。

完整的自动检查、Chrome 实玩、响应式和视觉忠实度证据见 [`docs/35-rhythm-relay-verification.md`](../../../docs/35-rhythm-relay-verification.md)。

## 本地优先与隐私

- 公网依赖：无；第三方运行依赖：无；
- 不使用麦克风，不读取媒体文件，不上传或保存音频；
- 初始序列由浏览器 `crypto.getRandomValues` 在本机生成；
- 序列、进度与失误只在当前页面内存存在；刷新即清空；
- 不使用 `fetch`、XHR、WebSocket、CDN、远程字体、localStorage、sessionStorage、IndexedDB、Cache API、Service Worker、账号、统计或遥测。

## 借鉴与来源声明

创意来自本仓库 [`docs/40-idea-backlog.md`](../../../docs/40-idea-backlog.md) 的 C15“节奏接力”。序列记忆是常见玩法类型，但本作品没有复制、改写或引入任何开源项目的代码、视觉、音效、题库或素材。

双人接力规则、交接遮挡、共享回声、状态机、Web Audio 合成、DOM、CSS、中文文案与测试均为本仓库自行实现。视觉概念由 OpenAI ImageGen 根据仓库规格生成，只作设计基准，不进入运行依赖。若未来实际参考或引入开源项目，必须在此补充固定来源、commit、许可证、借鉴内容与未复制边界。
