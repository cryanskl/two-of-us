# 星座接线员视觉资产

本目录两张 PNG 是 2026-07-21 使用 OpenAI 内置 ImageGen 以纯文字提示生成的原创生产资产，没有第三方图片输入：

- `observatory-console-background.png`：中央留白的暗梅/石墨观测台材质背景；
- `completion-keepsake.png`：严格 9 个瓷白节点、10 根发光线路的双翼星鸢完成纪念图。

源稿、概念、生成方式、尺寸、SHA-256 与审校结论见 [`docs/168-constellation-relay-design.md`](../../../../docs/168-constellation-relay-design.md)。运行时的点、边、席位、进度、结果、日志与操作全部由 DOM/CSS/SVG 表达；两张图片缺失时仍必须能从纯色接线板完整通关。
