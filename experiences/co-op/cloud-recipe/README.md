# 这一场雨，我们一起接

「这一场雨，我们一起接」是一款本地单设备双人合作游戏。左席只控制云朵左边，右席只控制云朵右边；两人要把闭区间调到刚刚好，接齐两颗同色彩滴，同时避开紧邻目标区间的灰滴。三份配方各三味，失败只重试当前一味，没有分数、生命、排名或双方表现比较。

## 启动

本作为 A 级本地体验，无需安装依赖或启动服务器。

1. 双击本目录的 `index.html`；
2. 点击“开始接雨”；
3. 两人确认当前配方后点击“接住第一味”；
4. 完成九味并共同调成三瓶天气饮料。

macOS 也可在仓库根目录运行：

```sh
open experiences/co-op/cloud-recipe/index.html
```

页面通过 `file://` 直接运行。请保留 `index.html`、`styles.css`、`config.js`、`logic.js`、`app.js` 与 `assets/` 的相对位置。

## 双席操作

- 左席使用 `A / D` 或左侧两个按钮，只移动云朵左边；
- 右席使用 `← / →` 或右侧两个按钮，只移动云朵右边；
- 键盘长按不会连发，每次按键或点击只移动一格；
- 云朵两端不能交叉，也不能越过七条雨道；
- 一波在固定 120 tick 后结算，接灰优先显示污染，漏彩滴则提示漏掉的方向；
- 重试从中性区间重新开始，不扣分、不比较谁造成了重试。

## 本地配置

准备者只需修改 [`config.js`](./config.js) 中的两个称呼和 `composeCompletionNote(summary)`。默认配置无需修改即可完整游玩。

称呼会去除首尾空白并按 Unicode code point 截至 12 字；空白、重复或畸形称呼整组回退。结语函数只收到递归冻结、与真实状态断开的完成摘要，应返回不超过 120 个 code point 的纯文本；空白、超长、Promise、异常或尝试修改摘要都会回退到安全结语。配置不能改变雨道、配方、tick、失败条件、视觉资产或来源声明。

## A 级、本地与隐私

- 经典脚本顺序固定为 `config.js → logic.js → app.js`，不使用 ES Module、构建步骤或项目私有依赖；
- 不使用网络、CDN、远程字体、账户、服务端、统计、分享、存储、Cookie、随机数、音频、振动、媒体或传感器；刷新即重置；
- `requestAnimationFrame` 只驱动本地固定 tick，页面隐藏、窗口失焦或 pagehide 会丢弃积压时间；
- 每个阶段都通过真实 DOM 重建，不在结果页保留不可见的活动雨滴、计时或旧按钮；
- 背景、云带或三瓶图片加载失败时，CSS/DOM 的雨道、水滴、把手、瓶形、文字和按钮仍能完成全部流程。

详细依据见[定向调研](../../../docs/151-cloud-recipe-research.md)、[产品与实现规格](../../../docs/152-cloud-recipe-spec.md)、[视觉设计](../../../docs/153-cloud-recipe-design.md)与[实施计划](../../../docs/154-cloud-recipe-plan.md)。

## 生成资产说明

三张运行时 PNG 均为本项目在 2026-07-21 使用 OpenAI 内置 ImageGen、仅以本项目原创文字提示生成的冻结源稿逐字节副本：背景、象牙云带和三瓶完成插画。没有输入第三方图片、开源项目截图、商业游戏素材或角色，也没有裁切、转码或二次合成。图片只承担气氛和材质，七道、落物、区间、状态、按钮与摘要全部由本地 DOM/CSS 和规则层生成。逐项尺寸与 SHA-256 见 [`assets/README.md`](./assets/README.md)。
