# 把颜色调到一起

一款同机双人合作的本地调色作品：玩家 1 用 `A / D` 调色相，玩家 2 用 `J / L` 调明度。两条刻度都对齐，就共同收下一张色笺；完成五张即合成一本共同色册。

## 打开方式

直接双击本目录的 `index.html`。作品使用经典脚本与本地资源，不需要安装依赖、启动服务或联网；也可以从仓库统一入口打开。

## 玩法

- 玩家 1：`A` 逆时针、`D` 顺时针；
- 玩家 2：`J` 深一点、`L` 亮一点；
- 鼠标与触屏可直接使用四个按钮；
- 每张色笺 24 秒，超时不会扣分，可立即重试同一张；
- 页面隐藏、窗口失焦或发生过长帧间隔时会安全暂停，不补扣离开时间。

显示层优先使用 OKLCH；不支持时自动改用 HSL。两种模式都只影响显示，不影响整数刻度、方向提示或成功判定。色彩信息也同时使用坐标、刻度、形状和文字表达。

## 借鉴与来源声明

「把颜色调到一起」是本仓库的原创零依赖实现。设计调研参考了 Colorfle 的“目标色与反馈”抽象回路、RGB Color Matching Game 的明确目标与文字反馈，以及 Coloris 的颜色控件可用性。最终实现没有复制这些项目的代码、算法、素材、题面、文案或依赖。

双人分轴、12 × 9 离散坐标、五张固定色笺、24 秒、失败无惩罚重试、中文文案、状态机与测试均由本仓库原创。背景资产由内置 ImageGen 原创生成。完整固定提交、许可证、标准依据与采用边界见 [`ATTRIBUTION.md`](./ATTRIBUTION.md)。
