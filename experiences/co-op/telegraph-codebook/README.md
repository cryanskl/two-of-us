# 默契电报码

两个人先共同记住六码本，再在同一台设备上轮流发送和译码。发送方按照目标打出三拍短 / 长讯号，交接后接收方听取播放并从四个词中选择；报码和译码都正确，才共同收下一分。

## 怎么打开

这是 A 级体验。直接双击本目录的 `index.html` 即可游玩，不需要安装依赖、启动服务或连接公网；也可以从 Two of Us 根门户打开。

## 怎么玩

1. 两个人一起查看“今晚的六码本”，准备好后开始；
2. 按提示把设备交给珊瑚方或青绿方，发送方独自查看目标；
3. 用 `S / L`、`.` / `-` 或两枚大电键录入三拍，Backspace 可撤回，Enter 可封存；
4. 交给接收方，播放结束后按 `1–4` 或点击一个词译码；每轮可按 `R` 重听一次；
5. 四轮角色交替，每人发送两轮，共同译对最多四封电报。

Web Audio 只是渐进增强：浏览器不支持或禁用音频时，每拍的灯光与“短 / 长”文字仍给出完整信息。页面失焦或隐藏会中止播放，回来后必须明确从头播放，旧计时器不会偷偷推进状态。

## 本地优先与隐私

- 公网依赖：无；第三方运行依赖：无；
- 不使用麦克风、摄像头、照片、位置、剪贴板或通知权限；
- 回合由浏览器安全随机源在本机生成；安全随机不可用时使用内置固定计划；
- 目标只在发送阶段进入 DOM；接收交接、播放和猜测阶段不会把目标、标准报码或完整已发报码放进隐藏节点；
- 这不是密码学隔离：查看源码或开发者工具仍可能发现 JavaScript 内存中的回合计划；
- 不使用 `fetch`、XHR、WebSocket、CDN、远程字体、localStorage、sessionStorage、IndexedDB、Cache API、Service Worker、账号、统计或遥测；
- 回合、报码和共同分只在当前页面内存存在，刷新即清空。

## 借鉴与来源声明

创意来自本仓库 [`docs/40-idea-backlog.md`](../../../docs/40-idea-backlog.md) 的 C10“默契电报码”。短 / 长脉冲编码是类似电报与摩斯码的通用概念，但本作品的六词映射、四轮合作规则、交接状态机、文案、DOM、CSS、Web Audio 和测试均为本仓库原创实现，不宣称使用国际摩斯电码，也没有复制或改写任何特定开源项目。

视觉概念由 OpenAI ImageGen 根据 [`docs/41-telegraph-codebook-spec.md`](../../../docs/41-telegraph-codebook-spec.md) 生成，只作为布局、配色与材质基准，不进入运行依赖。实现使用浏览器标准 API 与常见 Fisher–Yates 洗牌知识，没有引入第三方代码、图片、字体或音频。

逐项声明见 [`assets/ATTRIBUTION.md`](./assets/ATTRIBUTION.md)。若未来实际参考或引入开源项目，必须补充固定仓库链接、commit、许可证、借鉴内容、修改范围与未复制边界。
