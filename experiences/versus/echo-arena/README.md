# 回声擂台

同一台设备上的四音记忆对抗：当前玩家完整复现已有旋律，再亲手追加一个音；第一位按错的人输掉本局，先得两分者赢下比赛。

## 直接打开

双击 [`index.html`](./index.html) 即可。作品是 A 级经典脚本页面，不需要安装依赖、启动服务、账号或网络。

鼠标与触屏可点击四枚音键，键盘也可使用：

```text
1 = DO   2 = MI   3 = SOL   4 = LA
```

声音由浏览器即时合成。若浏览器限制或不支持 Web Audio，关闭声音后仍可依靠颜色、编号和按压动画完成整场比赛。

## 本地定制

编辑 [`config.js`](./config.js) 可以修改双方名字、第一局先手和每局开场音。

`chooseOpeningNote({ gameNumber, starter, noteIds })` 返回 `null` 时使用本地随机开场；返回 `do`、`mi`、`sol` 或 `la` 时，可以按局数组成你们自己的私密开场动机。策略抛错或返回其他内容会安全回退，不影响开局。

## 规则边界

- 三局两胜，后续各局严格轮换先手；
- 每轮先完整播放序列，当前玩家从第一音开始复现；
- 任一音按错，对方立即得到本局一分；
- 全部正确后必须追加一个音，再交给对方；
- 序列达到 16 音时共同封顶，本局不计分；
- 页面失焦会中断当前回放，回到页面后必须从第一音重新播放。

## 隐私与依赖

- 不发起网络请求；
- 不使用 localStorage、cookie、IndexedDB 或 Service Worker；
- 不录音、不采集麦克风、不保存名字、旋律或比分；
- 共享 [`tone-player.js`](../../../shared/audio/tone-player.js) 只管理本地 AudioContext 和短音节点；
- 背景、脚本和样式全部随目录或仓库本地提供。
