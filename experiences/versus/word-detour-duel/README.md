# 绕词对决

两个人在同一台设备上轮流描述、猜词并共同复核的本地小游戏。一局四回合，
每位玩家各描述两回合；每回合最多出现 6 张题卡。

## 直接打开

双击 `index.html`，浏览器以 `file://` 打开后即可游玩。页面使用经典相对脚本，
不需要安装依赖、启动服务器或连接网络。

自动化验收可以临时使用本地静态服务器，但这不替代 `file://` 直开合同。

## 怎么玩

1. 选择“纸飞机 / 晚风 / 星灯”牌组，以及 30、60、90 秒或不计时。
2. 猜词者背对屏幕，描述者确认只有自己在看后打开题卡。
3. 描述者绕开四个“不能说”的提示，让对方猜到中央目标词。
4. 猜中记 `+1`、踩词记 `-1`、跳过记 `0`。
5. 回合结束后把设备放回中间，只在两人一致时更正并确认成绩。

切出窗口、页面进入后台或主动点击“暂停并遮住”都会卸载当前题卡。回到页面
不会自动恢复，也不会自动继续计时；必须由描述者重新确认。

## 本地与隐私边界

- 页面不录音、不联网，也不使用本地存储、剪贴板、摄像头或麦克风。
- 题库、牌组和当前进程都是本地明文，不是加密内容；同机开发者工具仍可查看
  `config.js` 中的完整题库。
- 目标词只在合法的描述阶段进入 DOM；交接、暂停、回合结束与终局页面不会保留
  题卡节点。
- 读屏或系统朗读会通过共享扬声器读出秘密。使用辅助技术时，请改用耳机，或在
  猜词者离开听力范围后再打开题卡。
- 刷新或关闭页面会清空当前对局，没有恢复机制。
- 这是信任型玩法：页面不会判断玩家说了什么，也不会自动判罚。踩词由两人主动
  记录，并在回合后共同复核。

## 自定义与测试

`config.js` 内含 72 张原创中文题卡和三套对称 schedule。修改目标词或四个禁用
提示后，需要重新检查长度、去重、碰撞和 schedule 覆盖，不能只看页面是否能打开。

在项目目录执行：

```sh
node --test logic.test.js ui-contract.test.js
```
