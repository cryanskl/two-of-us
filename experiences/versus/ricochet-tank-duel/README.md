# 这一弹，拐弯见你

两个人共用一台设备，同时驾驶两辆抽象“折光车”：读懂墙面折射，躲开来弹，
先命中三次。双方若在同一个逻辑刻命中，会同时得分。

## 打开方式

直接双击本目录的 `index.html`。作品使用经典相对路径脚本，不需要安装 npm
依赖、启动服务器、联网、加载远程字体或写入浏览器存储。刷新页面会重置比赛。

本地服务器只用于开发调试，不是玩家依赖：

```bash
python3 -m http.server 4173
```

## 操作

| 席位 | 前进 | 后退 | 左转 | 右转 | 发射 |
| --- | --- | --- | --- | --- | --- |
| 左方 | W | S | A | D | F |
| 右方 | ↑ | ↓ | ← | → | Enter |

- `P`：暂停；暂停时再次按 `P` 可继续。
- `Escape`：只暂停，不直接恢复。
- 页面按钮、两侧五键触控区与键盘可同时使用。
- 触控区支持多个独立 `pointerId`；抬起、取消或失去 capture 都会释放对应动作。
- 页面失焦、隐藏、离开或浏览器出现长帧时，双方输入会一起清空并公平暂停。

部分消费级键盘存在硬件按键矩阵冲突；如果某组多键组合无法同时识别，可让一方或
双方改用页面触控按钮。这是硬件 ghosting 限制，不改变游戏的同步输入规则。

## 规则

- 一张 960×600 的固定镜像地图，左右玩家分别在自己的活动区移动。
- 车头决定光点方向；光点可以穿过中央通道进入对方区域。
- 每方最多有 2 枚光点在途；冷却 24 tick（0.4 秒）。
- 每枚光点最多反射 3 次、存留 360 个活跃 tick（6 秒）。
- 每个逻辑 tick 最多处理 4 次接触，第 5 个候选接触前安全销毁。
- 光点不自伤、不互撞；命中同一目标的多枚光点在同一 tick 只计 1 分。
- 先到 3 分者胜；双方同刻都到 3 分则平局。
- 比赛活跃时间最多 5400 tick（90 秒），到时先结算当刻命中，再按比分判定。

模拟固定为 60 Hz。渲染帧率、窗口尺寸、设备像素比和 reduced-motion 都不会进入
逻辑状态或改变碰撞结果。

## 暂停与恢复

暂停会冻结车辆、光点、冷却和比赛时间，丢弃渲染累加器并清空所有持续输入。
继续后不会补算离开页面期间的时间，而会重新经过完整的 3、2、1 倒计时。

自动暂停来源包括：

- 页面隐藏；
- 窗口失焦；
- `pagehide`；
- 单帧间隔超过 250 ms；
- 单帧需要补算超过 5 个固定 tick；
- 检测到逻辑不变量异常。

## 可访问性与显示模式

- 标题、比分、时间、规则、控制和结果都是真实 HTML 文本。
- Canvas 外持续显示双方朝向、粗粒度位置、在途数量、冷却和最近来弹。
- 左方用“左”文字、实心方向楔和实心光点；右方用“右”文字、条纹方向楔和空心
  光点，不只依赖珊瑚 / 湖蓝颜色。
- 所有操作按钮可 Tab 聚焦，具有清楚的焦点环和至少 44×44 CSS px 的目标。
- `role="status"` 只播报倒计时、暂停、命中和终局，不逐 tick 朗读位置。
- `prefers-reduced-motion: reduce` 移除装饰尾迹与位移动效，但保留玩法必需运动。
- `forced-colors` 使用系统文字、背景、边框与焦点颜色，阵营形状和文字仍保留。
- 页面支持从大桌面到 320 px 窄屏的自然重排，不锁定横竖屏。

诚实限制：实时空间躲避依赖持续感知赛场运动。文本投影能让规则、状态与结果可读，
也便于两人协作，但不能为完全非视觉玩家提供与视觉竞技完全等价的操作体验。
