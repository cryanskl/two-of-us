# 这一串，我还记得

一个同机双人记忆竞拍游戏。你们先共同观看八件旅行纪念物，再轮流公开报价自己能按顺序记住前多少件；最高报价者现场证明。

## 打开方式

直接双击 `index.html`，或把整个 `memory-bid` 目录复制到任意位置后双击打开。页面使用经典脚本和相对路径，不需要安装依赖、启动服务或联网。

## 怎么玩

1. 开局选择“让旧物自己经过”或“我们自己翻下一件”。播放方式整场不变。
2. 两个人共同看完八件旧物。自动模式可以暂停，手动模式每次由你们决定何时翻下一件。
3. 本轮先手从 2–8 中开价；之后只能报更高的数量或“就到这里”。
4. 最高报价者按顺序点出对应数量的旧物。全对自己得 1 分；错一件或主动认输，对方得 1 分。
5. 固定四轮，双方各先开价两次。四轮后总分高者获胜，2–2 是正式平局，不加赛。

证明阶段可以用数字键 `1–6` 选择物件、Backspace 撤回上一件、Escape 清空。所有操作也都有可点击的原生按钮。

## 隐私与依赖

- 序列只存在当前页面的本机内存中，刷新即清空；不使用浏览器存储。
- 不使用网络、账号、服务端、CDN、外部字体、音频、摄像头、麦克风或传感器。
- 图片加载失败时，编号、名称、轮廓占位和全部规则仍可操作。
- 页面隐藏或窗口失焦时会盖住正在展示的物件；返回后需要主动点击继续，不会在后台跳过。

## 可选个性化

无需修改即可完整游玩。准备者如果想给终局增加自己的话，可以在 `config.js` 的 `composeMatchNote(summary)` 中按注释改 5–10 行，只返回纯文本；不要把私人信息写进公开仓库。
