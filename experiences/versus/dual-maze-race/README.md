# 同路，谁先到

一个本地双人同屏迷宫竞速。两个人面对同一张完整迷宫，同时逐格移动；每张地图交换
一次左右席，四局后按公开积分决定结果。

## 直接开始

双击本目录的 `index.html` 即可。页面使用经典相对脚本，不需要安装依赖、启动服务器、
注册账号或联网。

建议两个人坐在同一块键盘或触屏前：

- 左席：`W` / `A` / `S` / `D`；
- 右席：方向键；
- 两组屏幕方向按钮可用于鼠标、键盘焦点和触屏；
- 每次按键或按钮 activation 只提交一个离散方向，不支持长按连发。

## 四局规则

| 局 | 地图 | 左席 | 右席 |
| ---: | --- | --- | --- |
| 1 | COUP | 玩家一 | 玩家二 |
| 2 | COUP | 玩家二 | 玩家一 |
| 3 | PAIR | 玩家一 | 玩家二 |
| 4 | PAIR | 玩家二 | 玩家一 |

- 两块棋盘在每局共享同一份只读迷宫数据，朝向、墙、起点和终点完全相同；
- 规则以 30Hz 固定逻辑拍结算，每拍最多消费双方各一个方向；
- 合法方向前进一格，撞墙留在原地并增加该玩家的撞墙数；
- 先到终点得 1 分；同一逻辑拍到达，双方各得 0.5 分；
- 四局总分较高者获胜；总分相同就是整场平局；
- 用时和撞墙数只供复盘，不是隐藏决胜条件。

每局开始前倒数 3 秒。手动暂停、页面隐藏、窗口失焦、页面离开或浏览器长帧都会安全
暂停并清空待处理输入；继续前重新倒数 1.5 秒，后台时间不会补跑。

## 输入检查的诚实边界

赛前需要分别试完两席的四个方向，并尝试同时按住 `D` 与 `←`。这只能证明浏览器收到
当前公开组合，不能保证所有物理键盘都不会 ghosting。若联合检测失败，页面会建议改用
两组触控按钮，也允许在明确了解风险后继续。

浏览器和设备也可能限制并发触点。目标设备若不能稳定接收两个人的同时输入，请换一块
键盘、改用鼠标与触控组合，或换设备；页面不会把硬件漏报描述成玩家失误。

## 本地、隐私与降级

- 不发送网络请求；
- 不使用 localStorage、sessionStorage、IndexedDB、Cookie 或 Cache API；
- 不读取或保存名字、比分与历史；
- 不申请摄像头、麦克风、定位、文件、振动或通知权限；
- 不加载远程字体、图片、音频、统计或第三方运行库；
- JavaScript 关闭时只显示静态说明，不伪装成可玩的比赛；
- `prefers-reduced-motion` 只取消视觉过渡，不改变 tick、倒数、积分或赢家；
- forced-colors 使用系统色、圆形/菱形和轮廓冗余保留辨识。

320px 窄屏仍并排显示两块迷宫，控制区允许纵向滚动。所有方向按钮至少
`52 × 52 CSS px`。实时速度对抗的视觉体验无法对所有辅助技术完全等价，本项目不声称
获得完整 WCAG 认证。

## 可定制内容

只编辑 `config.js`：

```js
var playerNames = Object.freeze(["玩家一", "玩家二"]);

function composeMatchNote(summary) {
  void summary;
  return "同一条路，换个位置，再比一次。";
}
```

可修改两个默认称呼和整场结束后的纯文本赠言。核心会清理、截断并冻结输入；配置不能
改变 seed、迷宫、赛程、tick、积分或赢家。请不要把私人信息提交到公开仓库。

## 验证

在仓库根目录运行：

```bash
node --test experiences/versus/dual-maze-race/logic.test.js
node --test experiences/versus/dual-maze-race/ui.contract.test.js
npm test
npm run verify
git diff --check
```

`npm test` 与 `npm run verify` 依赖仓库根目录既有开发依赖；它们不是最终用户直开本作
的前置条件。
