# 气球胆量局

两个人轮流面对一只隐藏爆点的气球：每次安全打气都会提高本轮待收分，也可以随时见好就收；碰到爆点只清空当前待收分。四个大轮、双方各完成四只气球后，总分高者获胜。

## 怎么打开

这是 A 级体验。直接双击本目录的 `index.html` 即可游玩，不需要执行 `npm install`、启动服务或连接公网；也可以从 Two of Us 根门户打开。

## 怎么玩

1. 珊瑚方与青绿方按页面提示轮流接过设备；
2. 点击“再打一泵”或按 `↑`，安全后待收分按 `1 / 3 / 6 / 10…` 增长；
3. 点击“见好就收”或按 `↓`，把待收分加入总分；
4. 达到本回合隐藏爆点时，只有待收分清零，总分不倒扣；
5. 四轮共八个回合全部完成后比较总分，允许平局。

爆点均匀分布在第 4–8 泵，所以前三泵绝对安全。四轮的先后手交替，双方各有两次先行动和两次后行动。

## 本地优先与隐私

- 公网依赖：无；第三方运行依赖：无；
- 爆点使用浏览器 `crypto.getRandomValues` 在本机生成，并通过拒绝采样避免 32 位余数偏差；
- 爆点、进度与比分只在当前页面内存存在，刷新即清空；
- 不读取照片、麦克风、摄像头、剪贴板或传感器；
- 不使用 fetch、XHR、WebSocket、CDN、远程字体、localStorage、sessionStorage、IndexedDB、Cache API、Service Worker、账号、统计或遥测。
