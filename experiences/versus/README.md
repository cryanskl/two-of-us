# 双人对抗

这一类作品让两个人轮流或同时操作，以分数、速度或胜负作为结果，例如井字棋、反应挑战和双人 Pong。

作品既可以同机运行，也可以采用 C 级局域网双设备；公网匹配只在明确需要异地游玩时考虑。

## 已收录

- [反应力对决](./reaction-duel/)：同屏抢按、抢跑送分、三局两胜。
- [心动拔河](./ribbon-tug/)：同屏用 A/L 或左右触控区持续拉动织带，先赢两局完成比赛。
- [气球胆量局](./balloon-dare/)：单设备轮流给隐藏爆点气球打气或收手，四轮后比较存下的总分。
- [数字凑靶](./number-target/)：从共享市场轮流拿两张数字和一个运算符，三局比较谁的算式离目标更近。
- [纸上球局](./paper-soccer/)：轮流在点阵上画不可重复线，利用旧点借力，把球送入对方球门或封住出口。
- [这一格归谁](./dots-and-boxes/)：轮流连接相邻点，闭合一格就得分并继续，16 格写满后比较归属。
- [光轨围猎](./light-trail-hunt/)：两束光同时持续前进，用转向留下永久轨迹；撞墙或撞线者落败，同 tick 双亡则平局。
- [这一颗我先到](./orbit-star-race/)：两枚卫星反向自动绕行，只切换内、中、外轨改变角速度，先碰到五颗星且比分不等者获胜。
- [藏好这一味](./secret-recipe-code/)：两人轮流藏好四格配方并遮屏交接，根据同位与错位反馈破译；交换角色后以更少猜测次数获胜。
- [这一串，我还记得](./memory-bid/)：共同看完八件旅行旧物后公开升价，最高报价者按顺序证明；四轮双方各先开价两次。
- [这一朵，我先养开](./garden-resource-duel/)：轮流遮屏藏下有限的阳光、雨露或虫害牌，共同揭晓后按季节长花瓣，先让自己的花开放。
- [这一颗，绕回来找你](./heart-catapult/)：轮流秘密选择角度和力度，两颗爱心直接或反弹飞向对方城堡，完整一轮后联合计分。
- [软软相扑](./soft-sumo/)：两枚软垫棋子同时转向、蓄力和冲刺，在收紧的圆形擂台上互推，三轮比较站稳次数。
- [心跳冲刺](./heart-sprint/)：两台设备加入本地房间，用手机连续点击推动跑者，先赢两局完成比赛。
- [连心四子棋](./lan-connect-four/)：两台设备加入本地房间，轮流落子，率先横、竖或斜向连成四颗获胜。
- [密封猜拳](./sealed-rps/)：双方在各自设备秘密出拳，由可信本机裁判收齐后同时揭晓，三局两胜。
