# 双人对抗

这一类作品让两个人轮流或同时操作，以分数、速度或胜负作为结果，例如井字棋、反应挑战和双人 Pong。

作品既可以同机运行，也可以采用 C 级局域网双设备；公网匹配只在明确需要异地游玩时考虑。

## 已收录

- [反应力对决](./reaction-duel/)：同屏抢按、抢跑送分、三局两胜。
- [心动拔河](./ribbon-tug/)：同屏用 A/L 或左右触控区持续拉动织带，先赢两局完成比赛。
- [气球胆量局](./balloon-dare/)：单设备轮流给隐藏爆点气球打气或收手，四轮后比较存下的总分。
- [数字凑靶](./number-target/)：从共享市场轮流拿两张数字和一个运算符，三局比较谁的算式离目标更近。
- [心跳冲刺](./heart-sprint/)：两台设备加入本地房间，用手机连续点击推动跑者，先赢两局完成比赛。
- [连心四子棋](./lan-connect-four/)：两台设备加入本地房间，轮流落子，率先横、竖或斜向连成四颗获胜。
- [密封猜拳](./sealed-rps/)：双方在各自设备秘密出拳，由可信本机裁判收齐后同时揭晓，三局两胜。

更多候选与实现顺序见 [双人对抗类调研](../../docs/30-versus-research.md)。
