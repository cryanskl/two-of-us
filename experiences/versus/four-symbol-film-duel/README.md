# 四符片名擂台

一款给两个人同设备轮流玩的本地猜片名游戏。所有片名、选项、解释和中文符号
标签均为项目原创虚构文本，不需要了解真实电影。

## 直接开始

在 Finder 中双击本目录的 `index.html` 即可。页面使用原生 HTML、CSS 和
JavaScript，不需要安装依赖、启动服务或联网；刷新页面会回到开场。

## 一局怎么玩

- 先写下两位玩家的称呼并选择一个题包；
- 一局固定 8 题，玩家 A 与玩家 B 严格交替，每人各答 4 题；
- 每题根据四枚 Unicode 符号，从四个原创虚构片名中选择一个；
- 每人有 2 枚聚光灯，每题最多使用一次，固定排除一个错误选项；
- 直接答对得 2 分，使用聚光灯后答对得 1 分，答错得 0 分，即
  **2 / 1 / 0** 计分；
- 选择后会先进入确认页，只有“提交答案”才会结算；
- 八题结束后显示总分、胜负与逐题结果。

数字键 `1` 至 `4` 可以在猜题页选择对应选项；Tab、Shift+Tab、Enter 和空格
可以完成其余操作。鼠标、触控板和触屏也都使用同一套原生控件。

## 交接隐私

进入交接页时，下一题的符号、选项、答案和解释都不会出现在 DOM 中；不是
CSS 隐藏、模糊或用幕布盖住。下一位玩家明确点击“已准备好”以后，当前题面才会
创建。

这个边界保护的是普通热座交接、页面查找和可访问树，不宣称抵抗主动打开
DevTools 或查看本地源文件的人。题库本来就随本地游戏文件分发。

## 文本等价与本地边界

符号由本机系统以 Unicode 文本渲染，每枚符号都有项目原创中文等价标签。
开场可选择把等价文字始终显示在符号下；不勾选时，标签仍提供给屏幕阅读器。
该选择在一局开始后锁定。

游戏不请求网络，不保存姓名和对局，不使用 Cookie、Web Storage、摄像头、
麦克风、音频、字体、图片或分析服务。概念图只用于设计确认，没有接入运行页。
