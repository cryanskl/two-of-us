# 反应力对决

一个 A 级同屏双人对抗游戏。看到绿色信号后抢按；提前抢跑会把分数送给对方，先得两分获胜。

## 启动

直接双击 `index.html`。无需安装、服务器或网络。

## 操作

- A 玩家：键盘 `A` 或左侧触控按钮；
- B 玩家：键盘 `L` 或右侧触控按钮。

## 标签

`双人对抗` · `A 级` · `单设备同屏` · `键盘/触屏` · `公网依赖：无`

玩法采用通用的“等待随机信号后抢按、抢跑判负”反应测试规则，由本仓库独立设计界面和状态机；未复制或改写任何第三方开源项目的源码、视觉、音效或素材，也没有第三方运行依赖。

除通用反应测试规则外，本作品的抢跑判定、三局两胜流程、触控与键盘交互、视觉和代码均在本仓库内独立实现。
