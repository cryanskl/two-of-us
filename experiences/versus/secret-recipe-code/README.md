# 藏好这一味

两个人共用一台设备的本地热座推理游戏。一位玩家藏好四格秘密配方，把设备交给另一位；破译者最多试配七次，只得到“同位”和“有料”两个数量。第二轮交换角色，自己的破译次数更少者获胜。

## 直接打开

双击 `index.html` 即可运行。页面使用经典脚本和相对路径，不需要安装、构建、服务器或联网；也不读取仓库外的共享文件。

1. 配方师选四格配料，同一种最多两格，整份至少包含三种配料。
2. 点击“藏好配方”后，页面会删除设置草稿节点，再进入设备交接。
3. 破译者每次选四格并提交：“同位”表示配料和位置都对，“有料”表示配料存在但位置不对。
4. 七次内完全同位即成功；未猜中记 8。交换角色后比较两人的破译分，较低者胜。

秘密只保存在当前页面的 JavaScript 内存中，不写入 DOM、URL、浏览器存储、剪贴板或网络；刷新会清空整场。这是面对面交接的遮挡设计，不是密码学加密，打开开发者工具的人仍可能查看进程内存。

## 键盘与降级

- `1–6` 依次选择红莓、柑橘、薄荷、可可、蜂蜜、海盐；
- `Backspace` 删除当前草稿末格；
- 设置时按 `Escape` 盖住草稿，猜测时按 `Escape` 清空未提交草稿；
- `Tab`、`Shift+Tab`、`Enter`、`Space` 使用原生按钮路径；
- 设置阶段窗口失焦或页面隐藏会自动盖住草稿，但不会自动揭开；
- 背景图、动画或强制颜色不可用时，规则、反馈、成绩和重开仍然可用。

## 个性化

`config.js` 可以安全修改两位玩家的显示名、配料显示文案和默认结语。准备者还可以在 `composeMatchNote(summary)` 的小型策略函数里写一段专属结语；默认实现无需修改即可完成整场。
