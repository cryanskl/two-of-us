# 光轨围猎

两个人在同一块键盘或触摸屏上同时转向的本地轨迹对抗。双方每个逻辑 tick 都会前进一步；撞墙、撞上任何旧轨，或与对方在同一 tick 相撞，本轮立即结束。

## 直接开始

双击 [`index.html`](./index.html) 即可。作品不需要安装依赖、启动服务器或连接网络，也不读取和保存浏览器存储。

1. 点击“开始围猎”；
2. 玩家 1 用 `A` / `D` 左右转；
3. 玩家 2 用方向键 `←` / `→`，也可改用 `J` / `L`；
4. 触屏设备可同时按两组转向按钮；
5. 单局胜者得 1 分，最多三轮，先到 2 分即赢下比赛。

`Escape` 可以暂停或继续。页面失焦、进入后台或帧间隔异常时会安全暂停，不补跑积压的逻辑 tick。

## 本地边界

- 原生 HTML、CSS、JavaScript 与 Canvas 2D；
- `file://` 直接运行，无构建步骤；
- 无网络请求、第三方脚本、远程字体、音频或分析代码；
- 无摄像头、麦克风、定位或本地存储；
- 棋盘逻辑固定在离散网格中，Canvas 尺寸和设备像素比只改变清晰度，不改变比赛结果。

## 自定义

可在 [`config.js`](./config.js) 中修改两位玩家姓名和允许的比赛参数。所有姓名与文案都通过 `textContent` 输出；无效配置会回退到安全默认值。

## 借鉴声明

「光轨围猎」是基于经典 light-cycle / trail-survival 抽象机制重新设计的原创本地双人游戏。研究阶段参考了 `JDStraughan/html5-lightcycles`、`thatplatypus/LightCycle`、`dpren/WebGL-Tron` 与 `patorjk/JavaScript-Snake` 的公开规则描述及架构取舍。

最终实现没有复制这些项目的代码、素材、音频、字体、模型或依赖；游戏状态机、同时结算、界面、文案、视觉资产与测试均为独立实现。固定提交、作者、许可证和零复制范围见 [`ATTRIBUTION.md`](./ATTRIBUTION.md)。
