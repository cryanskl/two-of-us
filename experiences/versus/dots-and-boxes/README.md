# 这一格归谁

两个人在同一台设备上轮流连接相邻点：谁用一笔闭合一格，格子就归谁，而且可以继续落笔；16 格全部归属后，高分者赢下这一页。

## 直接打开

双击 [`index.html`](./index.html) 即可开始。作品是 A 级经典脚本页面，不需要安装依赖、启动服务、账号或网络。

鼠标、触屏和键盘都操作同一组 40 个原生边按钮。开始后焦点进入第一条空边；按 `Tab` 可移动到其他空边，按 `Enter` 或空格落笔。

## 规则

- 固定 4×4 方格、5×5 点与 40 条唯一物理边；
- 没有闭合格子时换手；闭合一格或同时闭合两格时得分并继续；
- 16 格全部归属后立即结算，允许 8–8 平局；
- 点击“再来一页”会清空棋盘，并让上一页的后手成为新先手；
- 不提供撤销、AI、联网、计时、尺寸选择或长期战绩。

## 本地定制

编辑 [`config.js`](./config.js) 可以修改两个玩家名。`composeResult({ winnerIndex, playerNames, scores })` 是一个可选的私人语气入口：返回 `{ title, body }` 可以把中性的终局改成你们自己的话；返回 `null` 或写错时会安全使用内置文案，不会影响比分和赢家。

## 隐私与依赖

- 不发起网络请求，不使用远程字体、脚本、图片、API 或 CDN；
- 不使用 Cookie、localStorage、sessionStorage、IndexedDB 或 Service Worker；
- 不保存玩家名、边、格子或比分，刷新页面即清空；
- 目录是完整独立作品，不引用 `shared/` 或其他体验目录；
- 本地纸纹缺失时回退为 CSS 方格纸，全部规则与输入仍可用。
