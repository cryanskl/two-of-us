# 同一张，谁先拼回

两个人在同一台设备上，用完全相同、保证可解的 3×3 滑块局面同时竞速。左边用
W/A/S/D，右边用方向键；鼠标和触屏也可以直接点各自棋盘中空格旁边的图块。第一方
完成后，另一方仍有 100 ms 结算机会；差值不超过 100 ms 时判为并列。

## 本地点开

双击本目录的 `index.html` 即可开始，不需要安装依赖、启动服务或连接网络。页面先用
Canvas 生成原创内置图，因此不选择照片也能完整游玩。

如果浏览器或安全策略限制本地 `file://` 页面使用文件选择或图片解码，可用任意静态
HTTP 服务打开本目录作兼容性排查；项目本身仍无后端和远程资源。

## 玩法

- 左边的你：W/A/S/D，方向表示空格向上、左、下、右移动。
- 右边的你：方向键，语义与左边相同。
- 鼠标或触屏：点击空格四邻域中的图块；不需要拖拽。
- 倒数、暂停、恢复倒数和结算后都不会接受移动。
- 页面隐藏或窗口失焦时双方同时暂停；回到页面不会自动继续。
- “同图再来一场”保留当前图片，但生成新的双方相同乱序。
- 刷新或关闭页面会丢失当前照片、棋盘与成绩。

## 本地照片

可选择 JPEG、PNG 或 WebP，限制为：

- 文件不超过 20 MiB；
- 短边至少 600 像素；
- 任一边不超过 6000 像素；
- 总像素不超过 2400 万；
- 中心裁切后最多输出为 1200×1200。

页面优先使用
`createImageBitmap(file, { imageOrientation: "from-image" })`
应用图片方向，再用 Canvas 中心裁切并重新编码。不同浏览器对方向元数据和超大图片的
处理能力可能不同；失败时当前可玩图片保持不变，也不会回显文件名或内部异常。

游戏只维护一个派生 Object URL，预览和两块棋盘共同使用。换图时先切换全部引用，再
在下一帧 `revokeObjectURL` 释放旧 URL；过期候选、恢复内置图、`pagehide` 和
`beforeunload` 也会清理。项目自身不上传、不保存、不分享照片，不使用网络、Storage、
摄像头、麦克风或录音；这不等于浏览器扩展、操作系统或用户截图在技术上无法接触页面。

请选择你自己拍摄、已获授权或有权使用的照片。本地处理不会改变照片的权利归属。

## 可访问性

- 所有图块都是原生按钮，Tab 可逐个到达，Enter/Space 可激活。
- 每个图块名称包含原图行列、当前行列和是否可移动。
- 页面不用 ARIA grid，避免与右方方向键的比赛语义冲突。
- 状态区播报倒数、开始、暂停、恢复、完成和图片结果，不逐帧播报计时。
- 支持 `prefers-reduced-motion`、forced colors、200% 缩放和 320 px 窄屏。
