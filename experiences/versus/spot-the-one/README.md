# 一眼看穿

一个 A 级、本地优先的双人对抗：两块并排的面板显示同一组图案，只有一格不一样——可能转了个角度、变了大小，或者线条粗细不同。两个人同屏各守一块面板，谁先点中那一格，这一分就是谁的。

- 类型：双人对抗 · 单设备同屏
- 输入：触屏各点各的面板，或键盘双席（左席 `W A S D` + `F`，右席方向键 + 回车）
- 时长：一局约 3–5 分钟
- 默认 5 题，题面从 3×3 逐题放大到 7×7；点错会被锁定 1.5 秒，对方照常作答
- 常规题打平自动加时一题，直到分出胜负

## 打开

在完整仓库内直接双击 [`index.html`](./index.html) 即可。也可以从仓库根目录运行 `start.command` / `start.bat`，再从统一门户打开。

- 不需要安装 npm 包，不需要服务器、账号或网络；
- 没有任何图片、音频或字体文件：所有图案都由代码在页面内生成；
- 刷新或点击“再来一局”会换一颗新种子，得到一组全新的题。

作品目录是自足的：单独复制 `experiences/versus/spot-the-one/` 就能玩，不依赖仓库里的任何其他文件。

## 玩法与公平性

1. 点击“开始第一题”，两块面板同时出现同一组图案；
2. 找出唯一不同的那一格，在**自己那块面板**上点中它；
3. 点对得 1 分并进入下一题；点错被锁定一小会儿，锁定期间不能作答；
4. 默认 5 题后比分高者获胜；打平自动加时，一题定胜负。

公平性设计：

- 两块面板由同一确定性种子生成，双方看到的题面与差异完全一致；
- 差异永远包含旋转、大小或线宽这类**几何变化**，明度偏移只是辅助——色觉不同的玩家不会因此吃亏；每个图形都带一根指针，任何旋转差异都清晰可见；
- 点错的惩罚只锁自己，不影响对方；
- 题面难度只随题号变化（格子变多、差异变小），与谁领先无关。

## 定制

用文本编辑器打开 [`config.js`](./config.js)，可修改两位玩家的称呼、常规题数（1–9）和点错锁定时长（300–5000 毫秒）。写错任何一项都会安全回退到默认值。

## 本地、隐私与降级边界

- 页面没有网络请求、输入框、账号、Cookie、`localStorage`、`IndexedDB` 或 Service Worker；
- 题面完全由确定性函数从种子推出，逻辑层不读取时钟，可逐题重放与测试；
- 全流程可以只用键盘完成；回合、得分、锁定与胜负都会通过 live region 播报；
- 尊重 `prefers-reduced-motion` 与 `forced-colors`：动画可全部停用，高对比模式下光标与揭晓格保留可见边框。

## 借鉴与来源声明

核验日期：2026-08-01。

本作**没有引入任何第三方源码、素材、字体、音频、图标或运行依赖**。页面结构、样式、题面生成模型、状态机、中文文案和测试均为本仓库独立创作，没有复制、翻译、改写、打包或依赖任何外部项目。

“找不同”（spot the difference）是公有领域的经典纸面游戏形式，本作只沿用“两幅近似画面中找出差异”这一公开的玩法概念；双面板对席、几何差异维度轮换、锁定惩罚与加时规则均为本作自己的设计。仓库内作品 `reaction-duel` 的“抢答罚则”与 `light-grown-tree` 的“整数散列替代 `Math.random`”思路对本作有启发，均为本仓库自有实现。确定性伪随机使用标准整数散列（Knuth 乘法常量与 MurmurHash3 finalizer 常量，均为公开发表的通用算法常量，不构成对某个具体项目的借鉴）。
