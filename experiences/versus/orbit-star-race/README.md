# 这一颗我先到

两个人在同一台设备上同时操作两枚反向绕行的卫星。你们不能前进或后退，只能切换内、中、外三条轨道；内轨更快、外轨更慢，先碰到五颗目标星且比分不相等的人获胜。

## 直接打开

双击 [`index.html`](./index.html) 即可开始。作品是 A 级经典脚本页面，不需要安装依赖、启动服务、账号或网络。

朱方使用 `W / S`，蓝方使用 `↑ / ↓`；触屏也可以点击各自的“升一轨 / 降一轨”。键盘与触控最终调用同一条规则路径。

## 规则

- 朱方顺时针、蓝方逆时针自动绕行；
- 内轨角速度最高，中轨居中，外轨最低；
- 目标星先预告 0.8 秒，再开放捕获；只有同轨且角距离足够近才得分；
- 同一个固定步内距离相等时双方共享该星，各加一分；
- 至少一方达到 5 分且比分不等时结束；5–5 会继续加赛；
- 不提供暂停、自由推进、燃料、射击、AI、联网、设置或长期战绩。

## 本地定制

编辑 [`config.js`](./config.js) 可以修改两个玩家名。`composeResult({ winnerIndex, playerNames, scores, sharedClaims })` 是一个可选的私人语气入口：返回 `{ title, body }` 可替换中性终局文案；返回 `null`、抛错或返回非法结构时安全回退，不会改变 seed、比分或赢家。

这段 formatter 正好是一个适合准备者亲手完成的小贡献：5–10 行就能把“今晚的星轨”改成你们自己的称呼、梗或约定。

## 隐私、依赖与降级

- 不发起网络请求，不使用远程字体、脚本、图片、API 或 CDN；
- 不使用 Cookie、localStorage、sessionStorage、IndexedDB、Worker 或 Service Worker；
- 不保存玩家名、seed、轨迹、claim 或比分，刷新页面即清空；
- 目录是完整独立作品，不引用 `shared/` 或其他体验目录；
- 本地星图或图集缺失时回退 CSS 星点、双色标记、四芒星和中央太阳，规则仍完整可玩；
- 页面失焦、隐藏或离开时清空帧累积，不补跑后台时间。

## 借鉴与来源声明

轨道速度关系依据 NASA 对开普勒第三定律与圆轨道周期的公开说明，归一化为 `ω ∝ r^-3/2` 的三档游戏规则。四个固定开源项目只用于比较教育玩具、完整轨道模拟、实时重力与双人太空输入的架构风险；本作没有复制或改写它们的代码、公式常量、DOM、CSS、依赖、素材、关卡、音乐或字体。
