# 数字凑靶

一款 A 级本地双人对抗：两个人从同一个市场轮流拿两张数字牌和一个运算符，组成 `左数 运算符 右数`；离公开目标更近的一方获得 1 分，固定三局后比较比分。

## 打开

直接双击 `index.html`，或从仓库根目录运行 `start.command` / `start.bat` 后在统一门户打开。页面没有安装步骤，也不依赖服务器。

## 规则

每局按六步蛇形顺序公开选牌：开局方先拿第一个数字，另一方拿数字并先选运算符，开局方再选运算符和第二个数字，最后由另一方选第二个数字。下一局开局方交替。

- 运算符只有加、减、乘；第一张数字固定在左，第二张固定在右；
- 两边都完成后比较与目标的绝对距离，更近者得 1 分；
- 等距时本局平局，双方不加分；精确命中会标记“正中靶心”，仍只得 1 分；
- 固定完成三局，不提前结束；最终也允许平局。

数字键 `1..9` 可选择对应数字；数字 10–12 使用牌面按钮。运算符阶段可按 `+`、`-`、`*`，也可以全程使用鼠标或触屏。

## 随机与公平边界

- 每局从 `1..12` 无重复抽八张数字；目标从这些牌可组成的 `10..81` 表达式结果中生成，所以题面至少存在一个精确解；
- 浏览器使用 `crypto.getRandomValues` 和拒绝采样生成无偏索引，不回退到 `Math.random`；
- 开局方由每场比赛安全随机，三局中严格交替。因为三是奇数，一方必然开两局，所以本作只承诺轻量休闲公平，不宣称竞技级完全对称。
