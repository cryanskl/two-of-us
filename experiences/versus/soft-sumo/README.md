# 软软相扑

两个人共用一台设备：左右转向，按住蓄力，松开冲刺，把对方推出持续收缩的圆形擂台。比赛固定三轮；同一逻辑 tick 一起出圈时，本轮平局。

## 打开方式

直接双击 `index.html`。作品使用经典脚本和相对资源，不需要安装依赖、启动服务或连接网络。

## 操作

- 莓果：`A` / `D` 转向，按住 `W` 蓄力，松开冲刺。
- 海盐：`←` / `→` 转向，按住 `↑` 蓄力，松开冲刺。
- 触屏或鼠标：双方各有“逆时针 / 蓄力冲刺 / 顺时针”三个原生按钮；可并发多指操作。
- 失焦、切到后台或画面长时间停顿会安全暂停并清空输入，点击“继续比赛”后重新倒数。

## 个性化

可在 `config.js` 修改两位玩家名和界面短句；`composeMatchNote(summary)` 只负责三轮结束后的结语。配置不能修改物理参数、三轮规则或胜负。

## 本地与降级边界

作品不使用网络、存储、随机、音频、传感器或第三方运行依赖，刷新即重置。背景 WebP 和棋子图集加载失败时，CSS 圆垫、编号、纹样、方向和全部控制仍可完成比赛。

固定 60 tick/s 的物理、缩圈和胜负只在 `logic.js` 中推进；`requestAnimationFrame` 只负责固定步调度和 DOM 投影。减少动态效果只关闭表现过渡，不改变比赛结果。
