# 这一颗，绕回来找你

两个人共用一台设备的本地热座投射对抗。双方轮流秘密选择角度和力度，两颗爱心按
固定规则依次飞行，完整一轮后才联合计分；爱心可以直接送进城堡，也可以在软垫上
反弹一次再绕回来。

## 直接打开

双击 `index.html` 即可运行。页面只使用经典脚本、相对路径和本地 SVG，不需要安装、
构建、服务器、账号、权限或联网，也不会读取仓库外的共享文件。

1. 每轮两位玩家依次接管设备，分别秘密调整角度和力度；
2. 锁定后草稿立即从当前 DOM 移除，交接页不显示任何已锁参数；
3. 两份参数都锁定后，按固定先手顺序分别播放；
4. 每颗爱心直接或反弹落进对方城堡时，为发射者增加一次送达；
5. 两颗都完成后才更新比分；先达到 3 次且领先者获胜；
6. 达到目标但同分会继续，12 个完整轮仍无领先者则平局；
7. 每轮交换先手，输入顺序不会造成提前计分优势。

## 键盘、遮屏与降级

- `Tab`、`Shift+Tab`、`Enter`、`Space` 使用原生控件完成整局；
- 两个原生 range 支持方向键；旁边的“− / +”按钮每次移动一档；
- 秘密瞄准时按 `Escape` 会丢弃未锁定草稿并遮住页面；
- 窗口失焦、页面隐藏或离开页面时也会自动遮屏并取消当前表现动画；
- 重新接管后焦点回到当前阶段标题，未锁定草稿从默认档位重新开始；
- Canvas 不可用、绘制异常、减少动态或动画帧 API 失败时，会直接显示同一份文字
  结果，规则和计分不会改变；
- 320px 窄屏、200% 文本、减少动态和强制颜色模式下仍保留规则、参数、结果和操作。

## 个性化

可在 `config.js` 中安全修改产品短句、两位玩家显示名和公开终局结语。配置只能影响
纯文本展示，不能修改物理常量、角度/力度档位、目标分数、轮次上限或胜负。

不要把用户输入解释成 HTML，也不要在仓库中提交真实姓名、纪念日或私人消息。

## 正常热座隐私边界

未揭晓参数只存在当前页面的 JavaScript 内存中，不写入 DOM、URL、浏览器存储、
剪贴板或网络。第一颗播放时不会创建第二颗的参数、轨迹或可访问占位；本轮比分只在
两颗都完成后一起更新。

这是两个人正常传递同一设备时的视觉遮挡，不是密码学加密。主动打开开发者工具、
检查进程内存或修改页面脚本的人，仍可能看到或改变内部状态。刷新或关闭页面会清空
整局，不提供存档、恢复、统计或导出。
