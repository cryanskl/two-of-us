# 一层一层

一款 A 级本地惊喜：体验者用四种不同输入依次拆开丝带、包装纸、抽屉和小盒盖，每完成一层读到一句留言，最后打开准备者留在盒心的话。

## 打开

直接双击 `index.html`，或从仓库根目录运行 `start.command` / `start.bat` 后在统一门户打开。作品不需要安装依赖或启动服务。

## 个性化

用文本编辑器打开 `config.js`。最推荐只改：

- `layerMessages` 的四条递进留言；
- `finalMessage` 的最终一句话。

也可以修改收件人、署名、标题、邀请和重看按钮。四层留言必须保持四条；配置结构或长度不合法时，页面会整份回退到默认内容，不会出现半份私人文案与半份默认文案混合。

## 规则

1. 分别解开左右丝带；
2. 揭开四个纸角；
3. 把抽屉拉到 80% 以上；
4. 轻敲小盒盖三次；
5. 每层留言必须明确继续，第四层之后才显示盒心。

鼠标、触控和键盘均可完成：按钮支持 Enter / Space，抽屉 range 支持方向键。

## 隐私与本地边界

- 不联网、不上传、不保存，不读取照片、音频或设备权限；
- 所有内容只在当前页面内存中，刷新即从头开始；
- 尚未拆到的留言不会进入正常页面 DOM，但它们仍是本地 `config.js` 明文，不构成密码学保密；
- 不使用 `Math.random`、第三方脚本、外部字体或 CDN。
