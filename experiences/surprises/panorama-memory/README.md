# 全景回忆

一款 B 级本地回忆体验：选择自己电脑里的一张完整 360° 等距柱状全景照片，在浏览器里拖动、缩放并回看当时的地点。

## 启动方式

- 等级：B（统一安装后，本地启动）
- 玩家：1 人准备，可 1–2 人一起回看
- 公网依赖：游玩时无
- 第三方运行依赖：Pannellum 2.5.7（由根目录统一安装）

首次使用时双击仓库根目录的 `setup.command`（Windows 使用 `setup.bat`），以后双击 `start.command`（Windows 使用 `start.bat`），再从统一门户打开“全景回忆”。

直接双击本目录的 `index.html` 时，页面只展示 B 级启动说明，不开放照片选择器。这不是故障：Pannellum 受浏览器本地文件安全限制，需要仓库提供的本地服务和固定依赖映射。

## 照片要求

- 支持 JPEG、PNG、WebP，单个文件不超过 40 MiB；
- 需要完整 360° 等距柱状全景，宽高比应在 1.9–2.1；
- 小于 `2048×1024` 可以打开，但会提示清晰度可能不足；
- 大于 `4096×2048` 会提示性能风险，超过 `8192×4096` 会拒绝加载；
- 普通横向照片、局部全景和损坏图片不会被猜测或强行投影。

选择有效照片后，可以用鼠标或手指拖动视角、用滚轮或加减键缩放、用方向键浏览，也可以进入全屏。首版不会自动旋转，也不会申请设备方向权限。

## 隐私与生命周期

照片由浏览器的原生文件选择器读取，只转为当前页面内的 `blob:` 对象地址。应用没有上传 API，不使用 `fetch`、表单提交、localStorage、IndexedDB、Service Worker、账号或云同步，也不会读取 EXIF、GPS 和拍摄时间。

新照片会先完成格式、解码、尺寸和比例验证；验证失败时保留当前有效全景。验证成功后才销毁旧 viewer 并释放旧对象地址。更换、清除、离开页面或快速连续选择时，也会销毁不再使用的 viewer 并撤销对应 URL。文件名只可能作为本地浏览器对象的一部分存在，不进入请求路径、服务日志或持久存储。

请只在自己控制的设备和可信网络中使用，不要把本地服务暴露到公网。

## 移动端边界

本作品验证当前 Chrome 桌面和 `390×844` 响应式控制区；触屏拖动由 Pannellum 提供。Pannellum 上游没有把所有移动浏览器、App WebView 或前端框架都列为官方支持目标，因此这里不承诺所有手机环境表现一致。遇到 WebGL、纹理尺寸或浏览器兼容问题时，请换用桌面 Chrome 或先在本地缩小照片。

## 依赖边界

运行时只通过共享服务暴露以下固定白名单资源，不公开整个 `node_modules`：

```text
/vendor/pannellum/2.5.7/pannellum.css
/vendor/pannellum/2.5.7/pannellum.js
```
