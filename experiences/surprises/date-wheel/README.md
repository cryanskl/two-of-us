# 今晚做什么

一个 A 级本地约会转盘：准备 2–12 个候选，点击一次便等概率选出今晚的安排。可以一人提前准备给对方，也可以两个人现场一起决定。

## 启动与定制

- 等级：A（直接打开）
- 玩家：1–2 人
- 设备：单设备；触屏、鼠标和键盘均可
- 公网依赖：无；第三方运行依赖：无

直接双击本目录 `index.html`。编辑 `config.js` 可修改标题、说明、按钮、结果前缀和 `{ label, detail }` 候选；请勿把真实地址、票据或其他不希望公开的私人内容提交到公开仓库。

转盘先使用浏览器 `crypto.getRandomValues()` 等概率选定索引，再播放停到对应扇区的 SVG 动画。每次抽取相互独立，允许连续抽中同一项；没有隐藏权重、防重复、历史或网络请求。减少动态效果模式会缩短动画，但不会改变结果。
