# 爱的刮刮卡

一款 A 级单人惊喜：收礼物的人用鼠标或手指刮掉 Canvas 涂层，达到约 55% 后完整揭晓一张约会券、礼物说明或私人承诺。

## 启动方式

- 等级：A（直接打开）
- 玩家：1 人准备，1 人体验
- 设备：单设备
- 输入：鼠标、触屏；键盘可使用“直接揭晓”
- 公网依赖：无
- 第三方运行依赖：无

直接双击本目录的 `index.html`，不需要安装、服务器或网络。也可以从仓库根门户打开。

## 定制

编辑 `config.js` 中的称呼、标题、引导语、礼物标题、正文、结尾、落款和按钮文案。配置值只会作为纯文本显示；请不要把真实地址、票据、兑换码或其他不希望公开的私人内容提交到公开仓库。

## 交互说明

- 涂层达到约 55% 擦除面积后自动完整揭晓；
- 页面尺寸变化时会重放归一化擦除线段，不会重新盖住已经刮开的部分；
- “直接揭晓”是键盘与动作能力受限用户的等价入口；
- 页面不保存进度，刷新后会重新覆盖涂层。
