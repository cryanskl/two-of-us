# 一封慢慢打开的信

一个 A 级单人惊喜：拆开信封，依次阅读三段回忆，最后收到一份约会邀请。

## 启动

直接双击 `index.html`。无需安装、服务器或网络。

## 定制

编辑 `config.js` 中的收件人、署名、回忆卡片和最终邀请。不要把真实私人内容误提交到公开仓库。
