# 沿着折痕，折到你心里

一个 A 级本地惊喜。收礼者沿着五道亮起的折痕，把同一张代码原生信纸慢慢折好；主动翻到背面后，才会看见准备者留下的称呼、标题、留言和署名。

这是一套为网页独立设计的五步仪式，不是传统折纸模型教学。

## 打开方式

直接双击 `index.html`。页面使用经典脚本和相对路径，不需要安装依赖、启动服务、登录账号或连接网络；复制整个 `origami-heart` 目录后仍可独立打开。

## 怎么体验

1. 按“开始折”进入第一道折痕。
2. 每一步可以沿当前箭头拖动纸边，拖过提交阈值后完成；也可以直接按“折好这一步”。
3. 五道折痕必须依次完成，分别是收起下边、收进左角、收进右角、收圆左尖和收圆右尖。
4. 五折完成后，主动按“翻到背面”。
5. 最终短笺出现后，可以按“再折一次”清空进度并回到开场。

键盘用户可以使用 Tab 找到当前按钮，以 Enter 或 Space 完成；折纸阶段也可以使用 ArrowRight 快捷完成当前一步。拖动不是必需路径。

## 可选定制

默认配置无需修改即可完整体验。准备者可以在 `config.js` 中修改四个纯文本字段：

- `recipientName`
- `finalTitle`
- `finalMessage`
- `signature`

请不要把不希望进入仓库历史的私人信息提交到公开仓库。

## 隐私与依赖

- intro、五道折痕和翻面前的公开 view、DOM、属性、ARIA 与状态播报都不包含最终短笺。
- complete 时才创建称呼、标题、留言和署名节点；重开会再次删除。
- 内容和进度只存在当前页面内存；不写入 URL、浏览器存储、剪贴板或日志，也不发送网络请求。
- 刷新页面会清空进度。
- 这种阶段遮挡只防止正常体验流程提前看到内容；能查看 `config.js`、页面源码或 JavaScript 内存的人仍可读到本地配置，它不是密码学加密。
- 运行时不使用第三方代码、图片、字体、图标、音频、Canvas、WebGL 或远程服务。

## 显示与降级

2D 纸张是正式发布路径，支持 3D transform 时只增加拖动中的空间翻折感。减少动态、强制颜色、不支持 3D 或 `clip-path` 时，五道折痕、编号、文字和原生按钮仍可完成；JavaScript 被禁用时只显示公开说明，不会提前显示短笺。
