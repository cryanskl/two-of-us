# 拍立得显影

一款 A 级本地惊喜：按下快门取出相纸，再交替左右摇动九次。照片从模糊、低饱和逐层显影，写给对方的话只在完成后出现。

## 打开

直接双击 `index.html`，或从仓库根目录运行 `start.command` / `start.bat` 后在统一门户打开。页面没有安装步骤，也不依赖服务器。

## 个性化

1. 把一张自己有权使用的 `jpg / jpeg / png / webp / avif` 照片复制到 `assets/`；
2. 用文本编辑器打开 `config.js`；
3. 只替换 `photo`、`title`、`stamp`、`caption`、`finalNote` 五行；
4. 保持照片路径为本目录下的相对路径，例如 `./assets/our-photo.jpg`。

配置结构或文字长度不合法时，页面会整份回退到默认示例。配置有效但照片读取失败时，只回退到示例照片，已经写好的私人文案仍会保留。

## 玩法与输入

- 按“按下快门”，等待相纸弹出；
- 用鼠标或手指把相纸左右交替拖过中线，或让相纸获得焦点后交替按 `←`、`→`；
- 同一方向连续输入不会重复计数，完成九次有效摇动后显影结束；
- “再显影一次”会清空本轮进度，但不会保存任何结果。

## 隐私与本地边界

- 不联网、不上传、不保存，不请求相机、文件选择器、动作传感器或存储权限；
- 照片从相对路径直接读取，状态只存在当前页面内存，刷新即清空；
- 私人标题、地点、说明和留言在显影完成前不会进入页面 DOM；
- 但照片与文字仍是本地文件中的明文，不构成密码学保密。若仓库公开，请不要提交不适合公开的私人内容。
