# 三枚以后，都是我们

一个可以直接双击打开的本地惊喜页：收件人任意敲开“什么时候”“去哪里”“一起做什么”三枚未来签，三段收齐后再主动把它们拼成一封邀请。

## 直接打开

双击本目录的 `index.html`。页面使用经典脚本与相对资源，不需要安装依赖、启动服务或连接网络。

## 准备自己的内容

用纯文本编辑器打开 `config.js`，优先修改带 `TODO` 注释的内容：

- `notes.when`：想把邀请放在什么时候；
- `notes.where`：想和对方去哪里；
- `notes.together`：想一起做什么；
- `closing`：邀请后的补充话；
- `signature`：署名。

保存后重新打开 `index.html` 即可。动态文案按纯文本处理，不支持 HTML 标记。

## 玩法与隐私边界

- 三枚签可以按任意顺序打开，最终邀请始终按“什么时候 → 去哪里 → 一起做什么”组合；
- 收齐三段不会自动跳转，只有点击“把三个以后拼起来”才展开完整邀请；
- 不使用随机、账号、存储、音频、分析或公网请求，刷新页面即重置；
- 未到相应阶段的内容不会进入当前 DOM，但纯前端源文件本身可被查看，这不是密码学加密；
- 背景或饼干图片加载失败时，CSS 轮廓、文字和原生按钮仍可完成全流程。

## 文件

- `config.js`：可定制文案与邀请合成函数；
- `logic.js`：确定性状态机和阶段公开视图；
- `app.js`：DOM 渲染、焦点与无障碍播报；
- `styles.css`：响应式视觉、减少动效和强制颜色降级；
- `logic.test.js`：配置、状态、六种开启顺序与秘密边界测试；
- `ATTRIBUTION.md`：开源研究来源、排除项、生成素材与零复制声明。
