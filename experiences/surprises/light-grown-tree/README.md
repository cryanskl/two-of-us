# 跟着光，长成一棵树

一个 A 级、本地优先的单人惊喜：接收者移动一盏暖光，每让树长一节，所有枝条就朝光当时所在的方向长过去。十二节之后花开满枝，才展开准备者写下的信和相守时间。

最后那棵树的形状，不是预先画好的——它是对方把光带到过哪些地方的记录。同一条光的轨迹永远长出同一棵树，不同的轨迹长出不同的树。

## 打开

在完整仓库内直接双击 [`index.html`](./index.html) 即可。也可以从仓库根目录运行 `start.command` / `start.bat`，再从统一门户打开。

- 不需要安装 npm 包；
- 不需要服务器、账号或网络；
- 没有声音，也没有任何音频或图片文件；
- 画布不可用时会显示替代说明，生长、进度和最后的信仍然可以完整完成；
- 刷新页面会从头开始，不保存进度。

作品目录是自足的：单独复制 `experiences/surprises/light-grown-tree/` 就能送人，不依赖仓库里的任何其他文件。

## 玩法

1. 点击“开始种下”；
2. 把光拖到你想让树长过去的地方——也可以直接点画面上的任意位置，光会移过去；
3. 点击“让它长一节”；
4. 重复第 2、3 步，一共十二节；
5. 第 2、5、8 节之后枝条会分叉，最多长到八根；
6. 十二节长满后开花，信随之展开；
7. 点击“再种一棵”可以重新开始，长出完全不同的另一棵。

键盘操作：聚焦画面里的光点后，用方向键移动（按住 Shift 移动得更快），再用 Tab 移到“让它长一节”。全流程不需要鼠标。

树永远向上长：光只决定它往左往右偏多少、偏得多急，不会把枝条拽进地里。越细的枝越守住自己的方向，所以树冠会散开，而不是全部收拢到光点上。

## 准备一份自己的惊喜

用文本编辑器打开 [`config.js`](./config.js)，可修改：

- `recipientName`：完成后显示的称呼；
- `finalTitle`：最终标题；
- `letterLines`：信的正文，一行一句，最多 8 行；
- `signature`：落款；
- `togetherSince`：在一起的起点，例如 `"2019-04-20"` 或 `"2019-04-20T20:15:00"`；留 `null` 就不显示相守时间；
- `composeGrowthNote`：可选的 5–10 行提示策略。

`composeGrowthNote` 每长完一节调用一次，返回一句 40 字以内的短提示。返回 `null` 使用内置的六句；返回非字符串、空串或抛出异常都会安全回退，不会阻断生长，也不会挡住最后的信。日期写错同样只是不显示相守时间，而不会显示一个错误的数字。

## 本地、隐私与降级边界

- 页面没有网络请求、输入框、账号、Cookie、`localStorage`、`IndexedDB` 或 Service Worker；
- 文案只存在本地 `config.js`，不会上传；但它是本地明文，不是密码学保密；
- 相守时间只读取本机时钟，不做任何校时或上报；
- 生长完全由确定性函数计算，不使用 `Math.random`：同一条光的轨迹重放会得到同一棵树；
- 画面之外有一份文字进度镜像，并通过 live region 播报每一节的方向和剩余节数；
- 尊重 `prefers-reduced-motion`：开启后信直接呈现，不做淡入。

## 借鉴与来源声明

核验日期：2026-07-28。

本作**没有引入任何第三方源码、素材、字体、音频、图标或运行依赖**。页面结构、样式、生长模型、状态机、中文文案和测试均为本仓库独立创作，没有复制、翻译、改写、打包或依赖任何外部项目。

生长方向由三项加权合成：枝条自身方向的惯性、恒定的向上偏置、朝光方向的牵引；随分叉层级衰减的追光权重和最小仰角约束都是本作自己的设计参数。可重放的偏移量来自一个标准整数散列（Knuth 乘法常量与 MurmurHash3 finalizer 常量，均为公开发表的通用算法常量，不构成对某个具体项目的借鉴），只用来把「枝条 id + 步序」映射成固定抖动，替代 `Math.random`。

本作是仓库里第三方作品 [Love Tree](../love-tree/) 的原创替代：两者都属于“树 + 情书 + 相守时间”的惊喜类型，但玩法、代码、视觉和文案完全独立，不共享任何源码或素材。Love Tree 自身的来源与许可记录仍以它自己的 `README.md` 为准。
