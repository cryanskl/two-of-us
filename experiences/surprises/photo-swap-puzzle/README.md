# 拼回这一刻

一款 A 级私人照片交换拼图：从电脑或手机选择一张照片，应用在当前浏览器中把它中心裁成方形并打乱成九块；每次点选两块交换，直到拼回完整照片。

## 启动方式

- 等级：A（直接打开）
- 玩家：1 人准备、1 人体验，也可以两个人在同一设备上完成
- 输入：鼠标、单指触摸、Tab、Enter、Space
- 公网依赖：无
- 第三方运行依赖：无

直接双击本目录的 `index.html` 即可使用，不需要安装、启动服务或联网。本目录也可以单独复制给对方。

## 照片要求

- 支持 JPEG、PNG、WebP；
- 文件必须大于 0 且不超过 20 MiB；
- 短边至少 600px，任一边不超过 6000px；
- 不限制原图比例；应用只做固定的中心正方形裁切，不提供裁切编辑器。

应用把中心裁切输出为最长 1200px、质量 0.9 的 JPEG 派生图。九宫格每次使用安全随机值重新打乱；第一次点选一块，再点同一块会取消，点另一块才交换并增加次数。

## 隐私与生命周期

原始照片和派生图只存在当前浏览器上下文。应用不使用 `fetch`、XHR、WebSocket、表单提交、localStorage、IndexedDB、Cache API、Service Worker、账号、云同步、下载或分享，也不读取 EXIF、GPS、设备和拍摄时间。

原始文件对象 URL 在中心裁切完成后立即撤销。新照片只有在格式、尺寸、解码和 Canvas 输出全部成功后才替换当前拼图；失败时保留现有拼图。快速连续选择、更换、清除、`pagehide` 和 `beforeunload` 都会清理仍由应用持有的对象 URL。派生 JPEG 通常不继承原文件 EXIF，但本作品不声称提供恶意文件扫描或取证级元数据擦除。

## 操作与可访问性

- 九块都是固定的原生按钮，交换不会重建 DOM，因此键盘焦点保持稳定；
- 选中态同时使用珊瑚色轮廓、轻微位移和 `aria-pressed`；
- 每块的可访问名称包含原图目标行列与当前位置；
- 完成后九块锁定，并显示带通用 alt 的完整派生图；
- `prefers-reduced-motion` 下取消选中位移；
- 已验证的目标布局为桌面 `1280×900`、移动 `390×844`，并为 320px 宽度提供单列控制区。
