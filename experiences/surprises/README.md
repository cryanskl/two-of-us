# 单人惊喜

这一类作品由一个人提前准备内容，再把整个目录或入口送给伴侣打开体验。

## 已收录

- [Love Tree](./love-tree/)：点击爱心后生长的告白树、打字情书和相爱计时器。
- [一封慢慢打开的信](./memory-letter/)：依次翻阅三段回忆，最后送出一份约会邀请。
- [爱的刮刮卡](./scratch-surprise/)：刮掉 Canvas 涂层，揭晓可定制的约会券或私人承诺。
- [今晚做什么](./date-wheel/)：转动等概率约会转盘，从可定制候选中决定这次安排。
- [回到那一天](./panorama-memory/)：通过本地启动器选择一张私人 360° 全景照片，在当前页面中拖动回看。
- [拼回这一刻](./photo-swap-puzzle/)：选择一张本机照片，交换九块拼回完整画面；照片不会上传或保存。
- [未来车票](./future-ticket/)：从三组隐藏孔位中逐次盲选并打孔，签发一张可本地定制的未来约会车票。
- [拍立得显影](./instant-photo/)：按下快门取出相纸，交替左右摇动，让本地照片和写给对方的话逐层显影。
- [一层一层](./nested-gift/)：用解丝带、揭纸角、拉抽屉和轻敲四种输入，逐层打开可定制的盒心留言。
- [纸飞机投递](./paper-plane-mail/)：调好仰角与力度，把一封本地定制的信投进邮箱，命中后再亲手打开。
- [星码解锁](./star-code-unlock/)：回答三条只有彼此知道的线索，逐颗点亮星位，最后读出一段本地定制的星码。
- [把这首转给你](./hand-crank-music-box/)：顺时针转动手摇音乐盒，让原创短旋律逐音响起、纸雕夜景展开，最后读到一段本地留言。
- [把月亮拨回那一天](./moon-phase-secret/)：根据三条私人线索校准月份、日期和离线近似月相，三轴同时对齐后展开本地留言。
- [在雾上，写给你](./fog-window-letter/)：先在雾窗写下一遍，再沿自己的原始笔迹走回来，找回足够多露珠锚点后揭信。
- [把夜晚照成我们](./starlight-keepsake-search/)：移动光心并在五件纪念物上连续停留，逐件留下短句，找齐后点亮整幅夜景与信。
- [三枚以后，都是我们](./future-cookie-notes/)：任意敲开三枚未来签，收好时间、地点与一起做的事，再主动拼成一封邀请。
- [沿着折痕，折到你心里](./origami-heart/)：依次拖动或按按钮完成五道网页折痕，主动翻面后才展开代码原生心和本地短笺。
- [今晚，点三束光](./wish-fireworks/)：选择高度并按住蓄光，让三束烟火依次留下一个字，第三束落定后才展开本地定制的短笺。
- [把花语，系成一束](./flower-language-bouquet/)：依次挑出主花、陪衬和点缀，系成专属花语，并在完成后本地准备一份含留言的 SVG 花束。
- [每一格，都是喜欢你的理由](./compliment-reels/)：拉动三列夸夸纸卷，本轮第 3–6 次之间必有一次特别同频，真正落定后才展开私人结语。
