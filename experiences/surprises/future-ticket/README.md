# 未来车票

一款 A 级本地惊喜：体验者依次盲选三个孔位，打孔后才揭晓出发时间、目的地和随行彩蛋，最后得到一张完整约会车票。

## 打开

直接双击 `index.html`，或从仓库根目录运行 `start.command` / `start.bat` 后在统一门户打开。

## 个性化

用文本编辑器打开 `config.js`，替换：

- `passenger`、`issuer`、`finalNote` 与 `serial`；
- `groups` 中三组各三个候选，共九条文案。

每组固定三个候选。请确保时间、地点、彩蛋任意组合都成立；不要改动三个 ID `when / where / bonus`。配置结构或长度不合法时，页面会整份回退到默认内容。

## 隐私与本地边界

- 不联网、不上传、不保存，不读取设备权限；
- 结果只在当前页面内存中，刷新即清空；
- 未揭晓候选不会进入正常页面 DOM，但它们仍是本地 `config.js` 明文，不构成密码学保密。
