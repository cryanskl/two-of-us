# 纸飞机投递

一份本地优先的单人惊喜：收件人调整仰角与力度，把纸飞机送进邮箱；成功后亲手打开准备者写好的信。

## 直接打开

双击 [`index.html`](./index.html) 即可。它是 A 级纯静态体验，不需要安装依赖、启动服务、联网或创建账号。

## 换成你们的内容

用文本编辑器打开 [`config.js`](./config.js)，修改：

- `recipientName`：收件人称呼；
- `senderName`：落款名字；
- `letterTitle`：信件标题；
- `letterLines`：1–4 段正文；
- `signOff`：结尾寄语；
- `hintForMiss(context)`：可选的失败提示策略。

保存后重新打开或刷新页面即可。默认 `20° / 70` 是稳定命中组合，适合放进第三次提示中。

信件只在投递成功并点击“打开这封信”后创建到页面 DOM；但正文仍以明文保存在本机 `config.js`，这不是加密保护。页面不联网、不上传、不保存尝试记录。

## 规则与验证

- 固定 `1 / 120` 秒步长推进抛体规则，不受屏幕刷新率影响；
- 连续线段碰撞避免纸飞机跨过邮箱开口；
- 开启“减少动态效果”时直接演算到同一结果；
- 鼠标、触摸、键盘方向键和 ± 按钮均可调整；
- 刷新后从第一次投递重新开始。

规格、来源边界和验收口径见 [`../../../docs/54-paper-plane-mail-spec.md`](../../../docs/54-paper-plane-mail-spec.md)。
